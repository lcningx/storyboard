# 迪迦奥特曼（1996–1997，全 52 集）分集故事

> 资料来源：[Ultraman Wiki](https://ultra.fandom.com/) 各集页面与怪兽页面（英文粉丝维基），集名对照 [Wikipedia](https://en.wikipedia.org/wiki/Ultraman_Tiga)。2026-11-01 整理。
> 中文集名是日文原题的直译，不一定是国内播出时的译名。约一半的集在维基上只有一句话梗概，这些集的经过是从怪兽页面补的，细节可能不全。
> "能借的机制"一栏是整理时的初步判断，还没按《[案例拆解](../案例拆解.md)》的证据标准论证。

## 全剧的骨架

- **起源**：3000 万年前，一群光之巨人守护着超古代文明。现代挖出三座巨人石像，两座被怪兽毁了，GUTS 队员大古和最后一座融合，迪迦复活（第 1 集）
- **主角是人**：大古是人在操纵巨人的身体，所以被叫作"人间奥特曼"。剧场版交代迪迦曾是"黑暗巨人"之一，后来选择了光
- **贯穿线**：超古代文明为什么灭亡（第 45 集揭开一层）；还有别的巨人石像、别的"光之子孙"（第 43–44 集）；大古的身份分批被人知道（TG-6）；终极黑暗加坦杰厄复活（第 50–52 集）
- **结局**：迪迦被打成石像，人类和全世界的孩子变成光让他复活（TG-8）
