# 世界观

## 核心主题：各不成龙，合而成龙

龙王一共九个孩子，没有一个长得像龙：有的像乌龟，有的像狮子，有的拖着鱼尾巴。几百年来他们各奔东西，各过各的日子，心里都暗暗觉得自己"不够格"，怕老爹失望。

全剧要讲的就是：**一个孩子单独看都不像龙，九个合在一起，才是一条完整的龙。**

## 基本设定

- **舞台：** 普通的现代北京。胡同、地铁、超市、庙会、医院、小区物业，哪儿都能去。
- **外形：** 九兄妹平时是人形，但每个人都**保留明显的兽形特征**：龙角、鬃毛、龟壳、鱼尾、背上插着的剑……
- **人类的态度：** 见怪不怪。北京大爷什么没见过，顶多问一句"姑娘，你这cosplay挺下本儿啊"。（同《非人哉》的处理，人类不追究，笑点放在神兽自己身上。）
- **能力：** 都还在，但在现代生活里经常帮倒忙：蒲牢一嗓子能震碎玻璃，螭吻看见烟就喷水，赑屃一个人能扛起一辆车。
- **家：** 北京胡同里的一座老四合院，龙王的老宅。房间不够九个人住，这本身就是矛盾。

## 主线：从除夕到二月二

- **除夕：** 老爹在家族群里发消息，把散落在全国各地的九个孩子全叫回北京老宅过年。九兄妹几百年来第一次聚齐。
- **年夜饭：** 十个座位，老爹的位置空着。桌上只有一部手机，循环播放老爹的视频：
  > "爹退休了，出去转转。
  > 二月二龙抬头，今年你们九个替我抬。
  > 这之前，你们九个必须住在一起。谁搬出去，谁就别回来了。
  > 抬不起来，龙王的位子就交给你们堂兄弟。"
- **倒计时：** 从除夕到二月二，一个多月。每集片尾显示"距龙抬头还有X天"。
- **对手：** 九个堂兄弟，也就是九龙壁上那九条正统的龙。长得像龙，样样优秀，标准的"别人家的孩子"，一直觊觎龙王的位子。
- **季末：** 二月二，九兄妹合力行雨，在北京上空合成一条完整的龙。

## 时间线自带的节日场景

| 日子 | 场景 |
|---|---|
| 除夕 | 春运、回家、年夜饭 |

| 初二 | 亲戚上门（堂兄弟来了） |
| 初五 | 庙会、"破五"放鞭炮 |
| 初七以后 | 节后上班，社区登记，日常生活 |
| 正月十五 | 元宵灯会、猜灯谜 |
| 二月二 | 龙抬头、剃龙头 |

## 新角色来源（持续上新）

- **胡同邻居：** 隔壁的老大爷、遛鸟的、下棋的、收废品的
- **社区：** 物业、居委会大妈、社区网格员
- **生活场景里的路人：** 超市试吃阿姨、庙会摊主、外卖员、地铁安检员
- **神兽亲戚：** 九龙堂兄弟，以后还可以有表亲（凤家、麒麟家）、老爹的老朋友
