## 核心创作原则

> **生活随便现代，特征必须保留。**

参考《非人哉》《有兽焉》《快把我哥带走》：生活场景完全放开，就是普通的现代都市。笑点来自角色**本体的特征在日常生活里藏不住**。

- ✅ 可以：住在胡同里，用手机，点外卖，坐地铁，逛超市，过春节
- ✅ 必须：原形特征（角、尾巴、壳、背上的剑）、本能习性、能力、传说里的老梗，都要在日常里**持续制造麻烦**
- ❌ 不行：特征只剩一个职业标签，换成普通人来演也一样

## 从前几版吸取的教训

1. **人设不能只剩职业标签**（第一版的错误：睚眦是健身教练、螭吻是消防员，神兽的特征全没了）。
2. **也不能把生活范围限死**（第二版的错误：附在器物上、白天不能动、只能待在固定地点，场景太单一）。
3. **开局不能被动、单薄。** 第1集就要有事件、目标、倒计时，还要群戏。

## 与其他"龙生九子"作品的区分

"龙生九子"题材已有别人在做，本方案要靠下面几点做出差异：
- **核心主题"各不成龙，合而成龙"：** 单独一个都不像龙，九个合起来才是一条龙。
- **春节到二月二的时间线：** 从除夕团圆到龙抬头，用民俗节日串起整季。
- **"别人家的孩子"：** 九龙壁上那九条正统的龙是他们的堂兄弟，是竞争对手。
- **九子改编为4男5女：** "子"在古文里可以泛指子女。大姐囚牛、三姐嘲风、四姐蒲牢、五姐狻猊、八妹负屃，二哥睚眦、六哥赑屃、七哥狴犴、九弟螭吻。
