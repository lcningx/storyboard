## 企划方向（讨论记录）

**参考作品：** 《有兽焉》《快把我哥带走》《非人哉》

**目标平台：** 抖音等短视频平台。年轻观众偏爱多角色、不断有新角色登场的内容，这类内容流量好。

**参考作品的共同点：**
- 日常喜剧加群像，每集独立，适合切片传播
- 核心笑点是"反差"：身份高大上，处境接地气
- 角色辨识度高，一两个标签就能立住
- 笑中带暖，靠温情集积累粉丝黏性
- 传统文化现代化，带来亲切感和讨论度

**选题过程：**
1. 最初考虑"龙生九子"。这个思路已有别人在做，所以作为备选。
2. 备选的原创角色池：民间小神仙住老小区（灶王爷、门神、土地公等）、博物馆闭馆后的文物神兽
3. 选定：故宫太和殿脊兽
4. 后来又做了一版"龙生九子"方案，存在 [../各不成龙/](../各不成龙/README.md)

## 核心创作原则

> **身份不变，环境变。**

- 角色**必须保持神兽身份**：保留原形、本能、习性和本职工作。**不能把他们写成现代人**（比如变成健身教练、律师、消防员），否则就丢掉了特点。
- 笑点来自**古老神兽的逻辑撞上现代世界**，而不是来自他们"像现代人"。
- 现代元素是**冲击他们的东西**，不是他们的职业标签。
- 主线方向：神兽的老本行被现代社会"抢了饭碗"。
