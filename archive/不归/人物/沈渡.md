# 沈渡（主角）

> 名字里的"渡"，暗合摆渡、渡魂，也暗合枪里的阴差。读者一开始只会觉得这是个普通名字。

---

## 一句话

**欠了一屁股债的急救员，嘴上什么都在算钱，可只要有人快死了，他的手比谁都快。**

---

## 性格（参考张楚岚、淀治：愿望朴素，嘴贫，讨喜）

| 特点 | 表现 |
|---|---|
| **愿望朴素** | 还完债，睡个整觉。仅此而已 |
| **嘴贫** | 什么时候都能吐槽，挨揍的时候也是。爱用急救术语损人："你这属于开放性骨折，建议别动" |
| **爱算账** | 什么都折成钱算。看到自己的悬赏，第一反应是"我自首能分多少" |
| **怂在嘴上，硬在手上** | 嘴上喊着"我就是个开救护车的"，真到要命的时候从来不退 |
| **职业病** | 看见有人受伤就忍不住去处理，连刚想杀他的人也一样 |

**反差就是他招人喜欢的地方**：嘴上贪财、怕麻烦，手上能救就救。

---

## 背景

- **120 急救员**，天天抢夜班，因为夜班补贴多
- **欠债**：父亲很多年前跑了，留下一笔债。他从十几岁开始还，现在还在还
  - 父亲"一去不回"，和林晚的母亲"等人回家"形成镜像，两人在这一点上能互相理解
- 搭档老何是他在这个世界上最接近家人的人

---

## 能力

| 项目 | 内容 |
|---|---|
| 器 | 一把普通的手枪 |
| 鬼相 | 十米高、没有脸的巨人，从他的影子里站起来 |
| 本相 | **止**。巨人碰到的东西都会停下来：列车、水流、子弹，甚至心跳 |
| 另一个能力 | 巨人能把别人的鬼从主人身上揪出来。被揪的人会听见有人叫自己的名字 |
| **出现的规律** | **有人快死的时候，它才会出来**，不管快死的是沈渡自己还是别人。所以沈渡没法随意召唤它（第 3 集发现这条规律） |
| 异常 | 白塔测不出它的品阶，读数在"怨"和"煞"之间乱跳；器类既不是本命器，也不是炼器 |
| 藏着的 | "止"其实就是死亡本身。枪里住的是一只阴差 |
| 死境 | **黄泉路**：打开以后，死者可以离开（第 23 集） |

**读者先猜错**：读者会以为这是一只凶级的"巨人鬼"，本相是控制时间或者定身。直到很后面才知道，它根本不是鬼。

## 那三分钟

| 读者看到的 | 作者藏着的 |
|---|---|
| 一个雨夜，他跟车去救一个从楼上坠下的女孩，救护车在回程路上出了事故（第 5 集闪回） | 女孩是青苗会"下种"的目标，青苗会的人当晚也在现场捕猎一只阴差 |
| 他心跳停了三分钟，醒来时手里握着一把从没见过的枪 | 阴差逃命时需要一个刚死的身体做容器 |
| 监护仪显示 23:41 心跳停止，车祸在 23:44（第 17 集揭开） | 他死在车祸之前。阴差叫了他的名字，他应了一声 |

---

## 成长线

| 阶段 | 他想要什么 |
|---|---|
| 悬赏篇 | 撤掉悬赏，保住小命，接着还债 |
| 鬼市篇 | 找到挂单的人。第一次让一只鬼真正离开，发现自己能做到别人做不到的事 |
| 白塔篇 | 弄清自己到底是什么。得知自己早就死过一次，枪里是一只阴差 |
| 不归篇 | "能救就救"的人，要面对一个救不了所有人的选择：打开黄泉路，所有放不下的人都得放手 |
