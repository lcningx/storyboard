# 《不归》方向总结

> 汇总讨论中提出的所有意见、参考作品，以及由此得出的创作方向。

---

## 一、你提过的意见（按主题归类）

### 1. 类型与定位
- 不是传统捉鬼故事，要写**人控制鬼、拥有鬼的能力**
- 鬼不一定是敌人，"人比鬼可怕"
- 主角**不捉鬼**，他是鬼能力的拥有者，身上还有一股神秘的力量（类似镇魂街）
- **鬼只是差异化**，整体可以完全按镇魂街、一人之下来排
- 形式：**动漫节奏，每集约 5 分钟 × 24 集**

### 2. 想象力
- "没一点想象力"：别老往纸钱、香灰、黄纸、符、殡仪馆上靠，"跑不出钟馗"
- 武器不能是真枪，要魔幻；也不能全员用枪，太限制战斗形态
- 特效不能空：人形黑影、气泡破掉这类通用效果都不行
- 能力量级要大、要酷：无面巨人一掌按停整列地铁，这个方向是对的

### 3. 设定的合理性
- 鬼怎么出现？为什么人能拥有鬼的力量？
- 人死了都不走，是不是人人都有鬼？
- 鬼为什么附在枪上？很勉强
- 执念了结以后呢？帮鬼得不到好处，不帮又有道德压力，这是互斥的
- 战力怎么体现？以后怎么打架？
- 组织的作用和战力是什么？
- 组织不能是现实中的政府部门（"市殡葬管理处"不合情理）；可以是这个世界自己的官方组织
- 在这个世界里死人遍地，死一个人有什么好拍的？

### 4. 悬念与信息
- 不要在源头就把故事讲完（"加班鬼"一听名字就知道全部）
- 不只是鬼，人物、武器、主角形象都犯了同样的毛病
- 限制不能是数值惩罚（"折阳寿"），否则主角就成了只会燃烧生命的废物

### 5. 开场与节奏
- 第一场留不住人；救人的戏看不下去
- 要能用画面表达，不要内心独白
- "想表达什么？"——每场戏要有目的
- 最不想看交代世界观
- **直接打开局，先把人留下，再说世界的事**
- 开局观众不喜欢任何角色，也不喜欢这个世界，**只有 5 秒**
- 动作的因果要看得懂（20–30 秒看不明白）
- 人物改主意要有理由；台词要和场面对得上（"人就在这，还说来找我"）
- 缝缝补补以后感觉没了，节奏太慢
- 后面不能莫名其妙：不能引用观众没看过的事，不能断了因果
- 不能看两遍一样的东西，信息量不能为零

### 6. 人物
- 开局没人喜欢沈渡（冷静、话少、专业，不讨喜）
- 要多角色，一直有新东西、新概念、新人物

### 7. 剧本写法
- 格式不能像小说，对白不能书面化

## 二、参考作品

| 作品 | 提出者 | 可借鉴的点 |
|---|---|---|
| **《镇魂街》** | 你 | 人和灵搭档作战；灵的形象有分量、有辨识度；灵的强弱一眼看得出来 |
| **《一人之下》** | 你 | 现代中国 + 异能；**门面越日常，背后实力的反差越大**（"哪都通"是一家快递公司）；多势力群像；普通人被蒙在鼓里；**主角张楚岚嘴贫、贱萌、讨喜** |
| 《咒术回战》 | 我 | 清晰的等级体系；领域展开（要和我们的"死境"拉开距离）；战斗节奏 |
| 《JOJO的奇妙冒险》 | 我 | 一人一种能力，新角色流水线，战斗像解谜 |
| 《电锯人》 | 我 | 人和恶魔订契约；**主角淀治的愿望极其朴素（想吃好的、想过普通日子），所以讨喜** |
| 《诡秘之主》 | 我 | 世界观一层层揭开 |

**两部核心参考作品的共同点：**
- 都是都市异能战斗，力量体系看得懂、看得见
- 世界观是在剧情和战斗里带出来的，不靠讲设定
- 主角都有很鲜明的个人色彩，观众先喜欢上这个人，才愿意了解他的世界

## 三、方向总结

### 一句话定位

**一部以"鬼"为力量来源的都市异能战斗动画。卖点是想象力强、看得见的能力和大场面打戏；鬼只是皮肤和标签，不是题材本身。**

### 观众优先的五条原则

1. **5 秒抓人**：开场给一个看得懂、却不可能存在的画面
2. **先打，再讲人，最后讲世界**：奇观 → 打戏 → 人物 → 世界
3. **每场都有新信息**：不重复，不空转
4. **因果看得见**：每一个动作和效果都要能从画面上理解
5. **世界靠剧情带出来**：不交代，不解释，靠事件和冲突露出

### 设定的两条底线

1. **自洽**：每条设定都要回答"为什么"和"会怎样"，而且不能和其他设定互相矛盾
2. **原创**：不照搬现实中的机构，也不照搬传统民俗的套路；可以借民俗的"味道"，但形式要新

### 要避免的

| 避免 | 原因 |
|---|---|
| 纸钱、香灰、黄纸、殡仪馆等白事意象 | 想象力被框死，跳不出钟馗 |
| 现实中的政府部门 | 不合情理，也有现实牵扯 |
| 鬼起搞笑名字 / 现代化 | 失去质感 |
| 在名字、设定里把谜底讲完 | 观众没有理由往下看 |
| 数值惩罚式的限制 | 主角会变成消耗品 |
| 空特效 | 没有质感，也没有意义 |
| 小说腔、书面对白、内心独白 | 动画是靠画面和口语讲故事的 |
| 冷冰冰的完美主角 | 不讨喜 |

### 我在过程中反复犯的错（以后要警惕）

1. **从设定出发，而不是从观众的体验出发**：先想好了"世界是什么样"，再想怎么讲给观众，结果总是在交代设定
2. **想象力被传统民俗框住**：一想到鬼，就自动跳到白事道具和捉鬼法器
3. **只改一处，不看整体**：改了开场，后面的戏还在引用开场里已经删掉的内容
4. **逻辑漏洞**：设定之间不自洽，你一追问就站不住
5. **缝缝补补**：一场戏塞太多东西，出了漏洞就加台词补，越补越慢、越像解释，原来的感觉就没了。应该删，把东西往后挪

## 四、目前状态

### 已确定
- 类型、形式（5 分钟 × 24 集）
- 力量体系：本相 × 现代武器（器）× 四层共鸣（附器 → 鬼身 → 鬼相 → 死境），品阶看鬼相大小
- 主角沈渡：急救员，本相"止"，鬼相是无面巨人，真相是阴差
- **官方组织：白塔**（城市中心一座白塔，本身是一件巨大的器，塔里镇着一只快死的阴差；成员按"层"分级）。已替换所有文档中的"殓房 / 归安殡仪"
