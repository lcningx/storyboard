# 美术设计

## 一、整体风格定位

- **类型：** 现代国风2D动画，平涂（赛璐璐）上色，线条干净（待MJ风格验证后确认）。
- **为什么倾向这个风格：**
  - 短视频要求画面在手机小屏上也能一眼看清，所以造型要简单、轮廓鲜明、颜色块面大。
  - 每集1到2分钟，更新频率高，平涂风格的制作成本可控。
  - 国风元素（琉璃、青铜、朱漆、碑石、宣纸）放在配色和材质上，人物服装以现代日常为主，正好对应"生活随便现代，特征必须保留"。
- **头身比：** 约5头身，略带Q感但不是纯Q版。这样表情和肢体动作都有空间，喜剧表演更灵活。

## 二、角色设计总规范

这一部分是给美术做正式角色设计用的规范，与MJ无关。

### 1. 每个角色的配色取自自己的"本职器物"

这是全剧最重要的美术规则：**看颜色就知道这个角色原来是干什么的。**

| 角色 | 本职器物 | 主色 | 辅色 |
|---|---|---|---|
| 囚牛 | 胡琴琴头 | 檀木棕 | 象牙白 |
| 睚眦 | 刀柄 | 铁灰 | 血红 |
| 嘲风 | 殿角 | 琉璃黄 | 天青 |
| 蒲牢 | 铜钟 | 青铜绿 | 铜锈蓝 |
| 狻猊 | 香炉 | 香灰米 | 琥珀橙 |
| 赑屃 | 石碑 | 石板灰 | 苔藓绿 |
| 狴犴 | 狱门 | 朱漆红 | 黄铜 |
| 负屃 | 碑文 | 墨黑 | 宣纸白 |
| 螭吻 | 屋脊正吻 | 琉璃碧绿 | 水蓝 |

### 2. 轮廓必须一眼区分

九个人站成一排时，**只看黑色剪影也要能认出谁是谁**。

| 角色 | 轮廓形状 | 关键识别点 |
|---|---|---|
| 囚牛 | 柔和的长线条 | 长发、背上的胡琴 |
| 睚眦 | 尖锐的三角形 | 尖耳、獠牙、腰间的刀 |
| 嘲风 | 蹲姿的不规则形 | 小翅膀、永远蹲着 |
| 蒲牢 | 最矮，钟形 | 张大的嘴 |
| 狻猊 | 大圆头 | 蓬松的狮子鬃毛 |
| 赑屃 | 宽大的圆形 | 背上的龟壳 |
| 狴犴 | 方正的矩形 | 方脸、笔挺的站姿 |
| 负屃 | 细长形 | 细长的龙尾、眼镜 |
| 螭吻 | 最高最大 | 鱼尾、背上露出的剑柄 |

### 3. 家族统一特征：一双金色的眼睛

九兄妹长得一点都不像，**只有眼睛都是龙王一样的金色**。这是他们身上唯一"像龙"的地方。
- 美术上：让这群外形差异很大的角色看起来是一家人。
- 剧情上：可以作为"各不成龙，合而成龙"的伏笔，第10集合体时，九双金色的眼睛同时亮起。

### 4. 兽形特征的保留程度

- **必须保留、不能被衣服挡住：** 龟壳、尾巴、翅膀、角、鬃毛、背上的剑。设计服装时要给这些特征"开口"，比如赑屃的棉袄背后开一个大洞露出龟壳。
- **可以弱化：** 皮肤基本是人类肤色，局部可以有鳞片、斑纹（例如狴犴太阳穴上的虎纹）。
- **服装：** 现代日常服装，带一点点中式元素（盘扣、立领、对襟），不穿古装。

### 5. 五个女性角色不能共用一张"美女脸"

九子是4男5女。女性角色最容易被画成同一个模板，换个发型就算不同角色，这是要避免的。
- **差异靠轮廓和兽形特征：** 囚牛柔和修长，嘲风矫健、永远蹲着，蒲牢最矮、嘴最大，狻猊头发蓬成一个大圆，负屃细长带尾巴。五个人的剪影放在一起必须一眼分开。
- **允许"不漂亮"：** 蒲牢大吼时的嘴、狻猊瘫着的姿势、负屃毒舌时的表情，都要敢于画得夸张、好笑。喜剧角色的表情张力比好看更重要。
- **体型也要拉开：** 不要五个都是一样的纤细身材。

## 三、MJ风格验证

### 定位

- **MJ只用来验证风格，不生成资产图。** 出的图不作为角色定稿、场景原画或任何制作素材，正式资产由美术按上面的规范绘制。
- **要回答的问题：** 某一种风格，能不能**同时**撑住本剧的所有元素：九个兽形特征差异很大的角色、普通人类路人、现代北京的场景、国风道具？放在一起是否统一？在手机小屏上是否清楚？
- **看图时只看风格，不看设计细节。** MJ每次出的角色长相、服装都会不一样，这很正常，不用管。只关注线条、上色方式、色彩处理、光影、质感、细节密度这些风格层面的东西。

### 验证方法

1. **候选风格：** 准备3种风格段（A/B/C），见下文。
2. **固定测试套件：** 一组覆盖角色、场景、道具、组合镜头的内容提示词，见下文。
3. **交叉跑图：** 每条内容提示词分别接上A、B、C三种风格段各跑一次。**同一条内容的三次跑图用同一个 `--seed`**，减少内容变化对比较的干扰。
4. **拼图对比：** 按"元素×风格"拼成对比表，填写下面的评分表。
5. **锁定复测：** 选出胜出的风格后，挑一张最能代表这个风格的图，用 `--sref 图片链接` 锁定，把整个测试套件再跑一遍，看风格在所有元素上是否稳定。
6. **可选探索：** 如果三种都不满意，可以用 `--sref random` 随机探索风格，遇到好的就记下它的sref代码，加进候选。

### 参数约定

- **版本：** 默认 `--niji 6`。如果用更新的版本，所有提示词统一换掉版本参数即可。
- **画幅：** 角色、道具用 `--ar 1:1`，场景和组合镜头用 `--ar 16:9`，同一类元素画幅保持一致。
- **提示词用英文，** 不写具体作品名或画师名。
- **格式：** `[内容提示词], [风格段] --ar X:X --seed 固定值 --niji 6`

### 判断标准

- **淘汰线：** "兽形特征表现""手机小屏可读性""动画制作成本"任何一项低于3分，直接淘汰。这三项决定了这部剧能不能做。
- **风格混用：** 如果某种风格只在某类画面上特别出彩（比如B在S8九龙壁、回忆镜头上很好），可以考虑作为**特殊段落的辅助风格**，比如回忆或温情集，但主风格只能有一个。
- **验证结束后的交付：** 选定的风格段文字、一张代表性的 `--sref` 参考图、填好的评分表。这三样交给美术，作为正式设计的风格依据。
