## 一、底层逻辑

观众每一秒都在决定留下还是划走，心里算的是一笔账：

**留下来的理由 = 想知道的 + 得到的情绪 − 要花的脑子**

| 观察到的特点 | 在账本里的作用 |
|---|---|
| 故事简单 | 让"花的脑子"变小 |
| 打斗有逻辑 | 让"想知道的"变大：观众能跟着猜 |
| 观众熟悉的梗 | 花的脑子接近零，还自带情绪 |
| 前5秒 | 第一笔"想知道的"，必须在观众认识主角之前给出 |

### 核心引擎：猜 → 验证

1. 观众看懂规则，开始猜接下来会怎样
2. 剧情给出结果：
    - 猜中了 → 满足感（"我就知道！"），比如变身、必杀技这类仪式
    - 猜错了，但回头一想合理 → 惊喜（"原来还能这样！"）
    - 猜错了，而且不合理 → 觉得被骗，划走
3. 结果一出，马上给下一个猜测点

故事简单、规则清楚，观众才猜得动。熟悉的梗等于观众脑子里已经有现成的预测，只需要在他以为的地方拐个弯。

## 二、两个来源各管什么

**一句话：特摄管"一个单元一个单元怎么来"，动漫管"每一场怎么打"。**借多少、新在哪，见本章末尾"[借什么、新在哪](#借什么新在哪)"。

"来源"指的是学这件事主要看谁，按功能分，不按媒介分。特摄里也有好的打斗逻辑：空我的形态要从环境里拿武器（KR-1），龙骑的限制逼人做选择（KR-3）；动漫里也有好的仪式：咒术回战领域展开的手印（JJ-4）。判断一条规则放在哪边，问它管的是什么，不问它出自哪部作品。

### 叙事壳：主要看特摄

| 管什么 | 拿什么 | 证据 | 不拿什么 |
|---|---|---|---|
| 每个单元为什么来一个新对手 | 一条统一的来源规则：魔灵石、反派自己的杀人游戏 | KJ-7、KR-2（差 1 个案例） | 规则太死，怪兽变成流水线 |
| 每集的流程 | 固定公式，观众不用花脑子跟结构 | TG-1、SS-1 | 连打法也固定 |
| 仪式 | 变身、口号、集体亮相、招式名 | KJ-2、KR-4、SS-4、JJ-4 | 用仪式代替打斗设计 |
| 变量层的情绪 | 每集对手带来一个新故事，对手可以是受害者 | TG-4、TG-5、KJ-5、YR-8、HX-2 | 配角的情绪压过主角 |
| 伙伴集结和阶段高潮 | 伙伴逐个登场；新伙伴先当对手；最强形态先落在敌人手里，再靠合体夺回 | KJ-3、KJ-4、SS-2 | 每个新伙伴都走"先当敌人" |
| 熟梗返场 | 观众早就认识的东西当援军，或直接做成能力 | TG-7、SS-3、ZH-1 | 新剧没有前辈可借，要先自己攒 |
| 贯穿线的秘密 | 一个秘密分批让不同的人知道 | TG-6（1 个案例） | — |

### 打斗质感：主要看动漫

| 管什么 | 拿什么 | 证据 | 不拿什么 |
|---|---|---|---|
| 能力规则 | 一句话说清，规则里写着人物（性格、心结、身份） | OP-10、YR-2、JJ-2、ZH-5 | 要靠术语讲清的规则 |
| 换形态、变强 | 形态之间差在规则或条件上 | KR-1、FT-2（正例）；TG-2、KJ-1（反例） | 只差数值（更大、更快） |
| 限制 | 逼人做选择的限制 | OP-8、KR-3、HX-1 | 只把限制当节拍信号（TG-3）。节拍信号属于壳，可以用，但不是限制的全部 |
| 代价 | 看得见；落在身体、时间、剧情、伙伴上 | OP-8、YR-3、YR-6、YR-7、ZH-2 | 白给的变强 |
| 量级 | 借旁人的反应；用观众熟悉的物件做参照 | OP-1、YR-4、YR-7；OP-3、NR-1、NR-4 | 靠特效放大（见第四章） |
| 打斗类型 | 按任务分：亮相、切磋、教学、压制、规则、团战、死斗 | 见第四章第 2 节 | 每场都打成死斗 |
| 单场结构 | 死斗分层，每层更狠；输也可以燃；结局可以是关系或救赎 | OP-7、NR-1、FT-1、HX-2；OP-4、HX-2；OP-10、YR-5、TG-4、SS-2、FT-3 | 原作的长度，必须压缩 |
| 猜和拐弯 | 规则简单观众才会预判；预判可以被满足，也可以被假动作拐弯 | TG-2、FT-2、JJ-3 | 假动作用多了，观众不再预判 |
| 镜像 | 同一种能力换个人用，就是一面镜子 | YR-3、YR-6、KJ-6、JJ-4 | 换人太频繁 |

### 两边在哪里接上

骨架的每一步由壳定，每一步里怎么打由质感定。对照第六章的节拍表：

| 节拍（壳） | 这一步打什么（质感） |
|---|---|
| 教规则 | 亮相战或教学战，用一个画面教会能力和限制 |
| 第一回合 | 规则战或压制战：对手克制主角 |
| 压到底 | 逼选择的限制发作，代价开始显现 |
| 爆 | 用观众见过的规则翻盘，并付出代价 |
| 余波 | 打斗的结局类型（关系、送别）+ 单元留下了什么 |

仪式叠在质感上面：变身口号属于壳，变身以后能做什么、不能做什么属于质感。

### 典型错误

**把特摄的变身和计时器直接当成能力设计。** 结果是形态之间只差数值（TG-2），限制只是一个倒计时信号（TG-3），每集都在比谁更大、更快。

### 借什么、新在哪

**观众熟悉的地方尽量借，好东西直接拿来用；但全剧至少要有一个组合，让观众第一眼就说"这个没见过"。**

熟悉能让观众少花脑子，也让他猜得动（见第一章）；新意只需要集中在少数几个地方。

#### "新"的四个程度

| 程度 | 是什么 | 例子 |
|---|---|---|
| 0 照搬实例 | 换了名字，观众还是认得出出处 | 把某部作品里的某一集按原来的节奏搬过来 |
| 1 借机制，换素材 | 借的是"为什么好看"，内容是自己的 | 借"对手是受害者"（TG-4、YR-8），换成我们世界里的人和事 |
| 2 旧零件，新组合 | 每个零件都见过，这样组合没见过 | 召唤守护灵 × 三国武将（ZH-1）；前辈战队 × 钥匙（SS-3）；社畜 × 咒术（JJ-2） |
| 3 全新发明 | 观众从没见过 | 很少需要，而且要花观众的脑子 |

#### 每一层新到什么程度

| 层 | 程度 | 说明 |
|---|---|---|
| 叙事壳 | 0 到 1，最多拧一下 | 壳的价值就在熟悉。龙骑只拧了一处：骑士之间互相厮杀（KR-3） |
| 能力母题 | 2 | 组合是新的，零件可以全是借的。单个角色的能力可以借成熟的机制，只要被母题包住、长成自己的样子 |
| 每集的变量 | 1 | "新的点"是指对这部剧来说是新的，不是"世上从没有过"。经典套路可以反复用 |
| 情绪和主题 | 主题可以借，处境要是自己的 | 成长、羁绊、不平等这些主题本来就是共享的；观众代入的是处境（见第七章），处境要从我们自己的世界里长出来。迪迦和赛文的神回里，编剧常把自己的处境写进去：市川森一把屡屡被退稿的自己写成一宫（SV-3），把酒吧里遇到的外地青年写成玛雅（SV-4）；金城哲夫把对冲绳的思念写进"不得不回去"（SV-6）；太田爱从"总在回想已经消失的东西"出发写了奥比科（TG-14） |

#### 检查是不是在照搬

1. **换名测试**：角色名、招式名全换掉以后，观众还能认出"这就是某某作品里的那场"吗？能认出来，就是程度 0。
2. **借机制，不借实例**：可以借"限制要逼人做选择"，不能借"四挡用完十分钟没有霸气"。
3. **往上抽一层**：一个设计点如果来自某部作品的某一场，就问它背后的机制是什么，再用我们自己的素材重新长出来。

#### 实际的边界

照搬具体的角色、台词、剧情有版权风险。程度 0 偶尔可以用来致敬、玩梗，但不放在关键位置。

（"至少一个新组合，就能防止整部剧被说成换皮"是从 ZH-1、SS-3、JJ-2 推出来的结论，还没有直接的正例或反例验证，暂定。）

## 三、叙事壳：从特摄拿什么

### 1. 三层结构

**骨架固定，负责"一个单元怎么走"；变量每个单元换，负责"这个故事新在哪、打动人在哪"；入口每集换，负责把人留下。**

单元是故事的单位，集是播出的切法。迪迦教的是一个单元怎么讲，不是一集多长：一个单元讲几集由故事决定，可以一集讲完，也可以讲好几集（第 6 节）。

| 层 | 是否变化 | 装的是什么 | 迪迦里对应什么 |
|---|---|---|---|
| 骨架 | 固定 | 叙事流程和仪式：出现、变身、吃亏、翻盘、必杀 | 每集的公式（TG-1） |
| 变量 | 每个单元换 | 这个单元对手的**能力规则**，以及对手背后的故事 | 本集的怪兽和它的来历（TG-4、TG-5） |
| 入口 | 每集换 | 每一集的前 5 秒 | 怪兽第一次露面的画面 |

**骨架固定的是流程，不是打法。** 每个单元怎么打由对手的能力规则决定，属于变量层（见第四章）。连打法也固定，每个单元就只剩"换了一只怪兽"（TG-2、KJ-1）。

骨架的顺序（一个单元）：

1. **开头**：给一个不认识主角也看得懂的问号
2. **教规则**：这场仗靠什么打、限制是什么，用画面教，不用嘴说
3. **压**：主角吃亏，规则被逼到极限
4. **爆**：用观众已经知道的规则赢，是猜中的满足，或者合理的惊喜
5. **余波**：情绪刚放下，留下这个单元的产出，立刻抛出新问号

**每一集不管单元讲到哪，都要有三样**：开头 5 秒的钩子（第七章）、这一集自己的小爽点、结尾停在一个问号上。单元一集讲完，骨架按第六章的节拍表排进一集；跨几集时，切法见第六章"单元跨几集时"。

### 2. 对手为什么一个单元一个单元地来（暂定）

**用一条统一的规则回答"为什么每个单元都有新对手"。**

- 铠甲勇士：55 颗魔灵石和地球生命结合变成异能兽，既是来源，也是计数器，观众知道还剩多少（KJ-7）
- 空我：古朗基族在玩一场有人数、有时限的杀人游戏。反派自己的规则就是每集的倒计时，查出"他按什么规律选人"本身就是一场规则战（KR-2）

**边界**：规则太死，对手就成了流水线。每个对手还得有自己的能力规则和自己的故事。

### 3. 仪式

**变身、口号、集体亮相、招式名，给的是"猜中了"的满足，也是能传播的素材。**

- 观众提前知道"他要变身了"，等的就是这一下（TG-1）
- 口号要能被模仿："××铠甲，合体！"（KJ-2）、"来，数数你的罪孽吧"（KR-4）
- 集体亮相是确认"人齐了"的时刻（SS-4）
- 动漫里也有同样的仪式：领域展开要结手印、喊名字（JJ-4）

**边界**：
- 仪式管"什么时候来"，不管"来了能做什么"，替代不了能力设计（TG-2）

### 4. 每集的对手带来情绪

**变量层负责打动人。最有效的一种：对手本身就是受害者。**

- 怪鸟西拉是被人类的气体变成怪兽的，结局不是打倒，是送走（TG-4）
- 暗影护法附身必须得到对方同意，每次附身都是一个人的心结（KJ-5）
- 陈朵一辈子被人安排，最后选了自己的死法（YR-8）
- 蚁王最后几个小时和小麦下棋，观众同情了反派（HX-2）

情绪也可以不压在主角身上，让单元配角来扛（TG-5）。

**边界**：
- 单元配角的情绪不能比主角还重，多了主角就成了工具人
- 受害者要拍出眼泪，靠"人和对手原本的关系"，铺垫放在同一集前半段

#### 对手提一个关于人类的问题

**对手的规则可以不针对主角，而是作用在人心或人群上。打倒它不难，难的是它提出的那个问题。**

- 梅特隆星人卖掺了种子的香烟，整条街的人开始互相残杀。它问的是：人和人之间还剩多少信任（SV-1）
- 防卫军造出炸弹，炸掉了一颗星球，星兽飞来地球。怪兽本身就是军备竞赛的后果（SV-2）
- 假天使说能让死者复活，人群信了它，反把迪迦当成恶魔（TG-9）
- 花粉让全世界沉溺。迪迦烧得掉花，烧不掉人想要它的心（TG-12）
- 侬马鲁特的海底都市被摧毁以后，主角开始怀疑：人类才是侵略者（SV-5）

**问题怎么放：**
- 不替代打斗。打斗照常打，问题留到余波里再落下。落下的方式有四种：
  - 一句冷嘲的旁白（SV-1）
  - 最不同意主角的人，最后说出主角那句话（SV-2）
  - 全队都在庆祝，只有主角沉默（SV-5）
  - 留一个没被改变的人（TG-9）
- 收到一句话就能说清。SV-1 和 SV-5 的剧本都改了三稿，才从一个大议题收成"人与人失去信任""无法共存"
- 最好和主角的身份连起来。"侬马鲁特"正是主角故乡对地球人的古称（SV-5）

**边界：**
- 问题只提出来，不替观众回答。TG-9 的导演说过："不是每个人都信奥特曼。"
- 现实议题要看平台尺度。SV-2 在福岛核事故之后被取消过重播
- 前几集先别用这种写法：观众还不在乎主角，问题提出来也没人接（推论）

#### 主题从哪来、怎么收小

**主题能大能小，落点始终很小。** 问题可以问整个人类，也可以只问一个人，但交给观众的永远是一个人、一件东西：

| 集 | 主题有多大 | 落在哪 |
|---|---|---|
| TG-9 | 信仰：人宁愿相信马上能救自己的东西 | 队长的婆婆想让死去的儿子活过来 |
| TG-12 | 人类会不会选择快乐的毁灭 | 街上为一朵花打架的人；靠这朵花活下来的父女 |
| SV-1 | 人和人之间的信任 | 一包烟；安娜舅舅开的客机 |
| SV-5 | 谁才是地球原来的主人 | 一个两年前淹死的男孩，一块墓碑 |
| TG-10 | 一天的初恋 | 一枚吊坠 |
| TG-15 | 孤独 | 一首歌 |

小主题能打动所有人，是因为处境人人都有过：想家、怕被忘记、喜欢一个注定要分开的人。

**从哪挖**，按证据多少排：

1. **写的人自己的处境**：市川森一把被退稿的自己写成一宫（SV-3），把夜店里的外地女孩写成玛雅（SV-4）；金城哲夫写对冲绳的思念（SV-6）；太田爱写"总在回想已经消失的东西"（TG-14）、"失败以后也要往前走"（TG-4）；上原正三写自己年轻时创造奥特曼（TG-7）；川上英幸改写自己喜欢的妖怪传说（TG-13）
2. **观众手边的日常东西或现象**：当时一半日本人抽烟，香烟的设定"真实得可怕"（SV-1）；拿戒烟戒酒做比喻写沉溺（TG-12）
3. **全剧核心问题的一个切面**：迪迦的核心问题是"光是什么、人能不能自己成为光"，第 25、44、45 集的大主题都是它的切面（TG-9、TG-11、TG-12），大结局再把它收回来（TG-8）。所以大主题不会和整部剧打架（推论）
4. **借一部现成作品的机制**：《时光倒流七十年》（TG-10）、《银河铁道 999》（TG-12）、《阿尔法城》（SV-11）
5. **一句闲聊**（暂定，只有 1 个案例）："地球人真的是地球原来的主人吗？"（SV-5）

**挖出来以后：**
- **收成一句话的问题。** 好几集的剧本都是一稿稿收小的：SV-1 从"抽烟引发核事故"收到"人与人失去信任"；SV-7 从"批评社会"到"依赖科技"，最后收成"无法共存"；TG-12 想写"说服沉溺的人戒掉"，写不出来才改；TG-4 的故事中心从发明毒气的博士改到了死去的女孩身上
- **让对手的规则就是这个问题**：花粉就是诱惑（TG-12），种子就是不信任（SV-1），天使就是马上能得救的诱惑（TG-9），星兽就是武器的后果（SV-2）。打的就是那个问题
- **找一个人、一件东西来承载它**，主题再大也一样
- **只问不答**，见上一小节

**边界：**
- 很多集的主题从哪来，花絮里没有说，上面不是全貌
- 案例只来自迪迦和赛文两部特摄，动漫那边还没有对照

### 5. 伙伴集结和阶段高潮

**伙伴一个一个来，每来一个都是一个事件；集齐、合体、最强形态是阶段高潮。**

- **逐个登场**：铠甲勇士的五个人分好几集陆续登场（KJ-3，集数待核实）
- **新伙伴先当对手**：先打一场，再翻转关系入队（SS-2、OP-10），关系在打斗里兑现（FT-3）。第六人通常季中登场，正好是一个阶段高潮（SS-2）
- **最强形态先落在敌人手里**：帝皇侠第一次出现是被控制的向阳变的，先打一场压制战，再由五人合体夺回（KJ-4，暂定）
- **熟梗返场**：前辈、观众早就认识的人物当援军（TG-7、SS-3、ZH-1）。新剧没有前辈可借，要先在前几个单元里自己攒，这就是单元角色"返场"的用处
- **季终**：全剧积累的羁绊集中兑现，主角的最低点是"死了"（TG-8）

**边界**：每个新伙伴都走"先当敌人"就成了套路，要换着来。

### 6. 单元剧和贯穿线

像奥特曼一样，**一个单元讲完一个故事**。单元的长短由故事决定，可以一集讲完，也可以讲好几集。单元剧的剧情本身不难，难的是两件事：单元的产出不能丢，全剧要有贯穿线。

#### 单元讲完，留下什么

每个单元结束时，要有东西**留在世界里**，后面的故事能接着用。不然观众会觉得看了等于没看。

| 留下的东西 | 例子 |
|---|---|
| 角色得到的 | 新能力、新招式、新装备、一个新伙伴、一道伤 |
| 世界的变化 | 一条规则被揭开、一股势力的态度变了、多了一个能去的地方 |
| 关系的变化 | 两个人从敌对变成合作，或者结下了仇 |
| 留下的问题 | 一个没解开的线索、一个记住了主角的反派 |

**自检**：这个单元删掉，后面的剧情会不会接不上？如果删了也不影响，说明它什么都没留下。

#### 贯穿全剧的线

没有贯穿线，单元剧就是一盘散沙。贯穿线大概有三种，最好都有：

| 贯穿线 | 作用 | 奥特曼里对应什么 |
|---|---|---|
| 大问号（主线谜团） | 跨季的悬念，观众想知道答案 | 光之巨人从哪来、远古文明发生过什么 |
| 主角的长期目标或成长 | 观众陪着主角一路走 | 主角从新人变成真正的战士 |
| 越来越近的大威胁 | 每个单元都离它更近一步，最后爆发 | 最终大反派的复苏 |

**铁律：每个单元至少推进一根贯穿线**，哪怕只推一点点。挂不上贯穿线的单元，再好看也先放着。

#### 两三集的单元怎么断

每集结尾停在"压"的最低点，详见第六章"单元跨几集时"。

#### 秘密分批揭开（暂定）

迪迦的身份先让队长知道，再让丽娜知道，最后才让全队知道，每一次都是一个情绪点（TG-6）。

#### 两集一个案子（暂定）

假面骑士 W 每两集讲完一个案子：第一集查清谜面，第二集给出解法（KR-4）。和"每集结尾停在压的位置"是同一个结构。

### 7. 不该从特摄学的

| 不学 | 为什么 | 证据 |
|---|---|---|
| 形态之间只差数值 | 打起来只能比谁更大、更快 | TG-2、KJ-1 |
| 把计时器当成限制的全部 | 它只是节拍信号，不逼人做选择 | TG-3 |
| 每集用同一招必杀收尾 | 观众记不住任何一场仗 | TG-1（推论） |
| 第二场仗只是换个尺度重打一遍 | 没有新东西就是重复 | SS-1（推论） |

## 四、打斗质感：从动漫拿什么

AI 把特效的成本降到接近零以后，价值转到了两层：**逻辑**（能力规则、克制、解法）和**情绪**（为什么而打，打到一半想到了什么）。（旧版保留，待补证据）

### 1. 能力规则怎么设计

| 规则 | 说明 | 证据 |
|---|---|---|
| 一句话说清，规则里写着人物 | 路飞扛住石化靠性格；张灵玉的阴雷来自心结；七海的"加班"就是社畜本身 | OP-10、YR-2、JJ-2、ZH-5 |
| 限制要逼人做选择 | 四挡后十分钟没霸气，得有人拖住对手；龙骑不打就被契约兽吃；酷拉皮卡的锁链只能对仇人用 | OP-8、KR-3、HX-1 |
| 代价要看得见，落点可以不同 | 身体（八门撕裂）、时间（十分钟）、剧情（被除名、被禁足）、伙伴（于禁魂飞魄散） | NR-1、OP-8、YR-3、YR-7、ZH-2 |
| 形态之间差在规则或条件上 | 空我要先拿到对应物件；艾露莎每套铠甲各克一种对手 | KR-1、FT-2；反例 TG-2、KJ-1 |
| 熟悉的东西直接做成能力 | 三国武将，观众自带对他们战力的预期 | ZH-1、SS-3 |
| 同一种能力换人用，就是一面镜子 | 同样的拘灵遣将正邪对照；同样的奇门打层次差 | YR-3、YR-6、KJ-6、JJ-4 |
| 交代规则本身做成剧情动作（暂定） | 爆弹魔必须把规则讲给你听，能力才生效 | HX-3、JJ-2 |

打斗的硬规则：

1. **能力要有边界**：观众知道它不能做什么，比知道它能做什么更重要
2. **限制要逼人做选择**，不是扣血条（OP-8、KR-3、HX-1）
3. **对手要克制主角**：不克制就没有"压"（OP-2、OP-5、NR-1）
4. **解法必须用观众见过的东西**：临时冒出新能力赢了，等于作弊（OP-2、NR-2、YR-4）
5. **先吃亏再爆发**（OP-2、NR-5、HX-2）

### 2. 打斗类型：按这场仗的任务分

**每场仗的任务不同，打法也不同。不要每场都打成死斗。**

| 类型 | 任务 | 好看靠什么 | 禁忌 | 证据 |
|---|---|---|---|---|
| 亮相战 | 让观众记住这个人能做什么、有多强 | 快；对手分量先立住；一个画面讲清规则。可兼做教学战（暂定）；可以亮打法风格，不一定亮强度（暂定） | 压、拉扯、拖 | OP-1、YR-7、JJ-1、YR-1 |
| 切磋战 | 比较强弱、推动关系、制造"谁更强"的话题 | 不分胜负，重点是关系变化；用一个物件当裁判 | 打出生死，或一方被碾压 | OP-9、YR-5、NR-4 |
| 教学战 | 学会一个东西，后面兑现 | 观众和角色一起"懂了"；表面规则可以是假的 | 用台词讲课；学会了不兑现 | NR-3、SS-3、JJ-1、JJ-3 |
| 压制战 | 立住对手量级，给主角一个目标 | 让观众看清差在哪；留下一笔"欠账"（誓言、前辈留下的解法）。两种用法：立个人目标，或立世界刻度（暂定） | 输得窝囊；输完没有任何期待 | OP-4、OP-2、NR-5；OP-5 |
| 规则战 | 把"猜 → 验证"做足 | 先看穿规则的前提，再用观众见过的东西破掉 | 规则没提前交代；解法临时冒出来 | OP-2、YR-4、NR-2、NR-5、HX-3 |
| 团战 | 展示每个人的位置，让组合技成立 | 分工清楚：一个挡一个打，一个控位置一个输出 | 所有人同时放大招 | OP-6、FT-3、JJ-3 |
| 死斗 | 单元或整季的高潮 | 分层，每层更狠；代价看得见；最后一层可以是情绪反转 | 每集都这样打 | OP-7、NR-1、FT-1、HX-2 |

**结局也分类型**，不只有输赢：

| 结局 | 例子 |
|---|---|
| 打赢 | 大多数 |
| 打输但燃 | 押上了一切或守住了什么（OP-4、NR-1、HX-2） |
| 打平或被打断 | 切磋战常用（NR-4、OP-9） |
| 打出关系 | 敌人变伙伴，或伙伴之间出现裂缝（OP-10、YR-5、SS-2、FT-3） |
| 送别、救赎 | 对手是受害者（TG-4、YR-8） |

**一个单元里的搭配**：开头放亮相战，中段放压制战或规则战，后段放死斗或规则战的破局。"先小打，再大打"就体现在这个搭配里；超级战队的"地面战 + 巨大化"是同一个意思，但第二场必须有新东西（SS-1，暂定）。

#### 什么时候可以让打斗退后

**情绪单元：把打斗压到最短，让一种稀有的情绪当这一集的爆点。** 迪迦、赛文口碑最高的那两档里，有不少集不是靠打斗出名的（TG-10、TG-13、TG-14、TG-15、SV-1、SV-4）。迪迦第 29 集的战斗不到一分钟，照样是神回（TG-15）。

观众要的从来不是打斗本身，而是情绪。打斗是最常用的交付办法，但不是唯一的。普通的怪兽战给的是"爽"，看过几十场以后越来越薄；一种整部剧里很少出现的情绪，比如孤独、送别，反而更值钱、更容易被记住。

它成立有四个前提，缺一个就不要这样做：

| 前提 | 为什么 | 证据 |
|---|---|---|
| 壳还在 | 对手、变身、必杀一个不少，只是压短。观众本来就确信主角会赢，所以短不会让人觉得被骗；憋了一集的情绪一下子释放出来，爽是被压缩了，并没有消失 | TG-15、TG-10、SV-1 |
| 主角换成观众已经在乎的人 | 情绪集常常让一个核心配角当这一集的主角，靠的是前面很多集攒下来的感情；视角只跟着这一个人走 | TG-15（新城）、TG-10（矢住）。暂定，还缺一部作品 |
| 情绪线足够强，一条到底 | 打斗退后，要有更强的东西顶上来；不然打斗少就只是"水" | TG-10、TG-15、SV-1 |
| 稀少 | 每集都这样拍，"每集都爽"的约定就破了 | 推论：两部作品的口碑高位里，情绪集和打斗集交替出现 |

**放在哪里**：试播集和前几集不要这样做。那时观众还不认识任何人，只能先靠打斗和规则留住他。核心角色立住以后，隔一段放一集。

### 3. 单场打斗的内部结构

**量级怎么体现**：
- 借旁人的反应：科比的恐惧、两个高手下场救人、没人敢再上前（OP-1、YR-4、YR-7）
- 用观众熟悉的物件做参照：钢铁、负重砸出的坑、被打穿的水塔（OP-3、NR-1、NR-4）
- 基础招打出天花板（暂定）：老天师的金光咒（YR-7）
- 对方根本没认真（暂定）：鹰眼只拿一把小刀（OP-4）

**分层**：每一层都比上一层更狠。一挡到三挡，八门一门门往上开，百式观音到零之掌再到蔷薇（OP-7、NR-1、HX-2）。

**猜和拐弯**：规则简单观众才会预判。预判可以被满足（"该换空中型了"），也可以被假动作拐弯（东堂拍了手却不换）（TG-2、FT-2、JJ-3）。

**节奏**：别每场都炸到最大，全都很大观众就感觉不到大；大招前安静一拍。（旧版保留）

### 4. 情绪怎么进入打斗

| 方式 | 例子 | 证据 |
|---|---|---|
| 从能力规则里长出来 | 心结是能力的锁；誓约写着执念；附身必须本人同意 | YR-2、HX-1、KJ-5、ZH-5 |
| 守住了什么 | 背上的伤是剑士的耻辱；替敌人挡住伤疤 | OP-4、OP-10、NR-1 |
| 一件具体的物件或动作（暂定） | 阿斯玛的打火机；妖精尾巴的手势 | NR-2、FT-4 |
| 开打之前先蓄力（暂定） | 罗宾喊出"我想活下去"、烧掉世界政府的旗，然后分头去打 | OP-6 |
| 放在打完以后的余波里（暂定） | 被逐出公会后游行上的手势；西拉被送进宇宙 | FT-4、TG-4 |

### 5. 变强方式

每个角色有自己的变强方式，不是给整部戏选一种。

| 方式 | 爽在哪 | 硬要求 | 证据 |
|---|---|---|---|
| A 换形态、换装备 | 仪式感："来了来了！" | 形态之间差在规则或条件上；新形态先在小场面教会规则（暂定） | KR-1、FT-2；OP-7 |
| B 用法升级 | 聪明感："原来还能这样用！" | 新用法必须从观众见过的规则里推出来：沙子沾水会结块、橡胶能当泵 | OP-2、OP-7、JJ-3 |
| C 情绪、羁绊爆发 | 感动："就是为了这个！" | 情绪写在能力里（心结、誓约），或是全剧积累的集中兑现 | YR-2、HX-4、TG-8、KJ-4 |

**三种都要冒险或付代价**：白给的变强不燃（OP-3、OP-8、FT-1、HX-4）。三种也都要提前铺垫，否则就像作弊。

每个角色有自己的变强方式，好处是角色更好分辨、不容易腻、能组合、故事决定谁上。（旧版保留，待补证据）

### 6. 动漫不能照搬的

| 不照搬 | 怎么改 | 证据 |
|---|---|---|
| 原作一场仗打好几集、规则层层叠加 | 一场仗可以跨集，但每集只立一条关键规则、一个关键画面 | OP-2、OP-6、OP-8、YR-8、HX-2、KJ-4 |
| 要靠术语讲清的规则（暂定） | 换成一眼看懂的画面 | YR-3、JJ-4 |
| 一边打一边讲解（暂定） | 只在碾压时成立，势均力敌时不能停下来讲 | JJ-1 |
| 靠说服结束死斗（暂定） | 说服要有前面的铺垫，比如两人相似的经历 | NR-5 |

## 五、角色

多角色不分正派、反派、配角，只要能带来新的点就有效。每个新角色就是一个新变量，公式不变也不会腻。战力有高低，观众就会排名次、在评论区吵"谁能打过谁"：索隆和山治永远分不出胜负（OP-9），鸣人和佐助在水塔上留下的洞（NR-4），镇魂街用"地狱道"给每个人标等级（ZH-1）。

### 1. 两层角色

| 层 | 是谁 | 怎么出场 | 作用 |
|---|---|---|---|
| 核心层（常驻） | 主角和核心伙伴（铠甲勇士的几位铠甲） | 前期就出来，**先露面、后展开** | 属于骨架，观众长期投入感情 |
| 单元层（这个故事） | 怪兽、对手、来支援的人、本篇配角 | 跟着一个故事出现 | 属于变量，带来新的点 |

**出场和展开是两件事：先露面，后展开。** 曹焱兵初登场只召唤了许褚一个守护灵（ZH-1）；铠甲勇士的五个人分好几集陆续登场（KJ-3，集数待核实）。露面但不解释，等于给观众一个承诺：后面有他的戏。（暂定：两个例子都是"逐个登场"，还缺"只露面不解释"的直接案例）

#### 单元角色怎么在一个单元里立住

单元角色只有一个单元的时间，观众又不认识他。迪迦、赛文的神回用了四个办法：

**① 只给一个"想要"，而且想要的是人或地方，不是力量。** 一句话说得清，普通人也有过。
- 西拉想替死去的小主人毁掉毒气（TG-4）
- 奥比科不想被忘记（TG-14）
- 百合想回家，家却变成了马路（TG-10）
- 一宫想让自己的才能被承认（SV-3）
- 玛雅想让母星来接她回家（SV-4）

**② 出场先给一个动作，把"想要"和"得不到"一起演出来，不靠介绍。**
- 麻美死前先把鹦鹉放走（TG-4）
- 奥比科看见村子恢复了旧日的样子，高兴得跳起来（TG-14）
- 婆婆信了"天使"，因为她想让儿子活过来（TG-9）
- 佩加萨人的影子求人别报警，说自己只想歇一会儿（SV-7）
- 玛雅在天文馆里，对着假的星空给家发信号（SV-4）

**③ 挂在一个核心角色身上，借观众已有的感情。** 单元角色的分量，一半是借来的：观众跟了这个核心角色很多集，他在乎谁，观众就跟着在乎。最好让这个核心角色有一段和单元角色相似的处境。

| 单元角色 | 挂在谁身上 | 怎么连 | 出处 |
|---|---|---|---|
| 百合 | 矢住 | 他童年见过的老婆婆就是她 | TG-10 |
| 玛雅的哥哥 | 新城 | 附在新城身上；新城自己也有个妹妹 | TG-15 |
| 婆婆和友树 | 居间惠 | 她的家人；她自己愧疚没当好妈妈 | TG-9 |
| 小野田 | 宗方 | 宗方的老朋友 | TG-5 |
| 一宫 | 曾我 | 曾我未婚妻的老朋友 | SV-3 |
| 玛雅 | 弹 | 两个人都是独自留在地球的外星人 | SV-4 |

这样一来，核心角色就能轮流当一集的情绪中心：迪迦几乎每个队员都有一集"自己的单元"。

**④ 不会说话的角色，靠声音、动作和伤来演（暂定）。**
- 加迪的哭声用狗叫改成，它只出场一集，观众也会为它哭（TG-11）
- 奥比科的打斗动作设计得像小孩打闹（TG-14）
- 西拉吐着血还往前冲，伤了的左眼在结尾复原（TG-4）

怪兽的性格很多是在拍摄现场做出来的，写剧本时要给现场留出位置。

**边界：**
- 不是每一集都这样。迪迦 52 集里很多集的角色很薄，上面的案例都是口碑前两档的集
- 挂靠的那个核心角色必须已经立住，所以前几集做不到（推论）

### 2. 单元角色讲完以后去哪

| 去向 | 效果 |
|---|---|
| 退场 | 故事干净，不给观众加负担 |
| 返场 | 自己造出来的"熟悉的梗"，一出场就自带情绪，就像前辈奥特曼回来支援 |
| 埋伏笔 | 跨集的问号，让观众惦记 |

**返场是自己造出来的熟梗。** 迪迦借初代奥特曼，海贼战队借 34 支前辈战队，靠的都是观众已有的感情（TG-7、SS-3）。新剧没有前辈可借，前几个单元要有意识地留几个能返场的角色。

**退场也要给一个去处。** "打倒了"不是去处。角色是在结局里被完成的，有了去处，观众才会记住他：
- 西拉化成凤凰，麻美坐在它背上一起离开（TG-4）
- 奥比科看着村子，自己迎上迪迦的手刀（TG-14）
- 百合回到自己的时代，活过了一生（TG-10）
- 一宫"也许还活着，在宇宙某处望着地球"（SV-3）
- 最后一个佩加萨人只能在地球的阴影里流浪（SV-7）

这一步最容易丢掉。

### 3. 核心角色怎么设计

| 要求 | 说明 | 证据 |
|---|---|---|
| 能力规则里写着人物 | 看他的能力就知道他是什么人 | OP-10、YR-2、JJ-2、ZH-5 |
| 一句话定位，但要差在规则上 | "最快""防御最强"这种数值型定位好排名，打起来却同质；要像艾露莎的铠甲、空我的形态那样各克一种对手 | KJ-1（反例）；FT-2、KR-1 |
| 每个人有自己的变强方式 | 见第四章第 5 节 | |
| 至少有一对能组合 | 分工清楚：一个挡一个打，一个控位置一个输出 | FT-3、JJ-3、OP-6 |
| 关系写进能力（暂定） | 两人合成一个骑士，吵架就打不好；守护灵要认主，关系一变战力就变 | KR-4、ZH-3 |
| 可以有一个镜像角色 | 同一种能力换个人用，就是一面镜子 | YR-6、KJ-6、YR-3 |
| 颜值可以直接做成能力规则（暂定） | 女帝的美貌就是武器，满场石像是证明 | OP-10 |

### 4. 对手怎么设计

| 要求 | 说明 | 证据 |
|---|---|---|
| 克制主角 | 不克制就没有"压" | OP-2、OP-5、NR-1 |
| 有自己非赢不可的理由 | 龙骑的每个骑士都有愿望；陈朵想自己做一次选择 | KR-3、YR-8 |
| 可以是受害者，或在结局被同情 | 西拉、被附身的人、蚁王 | TG-4、KJ-5、HX-2 |
| 新伙伴可以先当对手 | 先打一场，再翻转关系 | SS-2、OP-10、FT-3 |
| 反例：刚立起来的反派别被别人轻松打掉（暂定） | 王并刚把风星潼打到差点死，转头被张灵玉轻松击败，量级白费 | YR-6 |

### 5. 五种"新的点"

| 新的点 | 例子 |
|---|---|
| 新能力 | 每集的对手（TG-1、KJ-7） |
| 新规则 | 原来四挡用完十分钟用不了霸气（OP-8） |
| 新关系 | 女帝爱上路飞；第六人入队（OP-10、SS-2） |
| 新情绪 | 怪兽是受害者（TG-4、YR-8） |
| 新信息 | 迪迦的身份被一层层揭开（TG-6） |

#### 新角色进场前的三问

1. 他带来了哪一种新的点？一种都没有就别加。
2. 他和核心层是什么关系？克制、帮忙，还是像一面镜子？单元角色要挂在哪个核心角色身上？
3. 故事讲完他去哪？退场、返场，还是埋伏笔？

### 6. 支援的位置

**支援几乎总出现在主角被压到最低的那一刻。** 它是"爆"的放大器，来支援的人还会顺手展示一个新能力：

- 初代奥特曼在迪迦能量被夺走后赶来（TG-7）
- 加吉尔在拉克萨斯要了结纳兹时冲上去挡招（FT-3）
- 迪迦变成石像后人类出手（TG-8）
- 四挡的十分钟空窗里，角斗士、萨博、罗轮流帮路飞拖住对手（OP-8）

**支援也可以来自普通人。** 这时候不展示新能力，展示的是"人类不是旁观者"：

- 居间惠通过通讯向市民求助，人们开着车、举着手电赶来，照亮迪迦（TG-9）
- 有人自己动手，毁掉身边的小花（TG-12）
- 一个无名的工程师独自修好了反应堆（SV-9）
- 黎明时曾我一枪命中，赛文复活（SV-10）
- 知道真相的队员们一起出击（SV-6）；全世界的孩子变成了光（TG-8）

**用法：**
- 普通人出的那份力要提前铺好。半块宝石在前编开头就出现了（SV-10）
- 出力的最好就是被这一集的问题影响过的那群人，这样翻盘本身就是对问题的回答。TG-9 里先被假天使说动的是市民，最后举着灯赶来的也是市民
- 普通人把主角托起来，最后一击还是交给主角。工程师修好反应堆以后，斩杀冈达的仍是赛文（SV-9）

### 7. 核心角色卡

| 项 | 要回答的问题 |
|---|---|
| 视觉标签 | 一眼能认出来的样子：颜值，再加一个反常的点 |
| 能力 | 一句话说清：能做什么，**不能**做什么 |
| 能力里写着什么 | 这个能力反映了他的哪种性格、心结或身份 |
| 限制逼他做什么选择 | 不是扣血条，而是"用了就会……" |
| 变强方式 | A、B、C，或几种组合；代价是什么 |
| 带来的情绪或话题 | 他的故事让观众有什么感受 |
| 怎么出场 | 先露面的方式，什么时候展开 |
| 和其他人的关系 | 克制、互补、组合、镜像 |
| 和谁组合、怎么分工 | 两人一起打时各自负责什么 |
| 内心声音（VO） | 有没有 VO，什么语气。不是每个角色都需要，没有 VO 的角色反而更神秘 |

## 六、单集：节拍与高光倒推

单集时长**不限**，由剧情决定。一集多长，取决于有几个值得看的高光：只有两个高光，硬撑长了就会水。

### 高光倒推法（写一集的主要方法）

先定终点，再倒着修路。观众要的是一个情绪爆发点和几个名场面，先保证它们，再反推剧情。

1. **定本集唯一的情绪爆发点**：什么情绪（燃、哭、爽、心疼）、什么画面。放在全集的 **70% 到 85%**，后面留余波和钩子。
2. **定名场面**：大约每1.5到2分钟一个。类型有：打斗高光、亮相、反转或打脸、金句、笑点、情绪。**最好能单独切成15到30秒的片段**，没看过前面也能看懂，切片会被二次传播。**名场面也可以不是打斗**，比如：
   - 隔着矮桌的对话：外星人和弹坐在榻榻米上（SV-1）
   - 坦白：弹对安娜说出自己是赛文（SV-6）
   - 拥抱：新城假扮哥哥（TG-15）
   - 抱住死去的伙伴：迪迦抱住加迪（TG-11）

   这类名场面靠反差和情绪撑起来，前提是观众已经在乎这个人，所以铺垫要比打斗高光更早开始。
3. **每个高光倒推三个问题**：观众要先知道什么（规则）？要先被压到什么程度？要先在乎什么？答案就是高光之前必须写的铺垫。
4. **排顺序**：由小到大，最大的爆发点放在后段。
5. **填连接段**：只放第3步要求的铺垫，同时守"每10到15秒变一次"。
6. **最后定前5秒**：钩子最好指向某个高光。可以先放高光片段再切回"三小时前"，但用多了会腻。

两个坑：
- **为了高光而高光**：连接段的因果必须过得去，人物改主意要有观众看得见的理由。
- **高光太密就没有高光**：情绪爆发点前面最好有一段相对安静的戏。

### 高潮台词怎么写

**台词是扳机，不是子弹。** 迪迦里让人落泪的台词，单拿出来几乎都是日常话：喊一个名字、说一句"笑一笑"、问一句"还会再见吧"。重量来自前面攒下的东西：观众已经知道代价、身份或结局（TG-16）。所以写高潮台词之前，先问一句：观众这时候知道什么，说话的人不知道什么？

**四种做法：**

1. **替别人作证。** 不说"我"，说"他是……""他不是……"。一个人站出来替另一个人说话，尤其是替被当成怪物、被误解的人说话。
   - "我跟你们说，他不是个坏孩子"（第 17 集）
   - "德班是我们剧组不可缺少的重要成员"（第 21 集）
   - "你永远是弹"（SV-6）
   - 弗利德说出拉克萨斯继承了珍惜同伴的心（FT-3）
2. **拒绝放弃的许可。** 一个关心主角的人说"你可以不去"，或者主角要救的人说"我想死"，主角偏不接受。道理是对的，人偏不听。
   - "你没有义务去面对一个根本赢不了的敌人"，"根本赢不了，我听不懂"（第 51 集）
   - "说你想活下去！"（OP-6）
   - "你就像我的兄弟"（NR-4）
3. **观众知道，说话的人不知道。** 同一句话，说的人觉得平常，听的人知道它的分量。
   - "我们还会再见的，对不对"（第 29 集）
   - "笑一笑好不好啊"（第 36 集）
   - 玛雅发信号求母星来接她回家（SV-4）
4. **主题句由付出代价的人用大白话说出来。** 而且只放在最后。
   - 刚失去花的努克说"努力地活完短短的一生"（TG-12）
   - 最不同意主角的桐山，说出了主角那句话（SV-2）
   - 全剧的核心问题问了五十集，大结局用一句"每一个人都能凭自己的力量变成光"来回答（TG-8）

**还可以试的（暂定，证据只来自迪迦）：**
- 让最不配的人说出最深的话，或者只是转述：小偷转述武士"勇士经常是孤独的"（第 16 集）
- 大动机底下藏一个小孩式的害怕：为了变强注射外星细胞的人，说出"如果我不是第一名，就没有人会爱我"（第 11 集）
- 句子不要写得太工整，允许重复、断掉："永远永远永远""我不能……我不能啊"

**边界：**
- 借的是做法，不是句子
- 主题大白话放在前几集就是说教
- 迪迦的 20 句名台词里至少 12 句出自单元角色或配角。高潮台词不一定要给主角

### 节拍表

节拍表是一个单元的节拍顺序。单元一集讲完时，按这个比例排进一集；跨几集时，节拍分到几集里，切法见下一节。比例大致固定，时长越长，每个节拍里能多放回合。10分钟的集可以有两个"第一回合"或两次"压"。

| 节拍 | 2分钟版 | 5分钟版 | 观众此刻的心理 | 必须交付的东西 |
|---|---|---|---|---|
| ① 钩子 | 0–5秒 | 0–5秒 | 随时划走 | 一个问号 |
| ② 钩子升级 | 5–15秒 | 5–30秒 | 留下了，还没投入 | 问号变大，**不回答**；主角的第一个动作 |
| ③ 教规则 | 15–35秒 | 30秒–1分30 | 好奇"他能干嘛" | 一次小交锋，用画面教会能力和限制 |
| ④ 第一回合 | 35–60秒 | 1分30–2分30 | 开始猜 | 本单元的新的点落地，对手克制主角（规则战或压制战） |
| ⑤ 压到底 | 60–80秒 | 2分30–3分30 | 担心、憋着 | 最低点；情绪注入 |
| ⑥ 爆 | 80–105秒 | 3分30–4分30 | 期待兑现 | 用已知规则赢；定格加VO补设定放在这里 |
| ⑦ 余波 + 钩子 | 105–120秒 | 4分30–5分 | 情绪刚放下 | 单元留下了什么 + 新问号 |

- ②最容易被忽略：钩子留住了人，马上开始解释，观众就泄气了。
- ⑤和⑥之间留一拍安静。
- 设定只在⑥和⑦里补。
- 每个节拍放哪种类型的仗，见第二章"两边在哪里接上"。

### 单元跨几集时

单元是故事的单位，集只是切法。一个单元切成几集，每一集仍要是完整的一集：

- 每集结尾停在"压"的位置：第1集停在"原来他克制我"，第2集停在最低点。
- **单元没讲完，单集也要有自己的小爽点**：一个小胜利、一次支援、一个漂亮的招。
- 后面几集的开头不用回顾，直接从动作里接上。
- 每一集照样要过第七章的开头 5 秒和本章的流失检查点，不因为是单元的中段就放松。

### 每10到15秒必须变一次

观众每一段都可能走。每10到15秒必须出现一样新东西：新信息、局势变化、动作升级、笑点或反差、新角色露面。

**检查方法**：剧本按15秒切格，每格写一个词说明"新在哪"。写不出来的格子就是流失点。

### 流失检查点

| 时间点 | 观众在想什么 | 怎么留住 |
|---|---|---|
| 3秒 | 这是什么？ | 第一帧就有问号 |
| 5秒 | 值得看吗？ | 问号升级 |
| 15秒 | 我看得懂吗？ | 主角和规则开始清楚 |
| 30秒 | 接下来会怎样？ | 观众开始猜 |
| 中点 | 还会有新东西吗？ | 第一回合的反转，或新角色 |
| 结尾前10秒 | 结束了，划走吧 | 结尾钩子提前到，不等片尾字幕 |

### 季的前三集

| 集 | 特殊任务 |
|---|---|
| 第1集 | 骨架完整跑一遍（第一个单元跨集时，至少跑到一次小胜利）；主角立住；大问号露一个角 |
| 第2集 | 证明公式能重复，但有变化；第二个核心角色登场或露面 |
| 第3集 | 贯穿线第一次推进；观众意识到背后有更大的事 |

## 七、开头5秒

开头观众谁都不认识，没法指望他在乎主角，只能靠不需要认识角色的东西留人。观众代入的是**处境**，不是人：他不会想"这个人好可怜"，会想"要是我在这儿……"。

| 钩子类型 | 为什么有效 | 举例 |
|---|---|---|
| 不可能的画面 | 心里立刻冒出"这是怎么回事" | 地铁车厢泡在水里，乘客还在刷手机 |
| 马上要出事 | 本能地想知道结果 | 枪口顶着后脑勺 |
| 熟悉的场面出了错 | 看懂只需零秒，反常又带来好奇 | 安检员拔一个人背上的剑，把人拎离了地 |
| 颜值 | 本能的停留理由，AI制作下成本接近零 | 女性主角开局 |

**颜值管得住前5秒，管不住第30秒。** 人人都有颜值以后，它就只是入场门槛，不再是差异。更有效的是**颜值 + 反常**：一个好看的女孩在做一件不可能的事，两个钩子叠在一起。颜值还可以直接做成能力规则，比如女帝满场的石像（OP-10，暂定）。

### 自检

- 关掉声音只看第一帧，能不能一句话说出"哪里不对劲"？
- 第一帧不能是黑屏，也不能是交代世界的空镜头（俯瞰城市之类）。
- 5秒内只做一件事，不需要知道是谁、为什么。

## 八、世界观：分散投放

**世界观不一口气讲完，拆开分散到很多地方，趁观众在看别的东西时补进去。** 观众最不想看交代设定，但正在享受画面、正在看打斗、正在笑的时候，他会顺手把信息收下，不觉得自己在听讲。

### 投放渠道

| 渠道 | 怎么用 | 适合补什么 |
|---|---|---|
| VO + 定格或升格 | 打在一个很高级的主角画面上，画面在给奖励，VO顺便补信息 | 主角的身份、来历、实力等级 |
| 对白 | 角色为了自己的目的说出来，不是为了告诉观众 | 规则、势力关系 |
| 路人讨论 | 旁观者的议论和反应 | 一个人有多强、多有名、多危险（借旁人的反应立量级：OP-1、YR-4、YR-7） |
| 画面里的物件 | 新闻、海报、徽章、通缉令、屏幕上的字 | 世界的背景、组织的存在 |
| 打斗中 | 能力规则在打的时候露出来 | 能力体系、克制关系（规则必须讲给对手听才生效，就是在打斗中交代规则：HX-3，暂定） |

### 原则

- **设定搭在奖励上**：观众得到爽点、美感、笑点的那一刻，最愿意接收信息。观众抗拒的不是信息，是"被讲课"的感觉。
- **一次只给一两条**，只给当下这场戏需要的。
- **先给现象，晚给解释**：先让观众看到"不对劲"，解释可以等很多集。
- **留一部分给观众自己拼**：画面角落的物件、一句没人接的台词，注意到的人会去评论区讨论"你们发现没有"。
- **设定集写全，剧本里只放碎片**：信息散在几十集里，作者必须知道全貌，否则前后矛盾，观众会说"吃书"。

### 两类世界观信息，处理方法相反

| 类型 | 例子 | 怎么给 |
|---|---|---|
| 规则类：不知道就看不懂这场仗 | 能力怎么用、有什么限制、谁克谁 | **早给、给清楚**，在需要的那一刻给 |
| 秘密类：不知道也能看，知道了更想看 | 世界的来历、组织的真面目、主角的身世 | **晚给、给一半**，当奖励一层一层放 |

世界观的一半是说明书，另一半是悬念。秘密类的世界观，本身就是第三章第 6 小节的"大问号"贯穿线。

### 信息差：这条信息先让谁知道

同一条信息，先让谁知道，带来的情绪完全不同。没有固定选法，按剧情需要来切换，一集里也可以切好几次。

| 状态 | 观众的体验 | 什么时候用 |
|---|---|---|
| 观众 < 角色 | 好奇："他知道什么？" | 神秘角色登场、埋悬念 |
| 观众 = 角色 | 一起发现、一起被惊到 | 主角探索新东西、揭开秘密 |
| 观众 > 角色 | 期待或担心："快了快了！""别进去！" | 扮猪吃老虎的打脸、反派布局、危险逼近；主角的身份被分批揭开（TG-6） |

希区柯克的炸弹：桌下有颗炸弹，观众不知道，爆炸只是几秒的惊吓；观众知道而角色不知道，同一段闲聊就变成几分钟的紧张。

"观众 > 角色"不和"猜 → 验证"冲突，它是另一种期待：观众猜的不是"会怎样"，而是"**什么时候**"和"**他们会是什么表情**"。

### 主角能力：已知部分清楚，上限藏着

- **已知部分要清楚**：观众能猜，打斗才有逻辑。
- **上限藏起来**：留给成长，也可以藏秘密。
- **新的一层是延伸，不是推翻**：海贼王的二挡还是橡胶，只是用法变了；突然会喷火就是作弊。二挡、三挡都是从"橡胶"推出来的（OP-7）。
- **可以和信息差叠用**：主角失控一次，观众看见了，主角自己不记得。从此每次主角被压到底，观众都会想"是不是要出来了"。

### VO 的用法

VO 是角色属性，有的角色有，有的没有，语气因人而异（写进角色卡）。

- **VO 和画面要有反差，不能重复。** 画面说"他很强"，VO 说"我很普通"；画面说"很危险"，VO 吐槽"今天又不能准时下班了"。
- **自问不答**：角色替观众问出心里的问题，观众就和他站到一起。在观众还不认识他的时候，这是最快建立关系的办法。懂行的人都觉得奇怪，还会抬高危险的量级。
- **VO 只说画面说不了的**：画面已经表现出"他很强"，VO 就别再说一遍。
- **时机和长度**：不放在前5秒；放在钩子立住以后、动作正在高潮时。一两句就够，再长动作就停了。
- **躲开自我介绍的套路**："我叫XX，是一个……"观众听太多了。可以只说状态不说名字，话说一半被动作打断，或者刚说完就被打脸。
- **说话人是谁**：全知旁白最省事，但最像讲课；角色自己说最有个性；另一个角色来说（比如对手说"那个人就是……"），信息和态度一起给。
