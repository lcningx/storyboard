# 案例拆解

> 《短剧爆款剧本框架》的证据库。框架正文里的每条结论都引用这里的案例编号，不在正文里展开。
> 2026-11-01 起建立，一部作品一部作品往上加。

## 怎么用

### 证据标准

1. 每条结论至少 3 个案例，至少来自 2 部作品。
2. 每条结论都写适用边界或反例：什么情况下不成立、会用坏。
3. 分清"观察"和"推论"：作品里发生了什么是观察，我们因此该怎么做是推论。
4. 事实要核实。查到可靠来源的不标；来源不可靠、有冲突或是推论的，标 **⚠️待核实**。

### 怎么建档

**先弄懂它想让人感到什么，再拆它怎么做到的。** 手法是为情绪服务的；只拆手法、不说情绪，就会把一集好故事拆成一堆技巧（2026-11-01 用户指出的问题）。

建一张卡按这个顺序走：

1. **先找口碑**：至少两份来源都说它好，才算值得拆。记下大家说好在哪
2. **读全剧情和花絮**：剧情按场面顺序读完；花絮里找编剧、导演说过的话，尤其是"想写什么""为什么这样改"
3. **回答三个问题**，答不出来不往下拆：
   - 观众看完带走的是什么情绪？
   - 它想说的那句话是什么？
   - 谁变了，怎么变的？
4. **按情绪的层次拆手法**：先在乎、再被压、最后落下来，每一层下面写它用了哪几招。不按技巧分类排
5. **对照高光倒推**：观众要先在乎什么、先知道什么、先被压到多低，这一集分别怎么答
6. **写清它成立的前提**：在什么条件下这一招才管用，换个位置会不会失效
7. **最后才写能借、不能借**
8. 没亲眼看过的，镜头、配乐、台词说不准的地方标 ⚠️待核实；自己的推导标"推测"

### 卡片字段

卡分两种。**单元卡**拆一整集或一个单元，**打斗卡**拆一场仗。

**单元卡**

| 字段 | 写什么 |
|---|---|
| 故事 | 按场面顺序，把发生了什么说清楚 |
| 情绪和想表达的 | 三个问题的答案：带走什么情绪、想说的那句话、谁变了 |
| 怎么交给观众 | 按情绪层次排，每层写用了哪几招 |
| 对照高光倒推 | 先在乎什么、先知道什么、先被压到多低；爆点是什么 |
| 为什么成立 | 前提和适用边界 |
| 能借 | 我们能拿走的做法 |
| 不能借 | 照搬会出问题的地方，以及短剧要怎么改 |

**打斗卡**

和单元卡同一个顺序，多一个"类型"。规则、量级、代价、升级不再单列，放进"怎么交给观众"对应的那一层里。

| 字段 | 写什么 |
|---|---|
| 类型 | 这场仗的任务：亮相、切磋、教学、突破、压制、规则、团战、死斗、关系反转……可以组合 |
| 经过 | 按场面顺序，把这场仗怎么打的说清楚 |
| 情绪和这场仗想说的 | 带走什么情绪；这场仗证明了什么；谁变了、关系怎么变 |
| 怎么交给观众 | 按情绪层次排；能力规则、量级（观众靠什么感觉到强）、代价、每次升级靠什么，都放进对应的层 |
| 对照高光倒推 | 先在乎什么、先知道什么、先被压到多低；爆点是什么 |
| 为什么成立 | 前提和适用边界 |
| 能借 | 我们能拿走的做法 |
| 不能借 | 照搬会出问题的地方，以及短剧要怎么改 |

## 海贼王（OP）

### OP-1 路飞 vs 阿尔比达（漫画第 2 话，动画第 1 集）

- **类型**：亮相战
- **规则**：橡胶。一场教两件事：铁棒打在身上没事（打不伤），拳头能伸长（能打远）
- **量级**：阿尔比达是一船之主，科比怕她怕得要死。对手的分量借科比的恐惧立起来；路飞一拳把她打倒
- **代价**：无
- **分几层**：一层
- **情绪**：科比的懦弱和路飞的坦荡形成对比，新角色的情绪借这个对比带出来
- **能借**：亮相战可以一次教完能力的两面（防和攻）；对手的分量不一定靠对手自己展示，可以借旁人的反应
- **不能借**：没有"压"的打法只适合很短的戏，拖长了就没有悬念

### OP-2 路飞 vs 克洛克达尔，三战（阿拉巴斯坦篇）

> 打斗卡（2026-11-01 按新方法重写）。资料：One Piece Wiki（阿拉巴斯坦篇页）。

- **类型**：压制战 → 压制战 → 规则战破局，同一个对手打三场
- **经过**：
  1. 阿拉巴斯坦多年不下雨。七武海克洛克达尔表面上是国民的英雄，暗中策划叛乱、夺取国家。公主薇薇想赶去阻止叛军，路飞说：就算拦住叛军，也除不掉克洛克达尔，人照样会死；两人吵起来，打了一架，路飞说大家都在拿命赌。薇薇最终同意，直接去找克洛克达尔
  2. **第一战**：克洛克达尔说陪他玩三分钟。路飞的拳头穿过他的身体，打不着：他是沙人。他能吸干东西，路飞的手臂被吸干，靠随身带的水才缓过来。三分钟一到，他放出沙暴吹向一座小镇，说那里每天的沙暴都是他干的。路飞分神，被他的钩子刺穿，扔进流沙等死
  3. **第二战**：路飞带着一桶水来，发现沾了水的沙子能打到。他把整桶水喝下去，用"水路飞"喷出水球，打中了克洛克达尔。克洛克达尔把整座王宫花园都吸干，掐住路飞的脖子把他吸干，扔在一边。路飞自己喷出去的水落回身上，才捡回一条命
  4. **第三战**：在王家陵墓里，路飞浑身是血，他的拳头沾着血，照样能让沙子变硬。克洛克达尔亮出毒钩，路飞中了毒，却根本不在乎，一心要把他打飞。最后一拳把克洛克达尔从地下打穿岩层，打上了天
  5. 克洛克达尔倒下，多年没下过的雨落了下来。叛军和王军停手，薇薇说：雨落下来了，噩梦结束了
- **情绪和这场仗想说的**：
  - **带走的情绪**：憋了两场的屈辱，最后用自己的血一次还清；然后是一场雨的释然
  - **这场仗证明了什么**：输两次也不放手。替别人拼命，就是把自己的命押上去
  - **谁变了**：薇薇，从想一个人扛下国家，到让伙伴们一起赌命
- **怎么交给观众**：
  - **第一层：先让对手赢得理直气壮**：打不着、被刺穿、扔进流沙。观众知道他有多强，也知道他有多坏（沙暴是他干的）
  - **第二层：每输一次，多懂一点**：第一战发现水有用；第二战把水用到极致，还是输。观众一路跟着找解法
  - **第三层：解法来自生活常识**：湿沙会结块。观众回头一想就觉得合理
  - **第四层：最后的水是自己的血**：代价直接在画面上，前两战的"水"在这里变成了"命"
  - **第五层：落在一场雨上**：国家多年的干旱是这个人造成的，他倒下，雨就来了
- **对照高光倒推**：
  - 先在乎什么：薇薇的国家；路飞那句"大家都在拿命赌"
  - 先知道什么：沙子沾水能打到
  - 先被压到多低：连输两场，第二次差点被吸干
  - 爆点：沾血的拳头；雨落下来
- **为什么成立**：
  1. 同一个对手打三次，每次的输法不同，观众不会觉得重复
  2. 解法一点点被找到，观众参与了破解
  3. 对手的能力（沙、干旱）和他对这个国家做的事是同一件事，打倒他和下雨是同一个结果
  - **前提**：前两次输要输得明白，观众才能跟着找答案
- **能借**：
  - 破解对手的规则可以拆到好几集里，每输一次多懂一点。正好对应两三集的单元：每集结尾停在"压"
  - 解法来自生活常识（沙子沾水会结块），观众回头一想就觉得合理，几乎不花脑子
  - 最后一次破解要付代价，把前面的"道具"换成"自己"
  - 对手的能力和他造成的灾难是同一件事，打赢就是灾难解除
- **不能借**：原作三场仗拉得很长，短剧要压缩
- **待核实**：路飞对薇薇那句话的原文 ⚠️待核实

### OP-3 索隆 vs Mr.1（阿拉巴斯坦篇）

- **类型**：突破战，在仗里学会一样新东西
- **规则**：Mr.1 全身能变成钢铁，刀砍不进去
- **量级**：钢铁是观众熟悉的东西，"砍开钢铁"不用任何解释
- **代价**：被砍到濒死
- **分几层**：砍不动 → 濒死 → 领悟"万物的呼吸"，一刀砍开钢铁
- **情绪**：成为世界第一剑豪的目标
- **能借**：仗里的突破要同时满足两点：已经被逼到绝境；原理能一句话说清（"听见呼吸"）
- **不能借**：在仗里临时学会新能力，离"作弊"只有一步。原作成立，是因为"能砍开钢铁"早就作为剑士的境界立在那里了 ⚠️待核实（推论，需要核对前文有没有铺）

### OP-4 索隆 vs 鹰眼（海上餐厅篇）

- **类型**：压制战，个人层面
- **规则**：没有特别的规则，就是剑术的差距
- **量级**：鹰眼是世界第一剑豪；只拿一把很小的刀对付索隆的三把刀 ⚠️待核实（"小刀"出自二手来源）
- **代价**：胸前留下一道大伤
- **分几层**：一层，从头到尾被压着打
- **情绪**：输了，但转身用正面挨刀，"背上的伤是剑士的耻辱"，守住了尊严
- **能借**：压制战要给观众留一笔"欠账"，比如一个誓言；用"对方根本没认真"表现差距，比真的打得很惨更狠
- **不能借**：输了却没留下任何"还账"的期待，就是纯憋屈

### OP-5 路飞 vs 青雉（长环长岛篇）

- **类型**：压制战，世界层面
- **规则**：青雉能把东西冻住
- **量级**：路飞要求单挑，被冻成冰，彻底输了。青雉饶了他，理由是他打败克洛克达尔，海军欠他一份人情
- **代价**：无
- **分几层**：一层
- **情绪**：为了保护罗宾而单挑
- **能借**：和 OP-4 对比，压制战有两种用法：OP-4 立个人目标（我要打败他），OP-5 立整个世界的刻度（这个级别现在根本碰不了）。两种任务不一样，不能混用
- **不能借**：世界刻度类的压制不能频繁用，用多了主角显得永远在输

### OP-6 草帽团 vs CP9（司法岛篇）

> 打斗卡（2026-11-01 按新方法重写）。资料：One Piece Wiki（司法岛篇页）。口碑：司法岛篇常被粉丝排进海贼王最受欢迎的篇章 ⚠️待核实（没有找到具体排名来源）。

- **类型**：团战，拆成一对一；开打前的关系高潮
- **经过**：
  1. 罗宾被世界政府带走，草帽团一路打进司法岛
  2. 路飞隔着峡谷喊她，说他来救她。罗宾回答：她不想被救，她只想死
  3. 罗宾的过去被揭开：她一次又一次被出卖，害怕有一天草帽团也会觉得她是累赘、抛下她。她喊着说，那样还不如死
  4. 长官斯潘达姆大笑，说她说得一点没错，谁跟她一起走都会觉得她是累赘；他指着正义之塔顶上的世界政府旗帜：要她的，是一个有一百七十多个加盟国的组织
  5. 路飞听完，叫狙击王把旗烧掉。旗帜着了火，全场惊呆：草帽团向世界政府宣战了
  6. 路飞喊："说你想活下去！"罗宾哭着求他们带她一起出海
  7. 罗宾戴着海楼石手铐，五把钥匙分在五个 CP9 成员手里，只有一把是真的。草帽团必须分头把 CP9 全部打倒
  8. 每个人都打到重伤，第 5 把钥匙才是对的
  9. 最后，梅利号自己开来接他们
- **情绪和这场仗想说的**：
  - **带走的情绪**：被选择的感动。不管你背着什么，你的敌人就是我们的敌人
  - **这场仗证明了什么**：伙伴不是不嫌你麻烦，是愿意为你和全世界为敌
  - **谁变了**：罗宾，从相信自己终究会被抛弃，到第一次开口求救
- **怎么交给观众**：
  - **第一层：被救的人先拒绝被救**："我想死"，把最低点交给她自己说出来
  - **第二层：反派替她说出恐惧**：谁都会嫌你是累赘；要你的是一百七十多个国家
  - **第三层：回答不是一句话，是一个不能撤回的动作**：烧旗。观众知道这一把火有多重
  - **第四层：逼她说出真心**："说你想活下去！"情绪在开打之前就已经拉满
  - **第五层：再分头去打**：钥匙规则给"分头单挑"一个理由，一次性给每个伙伴一场戏
- **对照高光倒推**：
  - 先在乎什么：罗宾一次次被出卖的过去
  - 先知道什么：世界政府有多大；烧旗等于宣战
  - 先被压到多低：她自己说想死
  - 爆点：烧旗；"我想活下去"
- **为什么成立**：
  1. 名场面在开打之前，打斗是兑现，不是起点（和"名场面可以不是打斗"相通）
  2. 宣战的代价观众心里有数，动作比任何承诺都重
  - **前提**：要救的人必须是观众已经在乎、但还没完全被接纳的伙伴
- **能借**：
  1. 用一个物件规则给"分头单挑"一个理由，一次性给每个伙伴一场戏
  2. 情绪先在开打前拉满，再分头去打
  3. 让被救的人先拒绝被救，再用一个不能撤回的动作回答她
- **不能借**：五场单挑在短剧里撑不住，最多拆两三场

### OP-7 二挡和三挡的首次使用（司法岛篇）

> 打斗卡（2026-11-01 按新方法重写）。资料：One Piece Wiki（二挡、三挡页）。旧卡里首次使用的顺序冲突已经核实。

- **类型**：死斗中的用法升级；变强的起因是一次惨败
- **经过**：
  1. 起因：路飞被海军大将青雉一招冻住，输得毫无还手之力（OP-5）。之后他见识了 CP9 的高速移动"剃"，琢磨出了二挡
  2. **二挡第一次用**（第 387 话），对手是 CP9 的布鲁诺。路飞对他说，自己不想再输、不想再让伙伴保护，所有的能力都要进化到下一阶段，然后喊出"二挡"。他加快全身血液的流速，身体冒出蒸汽，速度快到连刺客都看不清
  3. 同一场里，打到最后他喊了一声"挡……"，咬住拇指，这是三挡第一次露头（第 388 话），但没有用出来
  4. 三挡第一次真的用出来，是撞开一扇铁门，画面没有拍到（第 403 话）
  5. **三挡第一次完整亮相**是对路奇（第 421 话）：往骨头里灌气，把一条手臂变成巨人那么大。路奇一开始以为是虚张声势，挨了一拳才知道那是一根巨锤
  6. 代价：路奇看懂了二挡的原理，说它像兴奋剂，会大大缩短路飞的寿命；二挡用久了路飞会累到动不了。三挡解除以后，路飞会缩成小孩大小，缩的时间和变大的时间一样长
- **情绪和这场仗想说的**：
  - **带走的情绪**：憋屈了很久终于反击的爽；以及"他是在拿命换速度"的不安
  - **这场仗证明了什么**：输过一次，主角会为了不再输改变自己
  - **谁变了**：路飞，从靠天生的橡皮身体硬打，到主动开发能力的上限
- **怎么交给观众**：
  - **第一层：变强有起因**：上一篇被青雉完败，观众记得那种无力
  - **第二层：变强的那一刻有一句誓言**：不想再输、不想再被保护
  - **第三层：新招先在次一级的对手身上演示**：二挡打布鲁诺，三挡先露个头、再撞一扇门，到打路奇时观众已经有了期待
  - **第四层：代价由对手说破**：路奇说出"这会缩短你的寿命"，观众比路飞更担心
  - **第五层：代价里带一点好笑**：三挡解除后缩成小孩，紧张里有喘口气的地方
- **对照高光倒推**：
  - 先在乎什么：救罗宾；上一次惨败
  - 先知道什么：路飞是橡皮人；CP9 会高速移动
  - 先被压到多低：一挡打不过 CP9
  - 爆点：喊出"二挡"；巨人化的拳头
- **为什么成立**：
  1. 新形态是从原有的能力（橡皮身体）推出来的，不是凭空多了一个
  2. 两个新形态差在规则上：一个换速度，一个换体积，各有各的代价
  - **前提**：前面要有一次让观众难受的失败
- **能借**：
  1. 新招先在次一级的对手身上演示规则，到打大 boss 时观众已经懂了（顺序已核实：二挡对布鲁诺，三挡先露头再完整用在路奇身上）
  2. 变强的起因放在上一次惨败里，变强那一刻给一句誓言
  3. 代价由对手说出来，比主角自己说更有分量
  4. 新形态从原有能力的规则里推出来，形态之间差在规则上，不差在数值上
- **不能借**：新形态一次出两个，短剧里观众消化不了，一集只开一个

### OP-8 路飞 vs 多弗朗明哥，四挡（德雷斯罗萨篇）

> 打斗卡（2026-11-01 按新方法重写）。资料：One Piece Wiki（四挡页、德雷斯罗萨篇页）。旧卡里"别人帮他拖住"的情节已经核实。

- **类型**：死斗；限制制造出一整段支援戏
- **经过**：
  1. 多弗朗明哥用"鸟笼"把整座岛围住，丝线一点点收紧，笼里的人谁也出不去。他还操纵一部分居民去攻击别人，岛上的人这才明白，自己被他骗了十年
  2. 王宫屋顶上，路飞发现二挡太弱、三挡太慢。多弗朗明哥嘲笑他：德雷斯罗萨的苦难是他带来的。路飞回答：你伤害我的朋友，比这早得多。他用出了四挡（第 784 话），一拳把七武海从王宫屋顶打飞
  3. 四挡在最后一击前到了时间。用完以后十分钟内用不了霸气，路飞虚弱得几乎动不了（第 786 话）
  4. 路飞对角斗场的解说员说：再给他十分钟，他就能一拳打倒多弗朗明哥
  5. 这十分钟里：解说员召来原本想抢赏金的角斗士们挡住多弗朗明哥，再背着路飞逃；萨博拦下了想杀路飞的黑胡子海贼团的人；罗接过路飞，守着他度过剩下的时间；鸟笼加速收紧，岛上的居民一起去推那些丝线
  6. 十分钟后，路飞再上，打倒了多弗朗明哥
- **情绪和这场仗想说的**：
  - **带走的情绪**：十分钟里所有人一起扛的热血
  - **这场仗证明了什么**：主角的力量有空窗，空窗由大家来填
  - **谁变了**：岛上的居民，从被骗了十年的人，到自己去推鸟笼的人
- **怎么交给观众**：
  - **第一层：限制先说清楚**：用完十分钟不能用霸气。观众知道这十分钟有多危险
  - **第二层：主角亲口给出期限**："再给我十分钟"
  - **第三层：一个个人站出来**：角斗士、萨博、罗、居民。每个人在这十分钟里都有一场戏
  - **第四层：倒计时同时在两边走**：路飞在恢复，鸟笼在收紧
- **对照高光倒推**：
  - 先在乎什么：整座岛的人
  - 先知道什么：四挡的代价是十分钟
  - 先被压到多低：四挡打完，最后一击没出手，路飞躺倒
  - 爆点：十分钟后的那一拳
- **为什么成立**：
  1. 限制制造出一段清楚的时间，时间里塞满支援，每个配角都被用上
  2. 普通人（居民）也在出力（和 TG-9、SV-9 一回事）
  - **前提**：前面登场的配角要够多、观众都认识
- **能借**：
  1. 限制可以制造出一整段新的戏。限制不只用来"压"主角，还能给伙伴腾出戏份
  2. 让主角亲口说出期限，观众跟着数
  3. 主角恢复和危机加速两个倒计时同时走
- **不能借**：原作的空窗戏很长，短剧要压成一两个回合

### OP-9 索隆和山治的日常斗嘴

> 打斗卡（2026-11-01 按新方法重写）。这不是一场仗，是贯穿全剧的一种关系模式。资料是常识性的剧情记忆，具体场景没有逐一核实。

- **类型**：切磋战，关系确认
- **经过**：
  1. 索隆先上船，山治在海上餐厅篇入伙
  2. 两人一见面就吵，互相起外号（"绿藻头""卷眉毛"），为一点小事动手
  3. 每到大战，两人比谁打倒的敌人更强、谁更快。和之国篇里，两人各自对上凯多手下的两大"灾害"（索隆对烬，山治对奎因）⚠️待核实具体分配
  4. 吵归吵，到了关键时刻会把背后交给对方（推测，具体场景 ⚠️待核实）
- **情绪和这场仗想说的**：
  - **带走的情绪**：好笑，然后是"他们其实很信任对方"的暖
  - **这场仗证明了什么**：一段关系可以靠永远分不出胜负的竞争来确认
  - **关系怎么变**：不变。不变本身就是看点：观众每次都知道他们会吵，也知道他们靠得住
- **怎么交给观众**：
  1. **把亲近藏在吵架里**：两人从不说好话，观众自己读出关系
  2. **竞争给大战加一层小目标**：除了打赢敌人，还要赢过对方
  3. **永远不分胜负**：留给评论区一个"谁更强"的话题
- **对照高光倒推**：
  - 先在乎什么：两个人都已经是观众喜欢的角色
  - 先知道什么：他们一见面就会吵
  - 先被压到多低：不适用
  - 爆点：大战里两人同时完成各自的对决
- **为什么成立**：
  1. 实力接近，竞争才有意义
  2. 两人的能力和人设反差大（剑和腿，冷和热），吵起来就有看头
  - **前提**：两个角色都已经立住，观众在乎他们
- **能借**：
  1. 永远分不出胜负，这本身就是看点；给评论区制造"谁更强"的话题，关系也在一次次斗嘴里被确认
  2. 大战时把两个冤家分到同一级别的对手上，各打各的，比结果
- **不能借**：分出了胜负，话题就没了

### OP-10 路飞 vs 女帝汉库克与蛇姬姐妹（女儿岛篇，漫画第 518–520 话）

- **类型**：规则战 + 关系反转战
- **规则**：
  - 汉库克的甜甜果实，能把对她动了心的人变成石头；满场被石化的人就是证明
  - 她两次对路飞放石化光线，都失效了（第 518 话）；路飞以为那是福克西的迟缓光线，摆错了防御姿势，本身是个笑点
  - 为什么无效：剧里玛丽哥尔德猜他是吓坏了顾不上心动；"路飞心里没有邪念"这个更广为人知的说法是不是原作给的解释 ⚠️待核实
- **量级**：满场石像是参照物，观众一眼知道这招有多可怕，再看它对路飞失效
- **代价**：无
- **分几层**：打败处刑者豹子巴库拉 → 对上桑达索尼亚和玛丽哥尔德，打斗中无意识地第二次放出霸王色霸气 → 玛丽哥尔德的火烧掉了桑达索尼亚的衣服，后背的奴隶印记要暴露，路飞冲上去用身体挡住 → 打赢两姐妹（第 520 话）
- **情绪**：敌人藏了一辈子的伤疤，被对手护住了
- **能借**：
  1. 颜值可以就是规则本身：女帝的美貌直接是武器，满场石像是证明。框架第五节说"颜值 + 反常"，这里是把颜值做成了能力，AI 出颜值的成本接近零
  2. 免疫可以来自人物性格：路飞扛住石化不靠练出来的力量，靠"他就是这样的人"。规则一和人物挂钩，就成了刻画人物的工具
  3. 打斗中途换目标：拼命打着，突然变成帮敌人守秘密。观众猜的是"谁会赢"，被引到"他会怎么对待敌人"，是猜错了但回头一想合理的惊喜
  4. 仗打完关系翻转：汉库克爱上路飞，敌人变成日后的援军。留下的不是胜利，是关系（对应框架第三节"单元留下什么"里的关系变化）
- **不能借**：挡背的动作成立，是因为前面花了很多篇幅铺印记的秘密有多重。短剧要在同一集前半段就铺好，而且只能用一个画面讲清楚

### 海贼王小结（观察，未升格为规律）

1. 同一个对手可以用不同类型的仗来打：克洛克达尔前两次是压制，第三次才是规则战破局（OP-2）
2. 压制战有两种：立个人目标的（OP-4），立世界刻度的（OP-5）
3. 新招先在小场面教规则（OP-7）⚠️待核实
4. 限制可以生出新的戏，比如给伙伴腾出支援段落（OP-8）
5. 情绪的蓄力可以放在开打之前，不一定在打到最低点时才注入（OP-6）
6. 仗的结局不只是输赢，还可以是关系（OP-10）。打斗可以按结局分：打赢、打输、打平、打出关系
7. 颜值可以做成能力规则；免疫可以来自人物性格（OP-10）

## 一人之下（YR）

### YR-1 张楚岚的初赛（罗天大醮）

- **类型**：亮相战，亮的是打法风格，不是能力
- **规则**：能耍赖就绝不动手。轻松晋级，得名"不摇碧莲"（真人版改为"不要脸"）
- **量级**：不立量级，立人设
- **代价**：无
- **分几层**：一层
- **情绪**：好笑
- **能借**：亮相战可以亮"这个人怎么打"，不一定是"这个人有多强"，观众记住的是一种性格
- **不能借**：只靠耍赖赢，多了观众觉得主角没真本事，所以必须有一场证明他不只会耍赖（见 YR-2）

### YR-2 张楚岚 vs 张灵玉（罗天大醮决赛）

> 打斗卡（2026-11-01 按新方法重写）。资料：搜狐文章《罗天大醮最精彩的六场对决》（本场排第 1）、腾讯动漫和起点的问答、萌娘百科搜索摘要（页面本身没抓到）。全是二手资料和粉丝解读，证据比别的卡薄。

- **类型**：打到死斗级的切磋
- **经过**：
  1. 多数解读认为，老天师办罗天大醮就是为了张楚岚。张灵玉不知道师父的算计，全力出手
  2. 场边的年轻异人都盼着他痛打"不摇碧莲"：张楚岚前面靠耍赖、不动手赢下了比赛
  3. 张灵玉是老天师的关门弟子。和全性夏禾的过往让他失去了童子身，修不了阳五雷，只能修阴五雷。阴雷就是他的心结
  4. 他一开始把阴五雷当成阳五雷那样的掌心雷来用，压不住张楚岚的阳五雷
  5. 被逼到这一步，他用出了阴五雷真正的样子，解开了心结，把阴五雷发挥到了极致
  6. 张楚岚被逼出了真正的实力
  7. 张灵玉最后倒地输了。多数说法认为是老天师给他下了药 ⚠️待核实
- **情绪和这场仗想说的**：
  - **带走的情绪**：两个人都被看见了。张灵玉终于接受了自己，张楚岚证明了自己不只会耍赖
  - **这场仗证明了什么**：能力的上限锁在心结里，接受自己最不想面对的过去，能力才完整（推测）
  - **谁变了**：张灵玉。知乎专栏有文章专门写他"罗天大醮后的蜕变"
- **怎么交给观众**：
  1. **观众先站在对手那边**：全场都想看他教训耍赖的人
  2. **阴阳反着放**：心地淳朴的修阴雷，性格狡诈的修阳雷（萌娘百科的解读）。能力和人设反着配，冲突就在能力里
  3. **心结写进规则**：他不肯用真正的阴雷，就是不肯面对夏禾那段过去
  4. **解开心结和能力升级是同一个瞬间**
  5. **两个人都打出了真本事**：这一场的任务是证明主角不只会耍赖，和 YR-1 前后呼应
- **对照高光倒推**：
  - 先在乎什么：张灵玉的心结；张楚岚被所有人看不起
  - 先知道什么：阴雷和夏禾的关系
  - 先被压到多低：张灵玉压不住阳雷
  - 爆点：阴五雷真正展开
- **为什么成立**：
  1. 两边都有东西要证明
  2. 规则就是心结，打斗和人物成长是同一件事
  - **前提**：心结要在前面先交代清楚
- **能借**：
  1. 心结就是能力的锁，解开心结和能力升级是同一个瞬间（和 FT-3 的"能力规则揭开人心"是同一类做法）
  2. 能力和人设反着配，冲突写进能力里
  3. 主角被所有人看不起，决赛里证明自己
- **不能借**：靠场外因素（下药）决出胜负，观众回头会觉得被骗。短剧要么胜负干净，要么把它做成后面明确交代的悬念

### YR-3 王也 vs 诸葛青（罗天大醮）

> 打斗卡（2026-11-01 按新方法重写）。资料：搜狐文章《罗天大醮最精彩的六场对决》（本场排第 2）、萌娘百科搜索摘要（页面本身没抓到）、简书粉丝分析。证据薄，规则细节多为粉丝解读。

- **类型**：同类能力的量级比拼
- **经过**：
  1. 两个人在遇到彼此之前都轻松取胜，没碰到过真正的威胁
  2. 两人都用奇门。诸葛青被称为几十年来第一个掌握全部武侯奇门的人，他的奇门顺势引导；王也的风后奇门能在自定中宫后改动天地格局 ⚠️待核实（粉丝分析）
  3. 诸葛青拿出了全力，王也看起来还有保留
  4. 王也破局获胜。他快速连续发动风后奇局，受了内伤，吐血 ⚠️待核实
  5. 他暴露了自己是八奇技"风后奇门"的传人，被武当除名。萌娘百科的说法是：其实是他怕给武当惹麻烦，主动离开
  6. 这一战之后，两个人反而成了朋友。诸葛青一直觊觎风后奇门，王也看在眼里，仍然和他交心
- **情绪和这场仗想说的**：
  - **带走的情绪**：天才撞上了更高的天才，骄傲被打碎；赢的那个人却并不想赢（推测）
  - **这场仗证明了什么**：同一种能力之间也有层次
  - **关系怎么变**：从对手变成朋友，这是两人关系的起点
- **怎么交给观众**：
  1. **量级先靠"没人逼得出他们"来铺**
  2. **同一种能力相撞**：观众先通过诸葛青懂了"奇门是什么"，才懂"风后奇门高在哪"
  3. **赢的代价是剧情后果**：赢了比赛，丢了师门
  4. **打完成了朋友**：觊觎和交心同时存在，关系有张力
- **对照高光倒推**：
  - 先在乎什么：诸葛青的骄傲
  - 先知道什么：武侯奇门是什么
  - 先被压到多低：不适用（重点不在压）
  - 爆点：风后奇门破局
- **为什么成立**：
  1. 同类能力相撞，观众只要懂一层，就能看懂第二层
  2. 胜负引出后续剧情，不是打完就完
  - **前提**：第一层能力要先被观众看懂
- **能借**：
  1. 同类能力相撞，打的是层次差：观众先懂"奇门是什么"，才懂"风后奇门高在哪"
  2. 代价可以是剧情后果，不只是身体：赢了比赛，丢了师门
  3. 打完成为朋友，留一个觊觎的钩子
- **不能借**："中宫""格局"这类术语短剧观众接不住，必须换成一眼看懂的画面

### YR-4 冯宝宝 vs 萧霄（罗天大醮）

- **类型**：规则战，反转成碾压
- **规则**：萧霄的绝技擤气，能把人的灵魂暂时轰出体外
- **量级**：诸葛青和王也赶紧下场救下萧霄。两个高手都坐不住，观众就知道这一下有多危险
- **代价**：无（萧霄差点丧命）
- **分几层**：冯宝宝手忙脚乱 → 几回合后找到办法 → 把萧霄还没发出的擤气摁回去
- **情绪**：冯宝宝下手没轻重，带来恐惧和好笑
- **能借**：
  1. 规则战的解法可以是"用你的招打你"，不需要新能力，需要对规则的另一种理解
  2. 借旁人的反应立量级（和 OP-1 同一个做法）
- **不能借**：主角一方差点打死人，要有人拦下，否则观众对主角的好感会掉

### YR-5 风莎燕 vs 贾正亮（罗天大醮）

- **类型**：切磋战，打出关系
- **规则**：贾正亮用十二把斩仙飞刀；风莎燕能穿梭空间，绝技"宇宙迷"能在一定范围里设置多个空间出入口
- **量级**：贾正亮前面靠飞刀击败对手，是大黑马
- **代价**：两人都见血
- **分几层**：开始都不留情，刀刀见血、拳拳到肉 → 风莎燕放出"宇宙迷" → 最后一击贾正亮手下留情，惜败
- **情绪**：赛后两人关系迅速升温
- **能借**：打出关系（和 OP-10 同一种结局）
- **不能借**：前半场的"不留情"必须是真的，否则最后的手下留情没有分量

### YR-6 风星潼 vs 王并（罗天大醮）

- **类型**：同一种能力的正邪对照
- **规则**：两人都用拘灵遣将。风星潼看似气势十足，其实温和；王并的充满邪气
- **量级**：风星潼差点被打死
- **代价**：风星潼失去了一直陪着他的子仲爷爷和帮他过关的柳大爷
- **分几层**：正邪对拼 → 风星潼落败
- **情绪**：失去伙伴的痛
- **能借**：
  1. 同一种能力换一个人用，就是一面镜子：观众看到"这个能力在坏人手里是什么样"
  2. 输的代价可以是失去伙伴
- **不能借**：之后张灵玉轻松打败王并，有评论认为打得太轻。反派刚立起来就被别人轻松打掉，前面立的量级就白费了（反例）

### YR-7 老天师 vs 全性十四人（锡林郭勒草原）

- **类型**：碾压，亮相战的极端版
- **规则**：老天师常用金光咒，这是天师府的基础功法，也是异人界数一数二的护体功法
- **量级**：以丁嶋安为首的十四名全性高手被轻松击败，最后击杀全性代掌门龚庆；十佬想出面阻拦，老天师一巴掌扇飞陆瑾，就没人敢上前了 ⚠️待核实（二手文章）
- **代价**：战后被十佬会判决禁足龙虎山
- **分几层**：一层
- **情绪**：震慑
- **能借**：
  1. 基础招打出天花板：最基础的功法在最强的人手里就是碾压
  2. 量级要靠"观众已经知道多强的人"衬托：陆瑾是观众早就认识的十佬，比打倒一群新面孔有说服力
  3. 碾压也有代价，代价落在剧情上：被禁足
- **不能借**：碾压只适合配角或师父，主角一直碾压就没有"压"

### YR-8 陈朵之死（碧游村篇）

- **类型**：不是打斗，是对手的单元故事
- **规则**：陈朵是蛊身圣童，杀害华南地区负责人廖忠后逃走（廖忠之死的因果，各来源说法不一 ⚠️待核实）
- **量级**：无
- **代价**：她用生命力压住蛊毒，撑了约二十小时
- **分几层**：公司给她两个选项，回公司或者死，她选了死 → 二十小时里和大家逛街、买衣服、吃冰淇淋，做以前没做过的事 → 毒发，含笑而终
- **情绪**："对手"本身是受害者。一辈子被药仙会、公司、碧游村安排，没人问过她想要什么
- **能借**：
  1. 对手是受害者（和框架第二节"迪迦里有的怪兽本身是受害者"同一回事，待用特摄案例交叉验证）
  2. 单元的情绪高潮可以不是打斗，而是一个选择
- **不能借**：碧游村篇有一百多话，短剧里一个对手的悲剧要压在一两集讲完

## 迪迦奥特曼（TG）

> 中文资料多来自问答站和个人文章，可靠性低于前两部，⚠️ 较多。

### TG-1 每集的公式（全剧层面）

- **类型**：叙事壳
- **规则**：出现异常 → GUTS 调查 → 怪兽现身 → 大古变身 → 吃亏、计时器闪烁 → 换形态 → 必杀 ⚠️待核实（按全剧归纳，没有找到出处）
- **量级**：不适用
- **代价**：不适用
- **分几层**：不适用
- **情绪**：观众等的不是"会不会变身"，而是"什么时候、怎么来"
- **能借**：流程固定，观众不用花脑子跟结构，注意力全留给每集的新东西
- **不能借**：固定的是叙事，不是打法。打法也固定，每集就只剩"换了一只怪兽"

### TG-2 三种形态：复合型、强力型、空中型

- **类型**：变强方式 A（换形态）的仪式
- **规则**：复合型力量和速度均衡，平时以它登场；强力型（红）力气最大，擅长近身肉搏；空中型（蓝紫）最敏捷，飞行能力最强。额头的水晶负责形态转换，换时发出不同颜色的光
- **量级**：不适用
- **代价**：无
- **分几层**：复合型 → 按战况换成另外两种
- **情绪**：仪式感
- **能借**：换形态是对战况的回答。对手会飞就换空中型，皮厚就换强力型，观众能提前猜"该换哪个了"
- **不能借**：三种形态之间只差数值（力量、速度），不差规则。数值型换形态，打起来只能比谁更大、更快。《生肖》第一版"戴面具变兽"错就错在这里

### TG-3 彩色计时器

- **类型**：限制
- **规则**：能量减少时胸口计时器由蓝变红并闪烁，熄灭即力量耗尽
- **量级**：不适用
- **代价**：时间
- **分几层**：不适用
- **情绪**：紧张
- **能借**：限制要看得见，观众看灯就知道情况危急；它同时是节拍信号："压"开始了
- **不能借**：迪迦里的计时器大多只是"快不行了"的信号，很少真的逼大古做选择 ⚠️待核实（推论）。和 OP-8 对比：四挡的十分钟空窗逼出"谁来拖住对手"，还生出一段戏。同样是限制，有的只是节拍信号，有的逼人做选择

### TG-4 泽尔达点攻防战（第 32 集，怪鸟西拉）

> 单元卡（2026-11-01 按新方法重写）。资料：Ultraman Wiki（集页梗概和花絮、怪兽西拉页）、口碑汇总（见迪迦来源）。集页只有梗概，经过是从怪兽页补的，细节可能不全；没有亲眼看过本集。

- **故事**：
  1. 一只怪鸟一心要飞向"泽尔达点"，那里封存着能毁灭一切生物的泽尔达气体
  2. 发明并封存气体的根津博士说出真相：二十年前气体意外泄漏爆炸，他的女儿麻美在死前把养的鹦鹉西拉放走，西拉被气体变成了怪兽
  3. 西拉藏在浅间山里，一直为麻美的死悲伤，要毁掉气体，替她报仇
  4. 第一次冲击被 GUTS 打退，左眼差点被打中
  5. 第二次出来，GUTS 仍不放它过去。大古之前受的伤带到了迪迦身上；西拉伤得更重，一边吐血一边往前冲
  6. 垂死的根津博士帮西拉吸光了最后的气体
  7. 迪迦和 GUTS 把濒死的西拉送进太空。它和博士的灵魂化成光，左眼复原，变成金色凤凰；迪迦放出一道光给它引路，麻美的灵魂开心地坐在它背上，一起离开地球
- **情绪和想表达的**：
  - **带走的情绪**：心疼，最后被一种释然接住。日文博客说泪点在于"怪兽和博士各自的念想在结尾重合"
  - **想说的那句话**：编剧太田爱说，想讲的是"失败了也还有很多能做的事，失败以后也要继续往前走"
  - **谁变了**：根津博士，造出毒气、失去女儿的人，最后用自己的命帮怪兽完成心愿；GUTS 从拦住它，变成送它走
- **怎么交给观众**：
  - **第一层：先让你怕它，再告诉你它是谁**
    1. 开场是一只冲向毒气的怪鸟，观众和 GUTS 一样把它当威胁
    2. 博士一句话翻过来：它是一个小女孩的鹦鹉，是在替她报仇。同一个冲击动作，从可怕变成可怜
    3. 悲剧的源头是一个最小的动作：麻美死前先把鸟放走了。导演北浦嗣巳把故事中心从博士改到麻美身上（早期方案以博士为中心），情绪的起点就落在一个孩子身上
  - **第二层：让两边都在受伤**
    1. GUTS 和迪迦的任务是拦住它，观众却希望它过去
    2. 迪迦带着伤，西拉吐着血，两边都不是坏人，这场仗越打越疼
  - **第三层：让念想重合**
    1. 造出悲剧的人和失去主人的鸟，最后做了同一件事：博士帮它吸光气体
    2. 结局不是打倒，是送走：凤凰、复原的左眼、坐在背上的麻美，把死去的女孩"还"了回来
- **对照高光倒推**：
  - 先在乎什么：麻美放走鹦鹉的那一刻
  - 先知道什么：气体有多危险；博士就是发明者
  - 先被压到多低：西拉吐血还在往前冲，拦它的是我们这边的人
  - 爆点：化成凤凰，麻美坐在背上
- **为什么成立**：
  1. 受害者怪兽是观众一听就懂的处境：它不是坏，是太难过
  2. 情绪锚在一个孩子身上，不需要观众先认识谁
  3. 博士给了"失败以后还能做什么"一个具体的答案，主题和结局是同一个动作
  - **前提**：送走式的结局要有一个能让人接受的去处（太空、光、凤凰），否则就只是怪兽死了
- **能借**：
  1. 对手是受害者（和 YR-8、TG-14 一回事）
  2. 仗的结局可以是送走，不一定是打倒
  3. 同一个悲剧从两边讲：造成悲剧的人和失去所爱的生灵，结尾让两边的念想重合，比只讲一边更催泪
  4. 让制造悲剧的人亲手完成赎罪
- **不能借**：
  1. 要拍出眼泪，靠前面对"人和怪兽原本的关系"的铺垫，短剧要在同一集前半段铺好
  2. 导演说，回忆戏和怪兽戏的比例、保持温暖的家庭基调都很费工夫；飞行怪兽的特效也难，结尾的凤凰最后用了全 CG。短剧要把回忆压成一两个画面
- **待核实**：二十年前那场爆炸的具体经过 ⚠️待核实

### TG-5 吸血都市（第 33 集）

> 单元卡（2026-11-01 按新方法重写）。资料：Ultraman Wiki（集页梗概和花絮、怪兽丘拉诺斯页）。集页只有梗概，雪娜的结局来自之前的二手资料，没有亲眼看过本集。

- **故事**：
  1. 一个月里出了五起失踪案；GUTS 在现场找到一根头发
  2. 回基地路上救起一个昏倒的女人，脖子上有咬痕，体温像尸体。她在基地里醒来变成吸血鬼，要咬队长居间惠，副队长宗方及时赶到
  3. 头发是南美吸血蝙蝠的。宗方去找酒吧里认识的老朋友、杂志记者小野田，小野田知道内情：他像父亲一样带过的徒弟雪娜，也成了吸血鬼
  4. GUTS 潜入一座废弃的夜总会；大古被关进棺材里的亚空间，吸血鬼说他身上的"光"太多，变不成同类，只能杀掉
  5. 阳光照了进来；雪娜在告别小野田以后，在阳光下慢慢融化，小野田绝望地呼喊
  6. 怪兽丘拉诺斯用黑暗盖住天空，咬住迪迦，催眠他自己伤自己
  7. 小野田协助 GUTS 打瞎了怪兽的眼睛，他把这一击想象成在给雪娜拍照；迪迦定住怪兽，用光线消灭它
- **情绪和想表达的**：
  - **带走的情绪**：硬汉式的悲伤。一个中年男人亲眼看着自己带大的徒弟消失
  - **想说的那句话**：编剧长谷川圭一说，小野田和宗方的往来，是想写人面对看似不可能的处境时做出的决定性选择；雪娜的"光"象征和解与释放
  - **谁变了**：小野田，从旁观的记者变成亲手出力的人
- **怎么交给观众**：
  - **第一层：先用恐怖片的方式进来**：失踪、咬痕、尸体的体温、基地里醒来的吸血鬼，全是西洋恐怖片的熟套路
  - **第二层：情绪交给一对单元配角**：小野田和雪娜像父女，观众通过宗方的老朋友进入这段关系
  - **第三层：死亡就是和解**：阳光杀死吸血鬼，也让雪娜从怪物变回人（推测，由编剧"光象征和解与释放"推导）
  - **第四层：把悲伤变成一击**：小野田出手时想的是给她拍照，记者的本行和告别是同一个动作
- **对照高光倒推**：
  - 先在乎什么：小野田和雪娜像父女一样的关系
  - 先知道什么：吸血鬼怕阳光
  - 先被压到多低：雪娜在阳光里融化
  - 爆点：小野田"拍照"的那一击
- **为什么成立**：
  1. 吸血鬼的规则观众早就知道（怕阳光、咬人传染），不用教

### TG-9 恶魔的审判（第 25 集）

> 单元卡（2026-11-01 按新方法重写）。资料：Ultraman Wiki（集页剧情和花絮，含导演村石宏实、编剧小中千昭的说法）、口碑汇总（见迪迦来源）。没有亲眼看过本集。

- **故事**：
  1. 新闻里，城市上空出现了"天使"。受访的人里有队长居间惠的婆婆；居间惠的儿子友树发消息给妈妈，求她救奶奶
  2. 婆婆变了一个人，说天使能让她死去的儿子（居间惠的丈夫）活过来
  3. 居间惠对丽娜说：丈夫死的时候她在国外；婆婆把友树接走时，她松了一口气，觉得自己不配当妈妈。丽娜安慰她
  4. 大古被一个戴兜帽的少女叫作"迪迦"，遭到攻击；新城一靠近天使就头疼
  5. 第 3 集被打败过的基里艾洛德人回来了，在人群面前打开"地狱之门"，说服大家：迪迦才是恶魔，必须被打倒
  6. 受伤的大古被丽娜和居间惠找到（丽娜从这一集起知道了大古的身份）
  7. 迪迦变身，用复合型、强力型、空中型轮番上阵，对手每次都跟着变：他换强力型，它也变强；他换空中型，它长出翅膀。迪迦力竭倒地，眼睛暗下去，被黑暗吞没
  8. 居间惠想起迪迦需要光，让战机和车灯照他，不够；她通过所有通讯向市民求助，人们开着车、举着手电赶来。迪迦动了一下，还不够
  9. 城市的灯忽然全亮了。迪迦站起来，姿势照着广告牌上米开朗基罗的《创造亚当》摆；他打败对手，关上地狱之门，向人群竖起大拇指
  10. 居间惠去看儿子：矢住查出是友树黑进了电脑。她说她不生气，因为他帮了迪迦
  11. 结尾，一个女人捡起了天使的羽毛
- **情绪和想表达的**：
  - **带走的情绪**：在一片怀疑里，有人为你举起灯，被托住的那种暖；结尾留一丝凉
  - **想说的那句话**：导演村石宏实说，这场戏不是在演"光能量补给"，让迪迦复活的"光"是人们的信任和力量。网友的说法是"每个人心里都有光"。另一面是：人宁愿相信能马上解除痛苦的东西
  - **谁变了**：人群，从把迪迦当恶魔，到为他举灯；居间惠一家，觉得自己不配当妈妈的母亲，和用自己的方式帮了忙的儿子（推测）
- **怎么交给观众**：
  - **第一层：先让你理解为什么人会信"天使"**
    1. 被骗的人不蠢，是痛：婆婆想让死去的儿子回来。诱惑来自最普通的思念
    2. 同一条线上放着居间惠自己的愧疚，主题落到了队长的家里
  - **第二层：被保护的人站到了对面**
    1. 对手打的不是迪迦的身体，是人心里"信谁"
    2. 迪迦三种形态全被克制，眼睛一点点暗下去；人群在骂他是恶魔
  - **第三层：普通人一个一个选择**
    1. 指挥官做的是最普通的事：请大家把灯打开
    2. 光一层层加上去：战机、车灯、手电，还不够，最后整座城亮了。每多一盏灯，就是多一个人自己选择站过来
    3. 城市的灯来自友树：家里那条小线，在这一刻接上了大线（推测）
  - **第四层：落下来，但不说满**
    1. 导演用画面说出主题：《创造亚当》的姿势、向人群竖起大拇指。编剧原本只写了点一下头，不赞成加这些
    2. 结尾的女人捡起羽毛：不是每个人都信奥特曼（导演原话）。胜利以后留一个"没被改变的人"，主题就不会变成说教
- **对照高光倒推**：
  - 先在乎什么：居间惠一家；迪迦这半季的守护
  - 先知道什么：迪迦需要光（第 1 集"化为光"）；这个对手第 3 集来过
  - 先被压到多低：三种形态全输，被保护的人骂他是恶魔
  - 爆点：万家灯火，迪迦站起来
- **为什么成立**：
  1. "迪迦需要光"是全剧早就教会的规则，这一集只是把光从能量换成了人心，观众不用学新东西
  2. 对手说的话有一半是对的：人确实会怀疑、会想要更快的救赎。问题是真的，所以答案有分量
  3. 情绪落在人群的选择上，所以三种形态全输，不会让主角显得弱
  - **前提**：播到第 25 集，观众已经跟了半季，在乎迪迦，也在乎居间惠
- **能借**：
  1. 对手的规则作用在人群上，打的是"信谁"
  2. 最低点由普通人出力翻盘；光一层层加，每一层都是一个人的选择
  3. 主题问题放进核心角色的家里，大线和小线在同一个动作上接上
  4. 胜利以后留一个"没被改变的人"
  5. 用一个画面说出主题（复活的姿势），不用台词
- **不能借**：
  1. 靠大量群众演员和城市灯光，制作量大；短剧可以把"群众"压成几个有代表性的人
  2. 编剧和导演在"情绪外显到什么程度"上有分歧（点头还是竖大拇指）。这个度要事先和团队对齐
  3. 宗教意象要注意平台尺度
- **制作备注**：小中千昭本来没打算让丽娜在这一集知道大古的身份，看了演员吉本多香美的表演后才改

  - **第一层：先让你在乎她**
    1. 先让你心疼她的处境，再让你喜欢她这个人：她到现代以后最先遇到的，是家变成了马路
    2. 约会用的全是观众最熟悉的小事（汉堡、游戏厅、大头贴），她每惊讶一次，甜和"她不属于这里"的距离感就同时出现一次
    3. 一天的约会被凝成一件能拿在手里的东西：吊坠。这时观众只觉得是个可爱的小礼物
    4. 心动的是一个普通人，不是英雄，观众代入的是"普通男孩第一次喜欢上一个人"
  - **第二层：让放手有重量**
    1. 代价在按扳机之前就说清楚了（堀井的警告），之后每一秒都是"知道结局会疼"的
    2. 告别放在她不知道的时候：她笑着挥手道谢，矢住从后视镜里看着她越来越小。观众和矢住知道同一个秘密，她却在笑（剧评者印象最深的场面）
    3. 选择交到他一个人手上，只用一个字："能做到吗？""是！"没人替他决定，台词越短越重
    4. 按扳机前，再让观众看她一眼（他想起后视镜里的她）
    5. 胜利的那一秒就是失去的那一秒：没有欢呼，只有"是我杀了她"
  - **第三层：让那个微笑落下来**
    1. 答案一开始就摆在观众面前：开头的梦、第一眼的似曾相识，观众看到了，但没当回事
    2. 结尾一句解释都没有，只打开一个吊坠。观众自己把梦、似曾相识、送出去的吊坠全部连起来；从"我杀了她"的最低处，一下翻到最暖的地方
    3. 信物绕了八十年回到他手里，观众感到的是"她一直带着它"，而不是"设计得真巧"
    4. 片名把终点定在一个微笑上，不是打赢怪兽
  - **贯穿全集**：只跟着矢住一个人的心走，主角大古退到后面。剧评说实际只有二十几分钟，观众照样能代入
- **对照高光倒推**：
  - 先在乎什么：她失去了家；那一天的约会
  - 先知道什么：打倒怪兽，她会老去、会死
  - 先被压到多低：不知情的挥手；"是我杀了她"
  - 爆点：打开吊坠，不是打赢怪兽
- **为什么成立**：
  1. 矢住是观众看了三十多集的熟面孔，他的心动和痛不需要再介绍
  2. 怪兽战的壳还在：怪兽、GUTS、迪迦、必杀一个不少，只是退到后面
  3. 情绪线一条到底，没有支线分心
- **能借**：
  1. 代价由亲手按扳机的人承担：胜利条件和失去所爱是同一个动作
  2. 不知情的告别：观众知道代价，当事人不知道，平常的道别就成了名场面
  3. 信物闭环：首尾呼应靠一件物件，不靠台词；结尾的那一下同时揭开谜底、解开主角的心结
  4. 熟悉的日常里放进一个反常的人：反常感和甜感都来自最普通的场景，几乎不花特效钱
  5. 借经典的机制，换自己的皮：编剧长谷川圭一参考了电影《时光倒流七十年》，那部电影里老妇人把一块怀表交给年轻男主角，怀表成了没有起点的闭环；本集换成了大正少女和大头贴吊坠（框架第二章"借什么、新在哪"的程度 1 到 2）
- **不能借**：
  1. 谜底揭得太早：开头的梦就露了底，有剧评认为扫兴。要用"开头的梦 = 结尾的真相"，梦里只给一点点，比如只看见吊坠、看不见脸
  2. 时间悖论不严谨：特效导演大冈新一说"给出清楚、让人满意的结局"比严格的逻辑更重要；情感单元可以这样，规则战不行
  3. 中段偏平（中文网友）；少女的表演偏硬（日文剧评）
- **台词**：讲谈社《电视君》引用的台词"……这么阴沉！打起精神来嘛。呵呵……你看……我不也这么精神吗……"，中文配音版是"啊，这么没有精神，笑一笑好不好啊"（用户确认出自本集，2026-11-01）。说话人是年老的百合、对象是小时候的矢住，用户确认推测基本准确
- **制作备注**：编剧右田昌万为主，长谷川圭一提供了《时光倒流七十年》等想法；百合原本设想年纪更大，因为由中学生出演改成少女。少女百合由神谷沙耶加饰演，年老的百合由中千子饰演

### TG-11 继承影子的人（第 44 集）

> 单元卡（2026-11-01 按新方法重写）。资料：Ultraman Wiki（集页花絮、邪恶迪迦页、加迪页、正木敬吾页）、口碑汇总（见迪迦来源）。集页只有梗概，经过来自角色页，没有亲眼看过本集。

- **故事**：
  1. （第 43 集）赛科技公司的总裁、天才物理学家正木敬吾造出机器怪兽逼大古变身，查出他就是迪迦，也查出自己和大古一样带着超古代人的基因
  2. 正木认为大古不配独占光：奥特曼应该引导、控制人类进化，而大古帮人，只是为了当英雄的满足感。他把身体练到极限，打倒刚打完怪兽、精疲力竭的大古，抢走了神光棒
  3. 一条野狗把大古领到熊本的山洞里。大古隔着电网，看着正木把神光棒放进装置，化成光粒，和另一座巨人石像融合
  4. 邪恶迪迦降临熊本，配的是瓦格纳的《唐怀瑟》序曲。正木和巨人都控制不了那股力量，它横冲直撞，GUTS 战机被打下来
  5. 石像从前的伙伴加迪，借那条受伤的狗的身体醒来，哭着劝旧主住手，被打得遍体鳞伤
  6. 大古忍着电击，硬穿过电网，夺回神光棒
  7. 迪迦赶到时，邪恶迪迦当着他的面杀了加迪
  8. 迪迦在愤怒中打倒邪恶迪迦；他抱起加迪的尸体，带进太空安葬。正木被捕。那条狗从 GUTS 身边跑过，它还活着
  9. （第 52 集）正木回来，帮 GUTS 复活迪迦，赎了罪
- **情绪和想表达的**：
  - **带走的情绪**：心痛和愤怒。一只像忠犬一样的伙伴哭着唤不回老朋友，死在迪迦面前
  - **想说的那句话**：编剧小中千昭解释集名用"影"不用"暗"：邪恶迪迦不是天生的恶，它仍是真正的奥特曼，只是落到了错误的人手里。力量本身没有善恶；配得上光的不是基因，是拿它去做什么（推测，由正木的指控和集名对照推出）
  - **谁变了**：这一集里正木没有变，要到季终才变；大古被逼着回答"凭什么是我"
- **怎么交给观众**：
  - **第一层：先抛一个刺耳的问题**：正木的指控有一半戳中人。基因一样，大古凭什么独占光？他帮人是不是只为了当英雄？主角第一次被人当面质疑资格
  - **第二层：让主角失去一切**：被打倒、被抢走神光棒、隔着电网眼睁睁看着对手变成"另一个自己"
  - **第三层：让一个无辜的生命先上场**：加迪不会说话，只会哭着劝。迪迦到得刚好晚一步，它死在他面前
  - **第四层：落下来**：愤怒的对决；迪迦抱住加迪（动作演员权藤俊辅即兴，导演保留，成了全集最被记住的画面）；狗还活着，给小观众留了一点安慰
- **对照高光倒推**：
  - 先在乎什么：加迪（只在这一集出现，靠"狗"这个观众天然在乎的形象）
  - 先知道什么：正木和大古基因一样；神光棒被抢就变不了身
  - 先被压到多低：神光棒被抢，加迪被杀
  - 爆点：两个迪迦对决，迪迦抱起加迪
- **为什么成立**：
  1. 迪迦的样子是观众最熟的东西，同一个样子站到对面，冲击不用解释
  2. 第 43 集先铺了一集，正木不是空降的反派
  3. 加迪之前没出现过，却能让人哭：因为它借了一条狗的身体。制作方的出发点就是"狗是人的伙伴"，观众对狗的感情是现成的
  - **前提**：镜像要成立，观众必须先熟悉主角的力量和样子，所以放在第 44 集
- **能借**：
  1. 同一种力量换一个人用就是镜像（和 YR-6、KJ-6 一回事）；镜像的反派要带着一个让主角难以回答的指控
  2. 集名《继承影子的人》和第 1 集《继承光的人》对照，镜像从标题就开始了
  3. 主角先失去变身能力，让伙伴先上场、先牺牲，主角回来时情绪已经蓄满（和 SV 的胶囊怪兽是同一种结构）
  4. 一集内出场的角色要马上被在乎，可以借一个观众天然在乎的形象
  5. 反派之后回来赎罪，在季终收线
- **不能借**：
  1. 加迪是制作方要求的"胶囊怪兽"式角色，靠的是狗的形象。短剧里用伙伴之死，要么让伙伴先露过面，要么用一个观众天然在乎的形象
  2. 瓦格纳的序曲是古典乐，可以用；同类做法换成现代流行乐，就有版权问题
- **制作备注**："假迪迦"的故事原本排在第 30 集，因为制作原因推迟到第 44 集，反而能给大结局埋线。右田昌万和长谷川圭一都提过别的方案，比如长谷川写过一个被欺负的孩子想和古代奥特曼融合的故事

### TG-12 永恒的生命（第 45 集）

> 单元卡（2026-11-01 按新方法重写）。资料：Ultraman Wiki（集页剧情和花絮，含编剧右田昌万、特效导演大冈新一的说法）、口碑汇总（见迪迦来源）。没有亲眼看过本集。

- **故事**：
  1. GUTS 在一片野地里找到一朵奇怪的黄花。大古一看见它，眼前就闪过超古代文明毁灭的画面
  2. 大古在林子里遇见少女特拉；回来时队友们都醉倒在花粉里，特拉觉得好笑
  3. 吉杰拉花开遍了全世界，TPC 全员醉倒，只剩大古和特拉清醒
  4. 特拉的父亲努克现身：父女俩是超古代文明的生化人，靠吉杰拉的提取物保住大脑活了下来。他讲出古代的历史：光之巨人离开了，"可怕的黑暗"将要到来。超古代文明就是在这种快乐里灭亡的
  5. 天黑以后花粉失效，人们却自己上街找花，为了花打架。GUTS 醒来后讨论：人类也许宁愿要快乐的毁灭，也不要痛苦的现实。大古听了很不高兴
  6. 大古想起尤扎莱说他是光，变身。人群喊着"别碰它"，迪迦照样攻击巨花
  7. 迪迦被花粉喷中，被藤蔓倒吊起来
  8. GUTS 赶到开火，同时一些人开始自己动手，毁掉身边的小花
  9. 迪迦烧掉花根。天亮了，努克父女来道谢；大古为毁掉他们赖以生存的花道歉，努克说："生命是短暂的""人类是美好的"，挥手离开
  10. 第二天 GUTS 总结：做决定的是人类，不是迪迦
- **情绪和想表达的**：
  - **带走的情绪**：悬着的不安，人类差一点就选择了沉溺；最后是被古人看了一眼"人类是美好的"那种温柔
  - **想说的那句话**：救不了不想被救的人，只能让人自己放下；生命短暂，所以珍贵（"永恒的生命"这个片名是反讽）。编剧右田昌万说，这集和别的奥特曼不一样，打倒怪兽不等于人们马上清醒，就像戒烟戒酒，光靠警告是停不下来的
  - **谁变了**：一部分人类，自己动手毁了花；努克父女，从靠花活着，到接受生命短暂
- **怎么交给观众**：
  - **第一层：诱惑一开始是舒服的，甚至好笑**：队员们醉倒，特拉在笑。威胁一开始不像威胁
  - **第二层：再让你看见代价**：天黑后人们为花打架；GUTS 自己说出"人类也许宁愿要快乐的毁灭"。这句话是说给观众听的
  - **第三层：主角做一件不受欢迎的事**：在"别碰它"的喊声里攻击。被保护的人反对他
  - **第四层：迪迦最痛的时候，人自己选择**：特效导演大冈新一说，倒吊是为了表现迪迦痛苦挣扎，同时让人们在这时清醒过来、回到迪迦这边
  - **第五层：落下来**：失去生存之本的古人反而道谢，把"短暂"和"美好"连在一起
- **对照高光倒推**：
  - 先在乎什么：这一集的人物锚点比较弱，努克父女出场晚；它主要靠问题本身，和超古代文明的谜（推测）
  - 先知道什么：超古代文明就是这样灭亡的
  - 先被压到多低：人群喊"别碰它"，迪迦被倒吊
  - 爆点：人们自己毁掉身边的小花；努克的道谢
- **为什么成立**：
  1. 问题观众自己身上就有：编剧拿戒烟戒酒做比
  2. 它同时是揭秘集：超古代文明为什么灭亡，观众本来就想知道
  3. 和第 25 集是一对（网友也指出），观众已经见过一次"人群站到对面，又回来"
  - **前提**：贯穿线要先吊足胃口，揭秘才有人想听
- **能借**：
  1. 对手是一种诱惑，不是一个敌人；迪迦能打倒巨花，打不掉人们想要它的心
  2. 最后的胜利有一部分来自普通人自己动手（和 TG-9 互相呼应）
  3. 揭秘集同时当主题集：揭开的过去，就是现在的人要面对的问题
  4. 片名反讽
- **不能借**：
  1. 写"戒断"太写实，儿童向作品里没法写；编剧最初想写说服沉溺者戒掉，发现写不出来，才改成以迪迦为中心。短剧要找一个能用画面讲清的"放下"
  2. 人物锚点弱，口碑只到第二档，可能和这个有关（推测）；剧本也难写，努克的台词是涩谷浩康帮忙写的
- **制作备注**：灵感来自松本零士的《银河铁道 999》（用机械身体换永生）

### TG-13 复活的鬼神（第 16 集）

> 单元卡（2026-11-01 按新方法重写）。资料：Ultraman Wiki（集页剧情和花絮）、口碑汇总（见迪迦来源）。口碑主要来自一篇日文博客（D，排第 3）和一份中文推荐（F），证据比别的集薄。没有亲眼看过本集。

- **故事**：
  1. 三个小偷夜闯山里的神社，偷走一把剑和一尊像去卖。路过的警察看见地面震动，一只巨手从山坡里伸出来
  2. GUTS 赶到。老警察讲起传说：一个流浪武士打倒了强大的鬼神宿那鬼，把它切碎分开埋葬，然后继续云游斩妖
  3. 小偷们吃午饭时，其中一个良心不安，回到车上，被武士的魂附身。他打晕头目，逼另一个开车送他回神社

  5. 大古去追一个走在山路上的男人，有时看他像个武士。武士说大古"不是人，但不是威胁"，又说鬼神的恨比当年更深了，这次他一个人打不过
  6. 鬼神现身，武士离开小偷的身体
  7. 迪迦和鬼神打得不相上下；迪迦从背后抱住它，被它脑后的第二张脸偷袭；鬼神从山里抽出自己的刀
  8. 迪迦砍下鬼头，鬼头飞起来咬住他的肩膀，他越来越弱

  - **谁变了**：良心不安的小偷，被附身以后成了传话的人
  - **这张卡说明的事**：三个问题答得比别的集轻，照样上了口碑。娱乐集也能封神，靠的是"人"（喜剧演员）和"熟悉的传说"，不是主题
- **怎么交给观众**：
  1. **喜剧先行**：三个蠢贼内讧。导演川崎郷太和摄影仓持武弘商量后，刻意避开严肃的调子；小偷请了搞笑组合客串，笑点来自人物，不来自台词
  2. **传说一口气讲完**：老警察几句话交代清楚斩鬼、分埋、复仇，观众一听就懂
  3. **两个守护者认出彼此**：跨了几百年的武士和大古，一个人一个巨人，互相认出是同行（推测）
  4. **每一招都是怪谈的套路**：脑后的第二张脸、飞起来咬人的头、自己飞起来的剑
  5. **最没出息的人来收尾**：小偷成了武士和大古之间的传话人
- **对照高光倒推**：
  - 先在乎什么：不靠在乎，靠好笑和好奇
  - 先知道什么：传说（斩鬼、分埋）；剑是关键
  - 先被压到多低：飞起来的鬼头咬住迪迦
  - 爆点：剑自己飞起来，传说兑现
- **为什么成立**：
  1. 52 集的长篇需要换口味的集
  2. 民间传说的规则几乎零成本，观众自带
  3. 写的人选了自己喜欢的题材
  - **前提**：观众已经熟悉正常的怪兽集，换口味才显得新鲜
- **能借**：
  1. 拿观众熟悉的民间传说当单元：规则一听就懂
  2. 长篇单元剧里，需要这样的集来换口味；喜剧感来自人物，不来自台词
  3. 让配角来认出主角的本质，主角不用自己说
- **不能借**：
  1. 初稿是"怪兽把车困在隧道里"，被推翻后编剧川上英幸改用自己喜欢的妖怪传说重写。题材要选写的人真心喜欢的
  2. 短剧集数少，纯换口味的集要慎重放位置（推测）

### TG-14 我看到了奥比科（第 27 集）

> 单元卡（2026-11-01 按新方法重写）。资料：Ultraman Wiki（集页花絮、怪兽奥比科页，含编剧太田爱、制片丸谷嘉彦的说法）、口碑汇总（见迪迦来源）。集页只有梗概，经过来自怪兽页，没有亲眼看过本集。

- **故事**：
  1. 三个月来，日子野村每晚都出现一个推着路边摊的厨子，用影子戏吓唬人；最近一个被抓走的男人，五分钟后在山里被发现，昏迷不醒，头发全白。GUTS 来调查
  2. 夜里巡逻，新城听见一个孩子的声音，叫他"一起和奥比科玩"。他记住了堀井奶奶的话，没有回头，厨子就消失了
  3. 厨子撞见大古和堀井，转身就跑；被围住时召出影子，消失了。大古往它的锅里扔了一个追踪器，追到一口井
  4. 神社的神主拿着井里吐出来的追踪器出现，说出原委：这里从前是奥比科最喜欢的地方，村里要盖健身乐园，它发怒了
  5. 村民们互相提醒：夜里待在家里，看见路边摊就跑。奥比科又出来吹起路边摊的笛子，在黑暗里来回瞬移，把 GUTS 戏弄了一遍
  6. 全村夜里闭门熄灯，GUTS 在井边放鞭炮把它引出来。它看见村子恢复了从前的样子，高兴得跳起来
  7. 大古求它离开，它不肯，一气之下变回真身，变成巨人
  8. 迪迦只防守、不还手；奥比科的动作被设计得像小孩在打闹
  9. 奥比科看着眼前的村子，自己迎上迪迦的手刀，两个都化成光粒
  10. GUTS 明白了：它吓人，是因为不想被忘记
- **情绪和想表达的**：
  - **带走的情绪**：开头是鬼故事的毛骨悚然，结尾变成一股乡愁（网友评价）
  - **想说的那句话**：编剧太田爱说，故事的起点是"一个总在回想已经消失的东西的角色"，想让孩子理解人和地方的失去
  - **谁变了**：GUTS 和观众看它的眼光，从怪物变成念旧的老东西；奥比科自己，从不肯走，到选择在最喜欢的样子里结束
- **怎么交给观众**：
  - **第一层：先吓你**：夜里的路边摊、影子戏、白了的头发、"别回头"，全是日本怪谈的熟套路。太田爱最初就想要很重的夜晚气氛
  - **第二层：再让你笑**：它戏弄队员，像小孩恶作剧，打斗动作也设计成孩子打闹
  - **第三层：动机一揭开，鬼故事就翻成了乡愁**：健身乐园、从前最喜欢的地方，一句话就够
  - **第四层：给它一晚上的从前**：全村为它熄了灯，它看见村子回到旧日的样子，高兴得跳起来。这是人类送它的礼物，也是全集最温柔的一刻（推测）
  - **第五层：让它自己选择结束**：迪迦只守不攻，它看着村子，自己迎上手刀
- **对照高光倒推**：
  - 先在乎什么：它最喜欢的那个地方，也就是村子本身
  - 先知道什么：它怕光（照相亭的闪光灯伤过它）；它为什么闹
  - 先被压到多低：它不肯走，非打不可
  - 爆点：它自己迎上手刀，化成光粒
- **为什么成立**：
  1. 怪谈的规则观众自带，零成本
  2. 乡愁的处境人人都有：从小待的地方被拆掉、被开发
  3. 恐怖到温情的翻转，只靠一个动机就完成了
  4. 写的人是真心的：太田爱原本把奥比科想象成一个老人，只活在怀念里
  - **前提**：前面吓得够，翻转才有落差
- **能借**：
  1. 对手吓人的动机，是怕被遗忘：动机一揭开，鬼故事就变成了乡愁
  2. 在送走对手之前，先给它一次它想要的东西
  3. 主角选择只守不攻，对手自己选择结束（和 YR-8 的"单元高潮是一个选择"相通）
  4. 熟悉的怪谈套路当外壳
- **不能借**：
  1. 原剧本和制片人的结局是"迪迦把虚弱的奥比科送到远离人类的地方"，因为"奥比科什么坏事都没做"；导演川崎郷太拍摄时擅自改成了它自己消散，制片人看片后很不满，当面质问导演。结局要事先和团队对齐
  2. 太田爱设想的老人形象，被设计成了更活泼的样子；白天戏也是后来加的。情绪基调和角色设计要一致（推测）
- **制作备注**：片名致敬《奥特 Q》的《我看到了鸟》。导演还加了山里的僧人其实是狸猫之类的细节，强调村子里残留的传统和神秘

### TG-15 蓝色夜晚的记忆（第 29 集）

> 单元卡（2026-11-01 按新方法重写）。资料：Ultraman Wiki（集页、纳塔恩星人页）、三篇日文剧评、讲谈社 TELEMAGA、中文影评摘要（来源见迪迦来源）。没有亲眼看过本集，镜头、舞台细节说不准。

- **故事**：
  1. 当红歌手来栖玛雅人气大到粉丝有专门的称呼。真弓拉着大古去看她的演唱会，矢住吃醋，丽娜冷眼旁观。开场曲是《Be My Baby》的翻唱
  2. 新城试飞出事，差点死掉，醒来像变了个人，迷上了玛雅
  3. 真相：玛雅身体里住着一个外星女孩。十五年前她流落地球，附在一个刚在车祸中死去的女孩身上，从此用这个名字活着。附在新城身上的，是她失散十五年的哥哥，来接妹妹
  4. 她们的故乡被曾经的友邦纳塔恩星人灭了，母亲被杀，哥哥被抓后逃出。哥哥对大古说"故乡已经没了，要和同伴去找新的地方"，对妹妹却说"我们回出生的那颗星球"
  5. 兄妹重逢，哥哥解释为什么十五年都没能来接她
  6. 纳塔恩星人附在路人身上追到地球，开枪打死了附在新城身上的哥哥。大古怒喊"践踏自由，算什么正义！"，迪迦不到一分钟就消灭了它
  7. 新城醒来，人没事。为了不让玛雅知道哥哥已死，他假装还是哥哥，劝她"留在地球吧"
  8. 玛雅看穿了，没有说破，扑进了新城的怀里
  9. 出道一周年的舞台上，她唱了一首送给哥哥的《蓝色夜晚的记忆》
- **情绪和想表达的**：
  - **带走的情绪**：孤独。一个被万人喜爱的明星，其实是这个星球上最孤独的人；中间有过一次回家的希望，又被拿走；最后她选择留下来
  - **想说的那句话（推测）**：故乡没了以后，人要在异乡把自己活下去，留下来不是被困住，是自己的选择；爱一个人，有时就是替他撒一个谎；越热闹的人越可能孤独。编剧长谷川圭一说，他想写的是"留在地球上的辉夜姬"，一个充满孤独的故事
  - **谁变了**：玛雅，从等着被接回家，到自己决定留下
- **怎么交给观众**：
  - **第一层：在你知道真相之前，先让你看见她的热闹**
    1. 开场全是热闹：全民偶像、演唱会、队员们吃醋，一首欢快的老歌翻唱
    2. 后来才揭开连名字都不是她的。前面越热闹，揭开以后越孤独
    3. 新城的"追星"先被当成笑话，后来才知道是哥哥在找妹妹：同一个行为，先让你笑，再让你心疼
  - **第二层：让你比她先知道残酷的事**
    1. 哥哥对大古说故乡没了，对妹妹说"回家"。从此她每期待一次回家，观众就疼一次（和 TG-10 后视镜挥手同一种做法：她不知道，你知道）
    2. 十五年的道歉："终于被找到"的委屈和欢喜，是全集最暖的地方，也是为失去蓄力
  - **第三层：打斗一闪而过**
    1. 迪迦和敌人的战斗不到一分钟，是迪迦里最短的战斗之一。大古一句怒喊、一道光线，愤怒一闪就过去，镜头马上回到妹妹身上。打斗短，是为了不打断情绪线
  - **第四层：她怎么知道，又怎么接受**
    1. 第二个谎言：新城假装还是哥哥，劝她留下。一集里两个"哥哥"都在为她撒谎
    2. 她看穿了却不说破，扑进新城怀里。不用台词，观众从这个拥抱里就明白：她知道了，她接受了，她决定留下。中文影评指出，新城的话其实没起作用，她是在拥抱以后才决定留下的
    3. 最后的告别放在舞台上：万人面前，她为一个没人知道的人唱歌。一场在上万人面前举行、却没有人知道的葬礼（推测，由剧评"明星的孤独"推导）
    4. 情绪交给一首观众熟悉的歌：《蓝色夜晚的记忆》是 Procol Harum《苍白的浅影》的日文翻唱，歌词由编剧长谷川自己写。那段旋律本身就自带哀伤；剧评说歌和配乐配得极好，满屏的星空让宇宙显得又静又远
  - **人类这边的镜子（推测）**：新城自己也有妹妹真弓，日文剧评读出这一集也是真弓和新城吵架后的和好。新城去替一个外星哥哥扮演哥哥，可能正因为他自己就是哥哥
- **对照高光倒推**：
  - 先在乎什么：她的热闹，以及热闹背后十五年的孤独
  - 先知道什么：故乡已经没了，观众比她先知道
  - 先被压到多低：哥哥死在她面前
  - 爆点：那首歌，不是打斗
- **为什么成立**（为什么几乎没有打斗、主角戏份很少，照样被叫作神回）：
  1. **它给的情绪又多又稀有**：普通怪兽战给的是"爽"，看过几十场以后越来越薄；这一集给的是"孤独"和"送别"，整部剧里很少有。迪迦口碑前两档里，第 16、27、29、36 集都不是靠打斗出名的
  2. **壳一点没缺，只是压短了**：外星人、GUTS、变身、必杀都在。观众对"迪迦会赢"本来就有把握，一分钟打完不会觉得被骗；憋了一集的愤怒一下释放，爽被压缩了，没有消失
  3. **主角其实是换了一个**：这一集的主角是观众跟了二十八集的核心队员新城，视角只跟着兄妹一条线
  4. **处境人人都有过**（推测）：没有人是流落地球的外星少女，但几乎每个人都有过"在热闹里觉得没人懂我"、想家又回不去的时刻
  5. **写的人是真心的**：这是长谷川刚入行当布景助理时自己构思的故事
  6. **"封神"考验的是被记住**（推测）：几十场打斗会混在一起，一首在万人面前为无人知道的人唱的歌会单独留下来
  - **前提**：它是 52 集里的一集，稀少才珍贵；它花掉了前面二十八集对新城的积累；壳还在跑；情绪线足够强，强到能顶替打斗
- **能借**：
  1. 让观众比角色先知道一个残酷的事实，再看角色说出满怀希望的话
  2. 为对方撒谎的人，加上一个看穿却不说破的人：情绪全在没说出口的那部分
  3. 公开场合里的私人告别：越热闹的场面，告别越孤独
  4. 用一个人类配角，去照外星人的关系
  5. 核心角色立住以后，隔一段放一集"情绪集"：打斗压到最短，让观众已经在乎的配角当主角，用一种稀有的情绪换口味
- **不能借**：
  1. 借现成老歌有版权问题：短剧要用原创旋律，或找别的自带情绪的熟悉元素
  2. 故事原本是一小时的长度，被压成了 30 分钟；导演原田昌树（这是他在奥特曼系列的导演处女作）一开始也怀疑迪迦戏份这么少适不适合拍。主角退后的单元，要先想清楚用什么撑住节奏
  3. 反派只是工具（剧评说它"又弱又卑鄙"）：能这样做，是因为情绪全在兄妹身上；重心在打斗上的单元不能这样处理反派
  4. 试播集和前几集不能这样做：观众还不认识任何人，只能先用打斗和规则留住他
- **待核实**：哥哥对妹妹说"回家"的原话；舞台那场戏的具体样子 ⚠️待核实
- **制作备注**：长谷川说这个故事最初写的是一小时的长度；"玛雅"这个名字来自赛文第 37 集的玛雅（SV-4），两个玛雅的境遇正好相反（日文剧评）。片中歌曲由圆谷旗下歌手须藤瞳演唱，演玛雅的是田中规子

- **怎么交给观众**（七种做法）：
  1. **替别人作证**：不说"我"，说"他""德班"。一个人站出来替另一个人说话，尤其是替被当成怪物的存在说话（第 16、17、21、49 集）
  2. **观众知道，说话人不知道**：同一句话，说的人觉得平常，听的人知道它的分量（第 4、29、36 集）
  3. **拒绝讲道理**：道理是对的，人偏不听；一个关心主角的人给了他放弃的许可，他用"听不懂"拒绝（第 33、51 集）
  4. **最朴素的愿望，像小孩说的话**：回家、被爱、永远、再见（第 9、11、15、27 集）；大动机底下藏一个小孩的害怕，变强是因为"没人爱我"（第 11 集）
  5. **主题用大白话说，说的人是付出代价的那个**（第 8、25、44、45、52 集）
  6. **只喊一个名字**（第 32 集）
  7. **最不配的人说出最深的话，或者只是转述**（第 16 集，小偷转述武士）
  - **形式**：句子故意不工整，会重复、会断掉："没有人，没有人会爱我""永远永远永远""我不能……我不能啊"
- **为什么成立**：
  1. 每一句前面都有铺垫：观众已经知道代价、身份或结局
  2. 说话的人有分量：要么是付出代价的人，要么是最没资格说的人
  - **前提**：台词前面的戏必须先写好；单拿出来，这些话都很普通
- **能借**：
  1. 高潮台词让单元角色或配角说，而且替别人说
  2. 让最不配的人说出最深的话，或者让他转述
  3. 让一个关心主角的人给他放弃的许可，主角用一句"不懂""不行"拒绝
  4. 大动机底下藏一个小孩式的害怕，在高潮时说出来
  5. 句子允许重复、断掉，不要写得太工整
- **不能借**：
  1. 借的是做法，不是句子
  2. 主题大白话只能在铺够以后说，放在前几集就是说教

## 铠甲勇士（KJ）

> 资料主要来自维基百科和百度百科，维基条目本身标着"来源不足"。

### KJ-1 五行铠甲的分工

> 机制卡（2026-11-01 按新方法重写）。资料：中文维基《铠甲勇士》（页面标了"缺少来源""粉丝观点"）、百度百科。没有亲眼看过全剧。

- **类型**：团队定位
- **经过**：
  1. 五套铠甲对应金木水火土：炎龙侠（火）、风鹰侠（木）、黑犀侠（水）、地虎侠（土）、雪獒侠（金）。百科说炎龙侠最均衡、风鹰侠最快、黑犀侠防御最强 ⚠️待核实
  2. 每个召唤人都带着自己的事：炘南是钢琴家，外冷内软，心情只从琴声里出来；东杉害羞、没主见，爷爷是上一代风鹰侠；北淼是孤儿出身的富家子弟，多疑偏激，一直想当领导；坤中年纪最小，爱打篮球；西钊从小被影界抓走训练，是从敌人那边过来的
  3. 队里的冲突来自人，不来自能力：北淼为了领导权打伤炘南，又一直排斥西钊；坤中靠打篮球和西钊交上朋友，把他劝了过来
  4. 大结局五个人团结起来，合体成帝皇侠（KJ-4）
- **情绪和想说的**：
  - **带走的情绪**：五个人凑不到一起的别扭，到最后合成一个的痛快（推测）
  - **想说的那句话**：五行要团结，才能召出最强的那一个（推测，由大结局的合体推导）
  - **谁变了**：北淼，从排斥别人，到和西钊冰释前嫌
- **怎么交给观众**：
  1. **一个元素一句话**：五行是观众从小就熟的分类，不用教
  2. **队伍的戏在人和人之间**：谁想当头、谁不被接纳、谁去拉谁一把
  3. **合体当作和解的结果**：能力上的"合"，要等关系上的"合"
- **为什么成立**：
  1. 五行零成本，观众一看就能分清谁是谁
  2. 冲突放在召唤人身上，能力的同质被人物的差异补上了一部分
  - **前提**：每个召唤人都要有一个自己的心事
- **能借**：
  1. 队伍里每人一句话说得清的定位，用观众熟悉的分类（五行、生肖这一类）
  2. 队内冲突来自人，不来自能力：争领导权、排斥新人
  3. 合体要等关系先合
- **不能借**：定位是数值型的（速度、防御），和 TG-2 同一个毛病。我们要让每个人的能力差在规则上

- **类型**：仪式

- **量级**：不适用
- **代价**：不适用
- **分几层**：不适用

### KJ-3 伙伴一个个进队

> 机制卡（2026-11-01 按新方法重写）。资料：中文维基《铠甲勇士》（页面标了"缺少来源""粉丝观点"）、百度百科。登场集数来源不一致。

- **类型**：伙伴集结
- **经过**：
  1. 炘南、东杉、北淼是最早的三个人，联手封印了反派影霸手下的异能兽
  2. **地虎侠是从反派手里转过来的**：土影石先被影霸抢走，他本是土影村的后人，变成地虎侠，却被同伴告密，在围攻下死去，临死前把土影石托付给东杉；后来坤中被测出能召唤地虎铠甲
  3. **雪獒侠是从敌人变过来的**：西钊十年前被抓走，替影界卖命，但本性不坏。他和坤中因为打篮球成了朋友，放过炘南以后被界王用高压电惩罚，变身逃出来，加入了铠甲勇士
  4. 加入以后他仍被北淼处处排斥，后来因为张健的背叛、北淼得知他的过去，两人才和好
  5. 登场集数：炎龙侠第 2 集，风鹰侠第 3 集，黑犀侠第 10 或 13 集 ⚠️待核实（来源不一致）
- **情绪和想说的**：
  - **带走的情绪**：期待"下一个是谁"；以及一个前敌人终于被接纳的释然（推测）
  - **想说的那句话**：来路不同的人，也能成为一队（推测）
  - **谁变了**：西钊，从影界的人变成伙伴；北淼，从排斥到接纳
- **怎么交给观众**：
  1. **三种进队方式**：一开始就在的、从反派临死托付过来的、先当敌人再倒戈的。每一种进队都是一个单元
  2. **进队不等于被接受**：西钊加入以后还要再过一关，被排斥本身是一条线
  3. **友情先于入队**：坤中和西钊先因为篮球成了朋友，倒戈才有理由
- **为什么成立**：
  1. 进队方式换着来，不会每次都一样
  2. 倒戈有一个具体的人做桥梁，不是突然变好
  - **前提**：前敌人的"本性不坏"要先露出来
- **能借**：
  1. 伙伴逐个出场，对应框架"先露面，后展开"
  2. 进队方式换着来：原班人马、反派临死托付、敌人倒戈
  3. 倒戈前先让他和某个队员交上朋友
  4. 进队以后再被排斥一段，被接纳是第二个情绪点
- **不能借**：节奏细节未查全，登场集数核实后再下结论

### KJ-4 帝皇侠：最强形态先落在敌人手里

- **类型**：压制战 → 阶段高潮
- **规则**：帝皇侠第 46 集正式登场。召唤有两种方式：拥有五村血脉的人单独召唤，或五人合体召唤
- **量级**：向阳被黑帝控制后变成帝皇侠，召唤出远古四大恶兽
- **代价**：向阳之后身体虚弱，暂时无法再召唤
- **分几层**：向阳被控制成为帝皇侠 → 在敏慈的阻止下恢复意识 → 结局黑帝被暗影五护法残魂附身成为暗影黑魔兽，五位铠甲勇士合体成帝皇侠将它封印
- **情绪**：羁绊
- **能借**：
  1. 最强形态先出现在敌人一方或被控制的人身上，第一次露面就是压制战，量级先立住
  2. 再由主角们靠羁绊（五人合体）夺回来，成为阶段高潮
- **不能借**：原作走完这个过程用了四十多集，短剧要压到一个单元里

### KJ-5 暗影五护法附身，必须对方完全同意

- **类型**：反派规则
- **规则**：暗影五护法要附身他人才能在人间行动，而且必须得到对方完全同意。冰儿曾被恶水护法附身，结局摆脱控制，与北淼重归于好
- **量级**：不适用
- **代价**：被附身者失去自我
- **分几层**：不适用
- **情绪**：被诱惑、被救回
- **能借**：反派规则里写着"受害者必须同意"，每次附身都是一个人的心结和选择（可与 YR-2、TG-4 连起来看）
- **不能借**："同意"不拍出诱惑的过程，就是一句空设定

### KJ-6 铠甲能换人，也有人叛变

> 机制卡（2026-11-01 按新方法重写）。资料：中文维基《铠甲勇士》（页面标了"缺少来源""粉丝观点"）、百度百科。

- **类型**：同一能力的镜像；资格被考验
- **经过**：
  1. 北淼为了争领导权把炘南打成重伤，炘南交出炎龙铠甲的控制权，张健接替他成为炎龙侠
  2. 张健控制不住心魔，被暗影五护法利用，大家这才发现他就是内奸。炘南放下前嫌，和张健一对一决斗，夺回了炎龙铠甲
  3. 一队中了五护法的圈套，五个人为了救北淼强行解除铠甲，身体重伤。两个月后，他们亲眼看到二队的战斗力更强，主动交出了召唤器
  4. 二队为了消灭五护法，不惜拿孤儿向阳当诱饵。美真因为二队的做法，收回了他们召唤铠甲的权限，一队重新出山
  5. 地虎铠甲也换过人：反派影霸、坤中、二队的方中
- **情绪和想说的**：
  - **带走的情绪**：力量被夺走、被让出，再拿回来；被背叛的愤怒
  - **想说的那句话**：铠甲认的是人心，不是战力（推测，由美真收回二队权限推导）
  - **谁变了**：炘南，从交出铠甲到亲手夺回；一队，从自愿让位到重新被选上
- **怎么交给观众**：
  1. **资格是可以丢的**：铠甲是装备，人能换。主角组随时可能不再是主角组
  2. **内奸就在队里**：接替炘南的人恰恰是被利用的那个
  3. **更强的一队是一面镜子**：二队战力更强，但为了赢不择手段。观众看着他们，就明白了一队凭什么是一队
  4. **有人握着"资格"**：美真可以解除召唤人资格，力量背后有一个看人心的裁判
- **为什么成立**：
  1. 同一套铠甲在不同人手里，差别只能落在人身上，镜子一照就清楚
  2. 让主角自己让出力量，再看到别人用错，回来就有分量
  - **前提**：观众已经认准了一队这几个人
- **能借**：
  1. 同一套能力在不同人手里就是一面镜子（和 YR-6 一回事）
  2. 更强但不择手段的"二队"，用来反衬主角组凭什么是主角组
  3. 能力背后有一个按人心收回资格的裁判
- **不能借**：换人太频繁，观众记不住谁是谁

### KJ-7 异能兽：每集都来的理由

- **类型**：叙事壳
- **规则**：五千年前暗影大帝派人带 55 颗魔灵石入侵地球，魔灵石和地球生命结合变异成异能兽。第 1 集异能兽袭击渔民，受害者都失去了某段记忆
- **量级**：不适用
- **代价**：不适用
- **分几层**：不适用
- **情绪**：不适用
- **能借**：
  1. 对手从哪来用一条统一规则说清，"为什么每集都来一个新对手"就有了答案
  2. 55 颗魔灵石天然是计数器，观众知道还剩多少（类似七龙珠的收集）
- **不能借**：规则太死，每只异能兽就是"一颗石头 + 一种生物"的流水线，每只还得有自己的故事（参见 TG-4、TG-5）

## 假面骑士（KR）

> 选了三部规则设计差异最大的：空我、龙骑、W。资料以英文维基和粉丝 wiki 为主。

### KR-1 空我的形态：武器要从环境里拿

- **类型**：变强方式 A（换形态），差在规则而不只是数值
- **规则**：
  - 青龙形态：速度最快、跳得最高，但力量比基础形态弱；把长棍类物件重构成青龙棍
  - 天马形态：感官提升到极限，能精准远射；要先拿到"能射出东西"的物件（常是一条警官的手枪）才能变出天马弓枪
  - 泰坦形态：力量和防御最强；把棒状物件（常是摩托车把手）变成泰坦剑
- **量级**：不适用
- **代价**：每种形态都有短板（青龙弱、天马脆、泰坦慢）
- **分几层**：基础形态 → 按战况换形态 → 后期 Rising 强化
- **情绪**：不适用
- **能借**：换形态有条件（先找到对应的物件），换形态本身就成了战术决策，也给了画面"在战场上找东西"的动作。这是 TG-2、KJ-1 的对照：形态差在规则和条件上，打法才会不一样
- **不能借**：每次都要找物件，节奏会拖。短剧里物件要提前在场景里摆好（铺垫）

### KR-2 空我的古朗基：反派自己有游戏规则

> 机制卡（2026-11-01 按新方法重写）。资料：Kamen Rider Wiki（"Gegeru"页、恩·达古巴·泽巴页）。代表场面是规则一级级收紧的过程，和最终战。没有亲眼看过全剧。

- **类型**：反派规则，叙事壳；长线对手
- **经过**：
  1. 古朗基族在玩一场杀人游戏"杰格尔"。裁判决定谁上场、什么时候开始；一次只派一个出手，规定杀人数和时限
  2. 开始前，裁判把爆炸能量注入挑战者的腰带：时间到了还没完成，或者被判弃权，就会自爆；完成了，能量变成他的力量，晋升一级
  3. 等级越高，规则越严：最低一级只规定人数和时限，杀法随意；中间一级要自己报进度，不报就算弃权；最高一级必须提前报上杀法和地点，不按报的来就不算数，由裁判用一个算盘计数，算盘坏了就从头算
  4. 于是每个高级怪人都有一套自己的"谜题"：按东京 23 区日语读音的顺序，每区杀 9 人；按肖邦《革命练习曲》的乐谱在泳池里杀人；按自己指甲上颜色的顺序，挑颜色对得上的车和电梯下手
  5. 游戏的终点是挑战首领达古巴。首领先杀了 152 个同族，嫌它们"低等"；没有人完成最终游戏，他就亲自动手灭绝人类，还故意给受伤的空我时间变强
  6. 最终战在雪山上：五代雄介变成能控制住的究极形态，和达古巴打到两人的变身都撑不住、腰带里的石头都碎了，就赤手空拳互殴。达古巴笑到最后一刻，说五代很快也会像他一样暴力。五代是哭着打的 ⚠️待核实（广为流传的说法）
- **情绪和想说的**：
  - **带走的情绪**：恐惧；以及最后一战里，主角越赢越痛苦
  - **想说的那句话**：暴力就算是为了保护别人，也会伤到打的人自己（推测，由最终战推导）
  - **谁变了**：五代，那个一直笑着说"不想看到别人哭"的人，最后要用最暴力的样子去打（推测）
- **怎么交给观众**：
  1. **反派有自己的规矩**："为什么一集一集来"有了答案，每集一个挑战者
  2. **规矩自带倒计时**：杀人数和时限，每集都有紧迫感
  3. **规矩一级级收紧**：高级怪人的杀人方式本身是一道谜，警方和空我要先查出"他按什么规律选人"，才能抢在前面。查规律就是一场规则战
  4. **游戏的终点是首领**：长线对手一直在等，等所有人都失败，再亲自下场
  5. **最终战回到最原始的打法**：力量全耗尽，只剩拳头。打赢不是痛快，是代价
- **对照高光倒推**：
  - 先在乎什么：五代"不想看到别人哭"
  - 先知道什么：游戏规则；究极形态可能让人失控
  - 先被压到多低：首领亲自下场，开始在长野有计划地屠杀人类
  - 爆点：雪山上的赤手互殴
- **为什么成立**：
  1. 一条规则同时解决了"为什么一集一集来"和"怎么查"两个问题
  2. 规则越到后面越复杂，正好对应观众越看越熟、越想解谜
  - **前提**：规则要在早期就交代清楚，后面只加限制，不改基本逻辑
- **能借**：
  1. 反派有自己的规则，"为什么一集一集来"就有了答案（和 KJ-7 一回事）
  2. 杀人数和时限就是倒计时，每集自带紧迫感
  3. 每个怪人选人的规律不同，查出规律本身就是一场规则战
  4. 规则按等级收紧，季中季末的对手自然更难
  5. 长线首领站在游戏的终点等，不用早早出手
- **不能借**：
  1. 杀人游戏的残酷程度要按平台尺度调整
  2. 乐谱、读音这类规律太绕，短剧要换成一眼能看懂的规律

### KR-3 龙骑：十三个骑士的大逃杀

- **类型**：限制逼选择；伙伴即对手
- **规则**：十三个骑士在镜世界里互相厮杀，最后的胜者能实现一个愿望。骑士借契约兽的力量变身，用 Final Vent 和契约兽合击。代价是要用打倒的怪物的生命喂契约兽；卡组被毁或退出不当骑士，契约兽就可能反噬主人 ⚠️待核实（出自维基镜像）
- **量级**：不适用
- **代价**：不打就可能被自己的契约兽吃掉
- **分几层**：不适用
- **情绪**：每个骑士为了自己的愿望而战，没有纯粹的反派
- **能借**：
  1. 限制逼人做选择：不打，契约兽就反噬；打，就要伤害别人。和 OP-8 一样，属于"逼选择"型限制
  2. 每个对手都有自己的愿望，打斗的情绪来自"他为什么非赢不可"
- **不能借**：十三个骑士人数太多，短剧撑不住

### KR-4 W：两个人变成一个骑士

- **类型**：组合，把关系写进能力
- **规则**：左翔太郎和菲利普用两个盖亚记忆体插进双驱动器，合成一个假面骑士 W；左右两半各一个记忆体，换着组合出不同形态。牙王记忆体组成的 FangJoker 更强更快，但对菲利普身体负担大、很少用；菲利普只有在翔太郎协助下才控制得住牙王 ⚠️待核实（粉丝 wiki）
- **量级**：不适用
- **代价**：FangJoker 伤菲利普的身体
- **分几层**：基础组合 → 换组合 → 特殊形态
- **情绪**：搭档的信任
- **能借**：
  1. 两人一体：关系就是能力，搭档吵架就打不好，这让关系戏和打斗戏成了同一件事
  2. 两集一个案子：第一集查（谜面），第二集破（解法），对应框架"两三集单元怎么断"
  3. 决胜台词"来，数数你的罪孽吧"，和 KJ-2 的口号一样是仪式
- **不能借**：组合太多观众记不住，短剧控制在两三种

## 超级战队（SS）

> 系列层面的套路为主，资料多为英文粉丝 wiki 和 TV Tropes。

### SS-1 每集的公式：先小打，再大打

- **类型**：叙事壳
- **规则**：怪人出现 → 地面战，用各自的武器和武术 → 怪人被打倒后巨大化 → 召唤机甲合体成巨型机器人 → 必杀。电子战队电子人确立了"打倒后变大"；也有例外，超电子生物人的怪人不会变大
- **量级**：第二场从人的尺度变成楼的尺度
- **代价**：不适用
- **分几层**：两场仗，两种尺度
- **情绪**：仪式感
- **能借**：一集里两场仗、两种尺度，框架"大小对比：先小打，再大打"直接写进了公式
- **不能借**：第二场往往没有新规则，只是换个尺度再打一遍 ⚠️待核实（推论）。第二场要有新东西，否则就是重复

### SS-2 第六人：先当对手，后入队

> 机制卡（2026-11-01 按新方法重写）。代表场面用恐龙战队的龙战士布莱（系列第一个正式的"第六人"）。资料：Power Rangers Wiki（布莱页，含分集经过）、此前整理的第六人资料（见超级战队来源）。没有亲眼看过全剧。

- **类型**：伙伴集结；打出关系；限制逼选择；送别
- **经过（布莱）**：
  1. 1.7 亿年前，布莱是大和族黑骑士的长子。国王想收养他的弟弟格奇当王子，父亲反抗，战死。七岁的布莱无法原谅，独自流亡。弟弟一直不知道自己的身世
  2. 布莱长眠时墓穴坍塌，他已经死了。大兽神和生命之灵克洛托约定让他复活，但醒来以后只能活一段有限的时间
  3. （第 17–18 集）一个崇拜他的少年偷了钥匙，把他放了出来。他变成龙战士，向格奇宣战，投靠魔女班多拉，拿到一把会把仇恨放大成疯狂的剑。格奇得知两人是兄弟，劝他；大兽神命令格奇杀了他，格奇拒绝，受了罚
  4. （第 21–22 集）布莱背叛班多拉，被赶回地球。生命之灵告诉他只剩 38 小时，把他带进一个时间不流动的房间，交给他一支绿色的蜡烛，蜡烛就是他剩下的命。格奇一对一打败他，仇恨之剑碎了。他明白弟弟是真心在乎他，放下复仇，加入了队伍
  5. 他不想让大家知道寿命的事，每次出来帮完忙就马上消失，回到那个房间。第 31 集，他才说出秘密
  6. （第 34 集）他受不了房间里的孤独，走出去，结识了一对母女。女人被班多拉绑走，他去救，剩下的时间不到 5 小时
  7. （第 40–42 集）只剩几个小时。他梦见自己被死神拉着人力车接走，梦里还有一个也快要死的男孩。班多拉毁了那个房间，他被困在外面，时间开始一刻不停地流走。他找到了梦里的男孩小太，吹笛召来龙，带他骑了一回
  8. 小太在战斗中受了重伤。他母亲怪布莱，小太说不是他的错。布莱把自己的恐龙徽章交给小太
  9. 只剩一小时，他回到战场，想的是：只要能救下小太，死也可以。祈祷应验了，徽章在小太手里发出光，所有人恢复了力量，打倒了敌人。他从驾驶舱里消失了
  10. 生命之灵说，他已经死过一次，灵药对他没有用；照他的心愿，把灵药给了那个男孩
  11. 河滩上，格奇抱着他。他说，醒来以后能和弟弟并肩作战，他很高兴；他请大家把灵药留给男孩，最后一次变身，把龙之铠甲和兽奏剑传给格奇，托他守护地球和孩子。蜡烛熄灭了
  12. 死神车夫载他去彼岸，他觉得风很舒服。格奇吹起兽奏剑，最后一次看见了哥哥
- **其他第六人**（旧卡已有）：时间战队的时间火是红战士自负的竞争对手，最后成了队友；爆龙战队的爆龙杀手在最后一刻才倒戈
- **情绪和想说的**：
  - **带走的情绪**：悲壮。一个看得见的倒计时，一点点烧完
  - **想说的那句话**：有限的命要用来做什么？他想做一件有意义的事，又想和弟弟一起活下去，最后选了前者
  - **谁变了**：布莱，从复仇到守护；格奇，从不知道身世到接过哥哥的铠甲
- **怎么交给观众**：
  - **第一层：先当敌人，而且恨得有理由**：父亲被害，他的复仇是可以理解的
  - **第二层：关系揭开，敌人变哥哥**：弟弟宁可受罚也不杀他
  - **第三层：打败了才入队**：一对一，仇恨之剑碎掉，关系在打斗里翻转
  - **第四层：限制看得见**：一支蜡烛。每出手一次，蜡烛就短一截。观众知道，队友起初不知道
  - **第五层：最后几个小时给一个陌生孩子**：他的死不只是为了赢，是为了让一个孩子活
  - **第六层：传承**：把铠甲交给弟弟，力量留在队里
- **对照高光倒推**：
  - 先在乎什么：兄弟之间的血仇和亲情
  - 先知道什么：他只能活有限的时间；蜡烛就是他的命
  - 先被压到多低：房间被毁，时间不再停
  - 爆点：河滩上把铠甲交给弟弟，蜡烛熄灭
- **为什么成立**：
  1. 限制从一开始就是"逼人做选择"的那种，不是节拍信号（和 SV-6 一回事）
  2. 第六人本来就比主角们强，他的倒计时让"强"变成了"贵"
  3. 前后花了二十多集：入队、隐瞒、坦白、孤独、告别，每一步都是一个单元
  - **前提**：限制必须让观众看得见（蜡烛），而且越用越少
- **能借**：
  1. 新核心角色以对手身份先登场，先打一场压制战或切磋战，再翻转关系入队（和 OP-10、YR-5 的"打出关系"一回事）。季中登场正好是一个阶段高潮
  2. 对手的恨要有理由，最好和主角有血缘或旧账
  3. 给最强的伙伴一个看得见、越用越少的限制，让每次出手都是一次选择
  4. 角色离开时把力量传下去，人走了，能力留在队里
- **不能借**：
  1. 每个新伙伴都走"先当敌人"，就成了套路，要换着来
  2. 倒计时型的伙伴只能用一次，而且要舍得让他真的走

### SS-3 海贼战队：前辈的力量就是能力

- **类型**：熟梗当能力；前辈返场
- **规则**：过去 34 支战队在"传说大战"里交出了力量，力量化为大战力钥匙散落宇宙。海贼战队把钥匙插进变身器，就能变成前辈战队的成员，拿到他的外观、战斗方式和必杀技。前辈以平民身份来到地球，先考验海贼战队，再揭示自己战队成功的秘诀。结局时钥匙归还原主
- **量级**：借的是前辈的名声
- **代价**：不适用
- **分几层**：变成前辈 → 前辈考验 → 拿到前辈战队的大力量
- **情绪**：怀旧
- **能借**：
  1. 观众早就认识的东西直接做成能力，每集换一个前辈，就是一个自带情绪的变量（和 TG-7 一回事，镇魂街借历史人物也是同一招）
  2. "前辈考验后传授秘诀"本身就是一种教学战
- **不能借**：靠的是 34 年的积累，新剧没有。我们能借的熟梗是生肖、成语、民间传说

### SS-4 名乘和集体摆姿势

- **类型**：仪式
- **规则**：变身后各自报上名号、摆出姿势，最后集体亮相，背后爆炸 ⚠️待核实（广为人知，但没查到专门来源）
- **量级**：不适用
- **代价**：不适用
- **分几层**：不适用
- **情绪**：仪式感
- **能借**：集体亮相给观众一个确认"人齐了"的时刻，也给每个人一个单独的特写
- **不能借**：短剧时长紧，每人报名号太长，要压成一个镜头

## 妖精的尾巴（FT）

### FT-1 纳兹吞下以太纳诺 vs 杰拉尔（乐园之塔篇，动画第 40 集前后）

> 打斗卡（2026-11-01 按新方法重写）。资料：Fairy Tail Wiki（乐园之塔篇页）。没有逐镜头核对。

- **类型**：死斗，冒险爆发
- **经过**：
  1. 艾露莎小时候在乐园之塔当奴隶，被逼着建造复活黑魔导士杰雷夫的装置；儿时的同伴杰拉尔后来成了这座塔的主人。她和这段过去纠缠了八年
  2. 杰拉尔要拿艾露莎当活祭品。纳兹及时把她拉了出来，开玩笑说他们得回去工作，不然露西交不起房租。艾露莎哭着求他别打，纳兹把她打晕，独自对上杰拉尔
  3. 纳兹打不过，被杰拉尔的流星一次次打倒。他听见杰拉尔说怕塔受损，就专门去砸塔
  4. 杰拉尔要用一招把纳兹和艾露莎一起杀掉。艾露莎挡在纳兹前面，儿时的同伴西蒙又挡在艾露莎前面，替她挨了这一招。西蒙在她怀里说出喜欢她，死了
  5. 杰拉尔在笑。纳兹一拳打在他脸上，然后开始吃塔里的巨大魔水晶以太纳诺，第一次进入"龙之力"
  6. 杰拉尔要用一招毁掉整座塔，却因为之前被艾露莎砍过的伤，魔法失灵了。纳兹说：靠夺走别人的自由，是得不到自由的
  7. 纳兹一拳打倒杰拉尔，昏了过去，艾露莎抱住他。魔水晶失控要爆炸，艾露莎把自己融合进去，救大家
- **情绪和这场仗想说的**：
  - **带走的情绪**：愤怒点燃的爆发；一个女孩背了八年的过去终于被人替她打碎
  - **这场仗证明了什么**：伙伴会替你去打你不敢面对的过去
  - **谁变了**：艾露莎，从一个人扛着过去，到被纳兹拉回来
- **怎么交给观众**：
  - **第一层：先让对手赢**：流星打不着，纳兹一次次倒下
  - **第二层：一个配角死在眼前**：西蒙替艾露莎挡下那一招，说出喜欢她。杰拉尔在笑
  - **第三层：爆发必须冒险**：吃下不是自己属性的魔水晶，可能把自己毁掉。白给的变强不燃
  - **第四层：一句话点破对手**：夺走别人的自由，得不到自由
  - **第五层：爆发的后果转给伙伴**：魔水晶失控，艾露莎牺牲自己，下一段情绪戏直接生出来
- **对照高光倒推**：
  - 先在乎什么：艾露莎八年的过去
  - 先知道什么：纳兹能吃火恢复，别的东西吃了会出事
  - 先被压到多低：纳兹被打倒，西蒙死了
  - 爆点：吃下魔水晶，进入龙之力
- **为什么成立**：
  1. 爆发的导火索是一个配角的死，加上对手的笑，愤怒有具体的对象
  2. 赢的那一下有一半来自艾露莎之前留下的伤，胜利不全是纳兹一个人的
  - **前提**：吃魔水晶的风险要在前面讲清楚
- **能借**：
  1. 爆发必须冒险：白给的变强不燃
  2. 爆发的后果可以转到伙伴身上，直接生出下一段情绪戏（艾露莎的牺牲）
  3. 爆发前让一个配角死在眼前，再让反派笑
  4. 最后一击里留一份别人的功劳（艾露莎的伤）
- **不能借**：吃下魔水晶前要先让观众知道"吃别的属性会出事"，否则就是临时冒出的新能力
- **待核实**：纳兹能不能吃自己的火 ⚠️待核实

### FT-2 艾露莎的换装

- **类型**：变强方式 A（换装），差在克制规则
- **规则**：每套铠甲对应一种战况：海皇之铠抵消水系攻击；天轮之铠一次召出大量剑，专打一对多；炎帝之铠减轻火焰伤害；雷帝之铠克制雷系（对拉克萨斯、马卡洛夫有利）⚠️待核实（二手资料）
- **量级**：不适用
- **代价**：不适用
- **分几层**：按对手换装
- **情绪**：仪式感
- **能借**：每套铠甲差在"克制谁"，不只是数值，观众会预判"这次换哪套"（和 KR-1 一起，是 TG-2、KJ-1 的正面对照）
- **不能借**：铠甲太多，观众记不住。短剧里一个角色最多三四套，每套第一次出场都要用画面教清楚它克什么

### FT-3 纳兹和加吉尔 vs 拉克萨斯（妖精尾巴之战篇，动画第 41 集前后）

> 打斗卡（2026-11-01 按新方法重写）。资料：Fairy Tail Wiki（拉克萨斯页）。没有逐镜头核对。

- **类型**：团战；关系在打斗中兑现；能力规则揭开人心
- **经过**：
  1. 拉克萨斯是会长马卡洛夫的孙子、S 级魔导士。他嫌公会太弱，在收获祭上发动"妖精尾巴之战"，要用武力夺下公会；他说过，接手以后要把弱的成员全部清掉
  2. 加吉尔不久前还是敌对公会幽鬼的人，砸过妖精尾巴的会馆、伤过公会的人，刚刚加入
  3. 纳兹和加吉尔二打一，还是打不过。拉克萨斯进入近乎狂暴的状态，连马卡洛夫可能死都不在乎，要毁掉公会和整座城
  4. 拉克萨斯放出雷龙的长戟要了结纳兹，加吉尔用铁龙棍把雷引到自己身上，替纳兹硬扛下来
  5. 拉克萨斯用出终极魔法"妖精的法律"：它只会伤害施术者认定的敌人。光芒散去，公会的人和城里的居民一个都没有受伤。他的同伴弗利德说出原因：拉克萨斯从祖父那里继承的，不只是魔力，还有珍惜同伴的心
  6. 纳兹打倒了拉克萨斯
  7. 马卡洛夫把他逐出公会。幻想游行上，全公会对着离开的他举起同一个手势（FT-4），他哭了
- **情绪和这场仗想说的**：
  - **带走的情绪**：热血里夹着心酸。反派的终极魔法，暴露了他其实一直爱着这个公会
  - **这场仗证明了什么**：公会是家。前敌人可以用身体证明自己是家人；走歪的家人心里也还是家人
  - **关系怎么变**：加吉尔成了自己人；拉克萨斯从敌人变成被送走的家人
- **怎么交给观众**：
  - **第一层：二打一还打不过**：量级先演够
  - **第二层：前敌人替新伙伴挡招**：加吉尔这一挡，是他第一次用行动证明自己是妖精尾巴的人，不用台词交代
  - **第三层：规则揭开人心**：妖精的法律只伤敌人，结果没有一个人受伤。观众比拉克萨斯自己先知道他的真心
  - **第四层：赢下来，再送走**：打倒他，逐出公会，游行上的手势。打斗的余波是告别
- **对照高光倒推**：
  - 先在乎什么：公会这个"家"；加吉尔刚刚加入、还没被接受
  - 先知道什么：加吉尔以前是敌人；妖精的法律只伤敌人
  - 先被压到多低：拉克萨斯要毁掉整座城，连祖父的死活都不顾
  - 爆点：加吉尔导雷；妖精的法律没有伤到任何人
- **为什么成立**：
  1. 两个关系问题（加吉尔算不算自己人、拉克萨斯还爱不爱公会）都在这一场里用能力回答，不用台词
  2. 终极魔法的规则一句话就能讲清，它的"失败"本身就是答案
  - **前提**：规则要在发动之前或发动的同时讲给观众听
- **能借**：
  1. 前敌人用身体给新伙伴挡招，关系在打斗里兑现，不用台词交代（和 SS-2 的"先当对手后入队"接上）
  2. 用对手的能力规则揭开对手的真心：大招打空了，答案就出来了（和 YR-2 的"心结就是能力的锁"是同一类做法）
  3. 打赢以后紧接着送走，让死斗的余波变成告别
- **不能借**：纳兹吃雷变成"雷炎龙模式"的具体场景和时间 ⚠️待核实，暂不使用

### FT-4 拉克萨斯被逐出公会，和幻想游行上的手势

- **类型**：不是打斗，是仗打完以后的余波
- **规则**：拉克萨斯被打败后回到公会，马卡洛夫含泪把孙子逐出公会。幻想游行时，拉克萨斯在远处看着，马卡洛夫和整个公会一起举起手势，无声地告诉他"我们会一直看着你"。这个手势是拉克萨斯小时候想出来的 ⚠️待核实（粉丝 wiki）
- **量级**：不适用
- **代价**：被逐出公会
- **分几层**：逐出 → 游行 → 手势 → 拉克萨斯落泪
- **情绪**：羁绊；反派被原谅
- **能借**：
  1. 羁绊需要一个具体的、能反复用的动作，光靠台词撑不住
  2. 动作的来历（他小时候发明的）就是铺垫，兑现时一句话都不用说
  3. 单元的情绪高潮可以放在打完以后的余波里
- **不能借**：没有前面的铺垫，手势就只是一个手势

## 镇魂街（ZH）

> 资料以知乎、百度百科、维基百科为主，粉丝整理居多，具体话数大多未核实。

### ZH-1 守护灵：历史人物就是能力

> 机制卡（2026-11-01 按新方法重写）。资料：中文维基《镇魂街》、百度百科、知乎整理（见镇魂街来源）。镇魂街是这一批里证据最薄的：萌娘百科抓不到，代表场面的情绪没有找到评论支撑。

- **类型**：熟梗当能力
- **经过**：
  1. 寄灵人召唤守护灵战斗，守护灵多是历史人物，分人武灵、兽武灵、仙武灵、魔武灵和最强的神武灵
  2. 一个镇魂将最多只能有一个守护灵；能拥有好几个的，叫"武神躯"，百年难得一遇，当今只出现了三个
  3. 曹焱兵是曹操的后人、武神躯之一，守护灵都是三国曹魏名将（许褚、典韦、夏侯惇、夏侯渊、徐晃、张郃、张辽等）。张郃能化成他的铠甲。他初登场时只召唤了许褚一个
  4. 灵域用"地狱道"测强弱，从等活到无间分八等；能毁掉一条街的，是"大焦热"
- **情绪和想说的**：
  - **带走的情绪**：熟悉的人物站在主角身后，期待"下一个召唤谁"（推测）
  - **想说的那句话**：不适用，这是一个能力机制
  - **谁变了**：不适用
- **怎么交给观众**：
  1. **观众自带人物的印象**：许褚的猛、典韦的忠，不用介绍
  2. **数量就是战力**：一个人只能有一个，他能有好几个，稀有感马上出来；召唤了几个，观众数得清
  3. **先放一个**：初登场只召唤许褚，先露面后展开
- **为什么成立**：
  1. 熟梗零成本，量级预期是现成的
  2. "最多一个"的规则让"武神躯"的稀有一句话就能讲清
  - **前提**：选的人物观众真的熟
- **能借**：
  1. 观众早就认识的人物直接做成能力，量级预期是现成的（和 TG-7、SS-3 一回事）
  2. 战力和"召唤了几个"挂钩，观众数得出来；初登场只放一个，就是先露面后展开
  3. 先定一条普通人的上限（一人一个），再让主角打破它
- **不能借**：熟梗要选观众真的熟的。三国武将对中文观众是零成本，生僻人物就没有这个效果

### ZH-2 于禁：赢的代价是失去守护灵

> 机制卡（2026-11-01 按新方法重写）。资料：知乎整理（见镇魂街来源）。只有一份二手来源，具体经过没能再核实。

- **类型**：代价
- **经过**：少年曹焱兵以于禁为代价击败了八神斋的恶灵军团，于禁魂飞魄散；曹焱兵因此得到十殿阎罗与七武将 ⚠️待核实
- **情绪和想说的**：
  - **带走的情绪**：失去
  - **想说的那句话**：力量是用伙伴换来的（推测）
  - **谁变了**：曹焱兵，从少年到背着一个伙伴的命往前走（推测）
- **怎么交给观众**：
  1. **熟梗被改写**：历史上于禁晚节不保（投降关羽），这里让他以牺牲收场，观众会有"原来他还有这一面"的感受 ⚠️待核实（推论，需核对原作有没有这层意思）
  2. **放在回忆里**：牺牲发生在主角的过去，解释他现在为什么是这样
- **为什么成立**：熟梗的历史评价可以被剧情改写，反差本身就是情绪
- **能借**：代价可以是失去伙伴（和 YR-6 一回事）；熟梗人物的"历史评价"可以在剧里被改写
- **不能借**：在回忆里交代的牺牲分量有限，最好让观众先认识这个伙伴再失去

### ZH-3 守护灵要认主

> 机制卡（2026-11-01 按新方法重写）。资料：知乎整理、网易文章（见镇魂街来源）。

- **类型**：关系写进能力
- **经过**：
  1. 夏侯惇、夏侯渊兄弟一同认可了曹焱兵的实力，才追随他
  2. 张辽最初奉曹操为主，直到曹焱兵和十殿阎罗的龙核链接以后，才正式认曹焱兵为主
- **情绪和想说的**：
  - **带走的情绪**：被认可
  - **想说的那句话**：力量不是给你的，是你赢来的（推测）
  - **谁变了**：曹焱兵在守护灵眼里的位置，从"曹操的后人"变成"自己的主公"
- **怎么交给观众**：
  1. **能力有自己的意志**：守护灵会看人，不是道具
  2. **关系的变化等于战力的变化**：多一个人认主，就多一份力量（和 KR-4 一回事）
  3. **祖辈的影子**：张辽先认曹操，曹焱兵要从祖宗的影子里走出来（推测）
- **为什么成立**：认主是一个看得见的关系节点，每认一次就是一个情绪点
- **能借**：
  1. 能力（守护灵）有自己的意志，认可要靠赢来。关系变化直接等于战力变化
  2. 能力原本属于祖辈，主角要让它改认自己
- **不能借**：每个守护灵都走一遍认主，节奏会拖

### ZH-4 曹焱兵被曹操夺舍

- **规则**：守护灵们生前的主公是曹操。剧情中曹焱兵被曹操夺舍，许褚一声"丞相"让观众意识到眼前的已经不是曹焱兵 ⚠️待核实（个人解读文章）

- **代价**：主角失去自我
- **分几层**：不适用
- **情绪**：震惊
- **能借**：熟梗本身带着历史关系（曹操是他们的主公），这层关系可以翻成威胁；一个称呼就能完成揭示，不用解释
- **不能借**：细节未核实，暂只作参考

### NR-1 小李 vs 我爱罗（中忍考试）

> 打斗卡（2026-11-01 按新方法重写）。资料：Naruto Wiki（小李页，含岸本齐史的说法）、日文角色介绍；口碑：Studio Pierrot《火影忍者》动画 20 周年官方"最佳对决"排名第 3。没有逐镜头核对。

- **类型**：死斗，输了但燃
- **经过**：
  1. 中忍考试预选赛，小李对我爱罗。小李不会忍术和幻术，只会体术。他对凯老师说过：要证明不会忍术和幻术，也能成为了不起的忍者
  2. 我爱罗站着不动，沙子自动挡下了他所有的攻击
  3. 凯老师同意以后，小李卸下腿上的负重。负重落地，砸出两个大坑，他的速度暴涨，第一次打中了我爱罗
  4. 表莲华没有成功：我爱罗用沙子分身脱了身
  5. 凯同意他用禁术。小李一门一门打开八门遁甲，开到第五门，用出里莲华。我爱罗把葫芦化成沙子垫在身下，才勉强活下来
  6. 禁术的反噬撕裂了小李的身体，我爱罗趁机压碎了他的左臂和左腿
  7. 凯挡下了我爱罗的最后一击。小李已经昏迷，却又站了起来，摆出战斗的架势
  8. 医生说他可能再也当不了忍者：骨头碎片卡进了脊柱。后来只有纲手能做这台手术，成功率一半。后来他和我爱罗成了朋友
- **情绪和这场仗想说的**：
  - **带走的情绪**：心疼和燃。一个没有天赋的人把一切都押上去，还是输了，昏过去了还站着
  - **这场仗证明了什么**：努力能不能赢天才？这一场的回答是：赢不了，但能让人看见努力有多重（推测）。岸本齐史说，小李和小樱一开始被设计成"人的弱"的象征
  - **谁变了、关系怎么变**：凯和小李的师徒情，在凯挡在他身前的那一刻被看见；我爱罗后来和他成了朋友
- **怎么交给观众**：
  - **第一层：先让你看见他什么都没有**：不会忍术和幻术；第一轮攻击全被沙子挡住，对方连动都不用动。差距被画面直接摆出来
  - **第二层：揭开他一直背着的东西**：负重砸出两个坑，观众一下子明白，他之前一直带着这么重的东西在打。量级用熟悉的物件做参照
  - **第三层：每升一层，要付更多**：八门一门一门地开，每开一门身体就撕裂得更厉害。代价看得见，一层层加码
  - **第四层：押上一切，还是输**：手脚被压碎
  - **第五层：最后一下不是招式**：昏迷着站起来。意志比招式更后出现，也更重
- **对照高光倒推**：
  - 先在乎什么：小李的"不会忍术也能当忍者"；他前面救过小樱、和佐助交过手
  - 先知道什么：我爱罗的沙子会自动防御；小李绑着负重
  - 先被压到多低：手脚被压碎，可能再也当不了忍者
  - 爆点：卸下负重；昏迷着站起来
- **为什么成立**：
  1. 处境人人都有：没有天赋的人拼命
  2. 对手的规则（沙子自动防御，站着不动就能挡下一切）正好是"天才不用努力"的画面（推测）
  3. 输了也燃，因为观众看见了他押上的全部
  4. 有后续：手术、和我爱罗和解，角色没有就此消失
  - **前提**：观众在这场之前已经在乎他
- **能借**：
  1. 量级用熟悉的物件做参照（负重砸坑）
  2. 代价看得见、一层层加码
  3. 输也可以是全剧最燃的打斗之一，因为观众看到了他押上的一切
  4. 对手的能力规则，最好正是主角处境的反面
  5. 输掉的那一方，最后一个画面给他的意志，不给招式
- **不能借**：
  1. 输的代价太重（几乎断送忍者生涯），要有后续交代，不能让角色就此消失
  2. 配角的死斗能封神，前提是观众已经在乎这个配角；短剧要先给他一两场戏
- **待核实**：凯给小李定的使用禁术的条件 ⚠️待核实

### NR-2 鹿丸 vs 飞段（疾风传）

- **规则**：飞段的诅咒要在他的仪式圆圈里才生效；飞段不死
- **量级**：飞段杀了鹿丸的老师阿斯玛
- **代价**：不适用
- **分几层**：鹿丸看穿"必须在圆圈里" → 用影子模仿术把飞段拉出圆圈 → 把飞段和角都分开、引进奈良家的森林 → 炸开、把还在说话的飞段埋进只有奈良家知道的地方。阿斯玛留下的打火机，有说是最后一击，有说是放在土堆上致意 ⚠️待核实
- **情绪**：为老师报仇
- **能借**：
  1. 规则战：先看穿规则的前提条件（圆圈），再破坏前提

### NR-3 卡卡西的铃铛测试（第 5 集前后）

> 打斗卡（2026-11-01 按新方法重写）。资料：Naruto Wiki（铃铛测试页）、火影官网动画介绍。

- **类型**：教学战
- **经过**：
  1. 第七班成立的第一天，卡卡西安排了一场生存演习，不许三个人吃早饭
  2. 规则：抢到他腰上的铃铛才算合格，抢不到的人没有午饭，要被绑在木桩上看别人吃，还要被送回忍者学校。铃铛只有两个，三个人里注定有一个被刷掉
  3. 三个人各自单干，全都失败了；鸣人偷吃便当，被绑在木桩上
  4. 卡卡西差点把三个人全赶回学校，说他们不懂团队合作。他让佐助和小樱吃午饭，但不许给鸣人吃
  5. 佐助和小樱违反他的命令，喂鸣人吃了饭
  6. 卡卡西现身，宣布三人合格。他说："违反规则的人被叫作垃圾，但不珍惜同伴的人，比垃圾还不如"
  7. 后来揭出，这句话是卡卡西小时候从同伴带土那里学来的
  8. 两年半以后，卡卡西对鸣人和小樱又测了一次；铃铛也在剧场版里再次出现，成了第七班的信物
- **情绪和这场仗想说的**：
  - **带走的情绪**：先被骗了一下，然后被暖到
  - **这场仗证明了什么**：同伴比规则重要。这是全剧的主题第一次被说出来（推测）
  - **谁变了、关系怎么变**：三个各顾各的人，第一次站到了一起
- **怎么交给观众**：
  1. **规则逼他们互相竞争**：两个铃铛、三个人，测试一开始就在挑拨
  2. **老师碾压**：卡卡西轻松戏耍三个人，量级不用多讲
  3. **压到最低**：全部失败，鸣人被绑在木桩上，三个人眼看就要回学校
  4. **真正的考点是一个很小的动作**：偷偷喂一口饭，违反老师的命令
  5. **揭开**：测试考的从来不是抢铃铛
  6. **一句话落地**：那句"比垃圾还不如"，后来又揭出它来自带土，老师的这一课有来历
- **对照高光倒推**：
  - 先在乎什么：鸣人的孤独，三个人能不能成为一个班
  - 先知道什么：铃铛只有两个
  - 先被压到多低：全员失败，鸣人被绑着挨饿
  - 爆点：喂饭，以及卡卡西那句话
- **为什么成立**：
  1. 教学战的规则是假的，真正考的东西藏在规则后面，观众和角色一起被骗、一起懂
  2. 测试的答案就是全剧的主题
  3. 铃铛后来反复回来，成了观众熟悉的梗
  - **前提**：老师要强到让学生不可能单独过关
- **能借**：
  1. 教学战的规则是假的，真正考的是另一件事。观众和角色一起被骗，再一起"懂了"
  2. 老师的这一课有来历（带土），给后面埋了线
  3. 真正的考点放在一个很小的动作里
  4. 测试里的道具后来反复出现，成为信物和熟梗
- **不能借**：主题这么早就说出口，需要观众已经在乎这几个人。短剧在第一集用这招，要先给每个人一个让人在乎的点
- **待核实**：旧卡写"动画和漫画版本有差异"，维基上没有标出这一场的差异 ⚠️待核实

### NR-4 鸣人 vs 佐助：医院天台到终结之谷

> 打斗卡（2026-11-01 按新方法重写）。资料：Naruto Wiki（佐助页）。这一张跨了两场仗：医院天台和终结之谷。

- **类型**：切磋战，打出关系裂缝；后续是死斗
- **经过**：
  1. 佐助被哥哥鼬打败，鼬让他在幻术里一遍遍看着父母被杀，说他还是太弱。他昏迷住院
  2. 醒来以后，他发现自己离鼬还是那么远；又嫉妒鸣人：班里成绩最差的那个，居然打败了我爱罗
  3. 鸣人来医院看他，佐助要和他打一场。鸣人说他身体还没好，佐助坚持
  4. 天台上越打越凶，佐助用出千鸟，鸣人用出螺旋丸。卡卡西赶到，把两人的招拨开，打在两边的水塔上
  5. 佐助在意的是谁打出的洞更大：千鸟那一面只是一个小洞，螺旋丸那一面整个背面都炸开了 ⚠️待核实（谁在什么时候看到的，来源说法不一）
  6. 不久以后，佐助离开木叶去找大蛇丸。鸣人在终结之谷追上他，佐助把这一战当成"天台上被打断的那一场"的续场；他还想起鼬说过，杀了最亲近的朋友就能开出万花筒写轮眼，决定杀了鸣人
  7. 鸣人问他为什么要做到这一步，说佐助对他来说就像兄弟。佐助承认这份羁绊，说要亲手斩断它，然后才第一次戴上护额，说鸣人连他的护额都碰不到
  8. 很多年以后，鸣人把那块护额还给了佐助，佐助一直带在身边
- **情绪和这场仗想说的**：
  - **带走的情绪**：嫉妒，和一段友情裂开的声音
  - **这场仗证明了什么**：最好的对手，也是最亲的人；越在乎，越想赢过他
  - **关系怎么变**：从竞争变成裂缝，再到兵戎相见，最后靠一块护额收回来
- **怎么交给观众**：
  1. **先给嫉妒一个来源**：被哥哥打垮，又看着吊车尾超过自己
  2. **不用人说谁更强，用一个物件当裁判**：水塔上两个洞，一大一小
  3. **打断，不分胜负**：卡卡西拨开两人的招，这一场没有结局，留到终结之谷
  4. **续场时把关系说破**："你就像我的兄弟""我要斩断它"
  5. **用一件物件收住全部**：天台上没戴、终结之谷才戴上、多年后被还回来的护额
- **对照高光倒推**：
  - 先在乎什么：两人从入学起的竞争
  - 先知道什么：千鸟和螺旋丸，两人各自的招
  - 先被压到多低：佐助看到两个洞的大小
  - 爆点：水塔上的洞；终结之谷的最后一击
- **为什么成立**：
  1. 竞争铺了很久，水塔这一下才有分量
  2. 天台被打断，把冲突完整留给了下一场
  - **前提**：两人的关系先被观众认定是"最好的对手"
- **能借**：
  1. 切磋不分胜负，重点是关系变化
  2. 用一个物件（水塔）做量级的裁判，不用任何人说谁更强
  3. 第一场被打断，第二场是续场：长线对手的两场仗要连起来看
  4. 用一件小物件（护额）贯穿两人的关系
- **不能借**：没有前面长期的竞争铺垫，水塔这一下就只是一个洞

- **能借**：
  1. 亮相战同时是教学战：五条悟把虎杖带在身边看，一边打一边讲，观众和虎杖一起学会"领域是什么"
  2. 对手越强，被当教具时越能立住主角方的量级
- **不能借**：一边打一边讲解，只有在碾压时成立；势均力敌的仗里停下来讲解会拖节奏

### JJ-2 七海建人：上班族的咒术

- **类型**：能力规则和人物身份一体
- **规则**：术式"十划咒法"把目标十等分，在 7:3 的位置强行制造弱点。他给自己立了"加班"的束缚：工作时间内压着咒力，超过工作时间后咒力反而增强（具体比例来自粉丝站 ⚠️待核实）。他还有一个"亮出底牌"的束缚，对真人时一起用过 ⚠️待核实
- **量级**：不适用
- **代价**：工作时间内压着自己
- **分几层**：上班时间 → 加班后增强
- **情绪**：讨厌加班的社畜，观众自带共鸣
- **能借**：规则来自观众最熟悉的日常（上班、加班），零理解成本；规则本身就是人设
- **不能借**：日常梗只能用在人物身上一两次，反复强调就成了段子

### JJ-3 东堂的不义游戏，和虎杖一起打花御

- **类型**：团战 + 教学战 + 规则战的拐弯
- **规则**：东堂拍手，就能把自己、虎杖或附近的东西对调位置；他也可以拍手却不换
- **量级**：花御是特级咒灵
- **代价**：不适用
- **分几层**：东堂在战斗中教虎杖打出黑闪（靠进入心流状态反复打出）→ 虎杖连续三次黑闪 → 花御预判第四次会换位、提前防备 → 东堂拍手但不换 → 第四击命中（依据章节摘要 ⚠️待核实）
- **情绪**：搭档的爽快
- **能借**：
  1. 规则越简单，观众和对手越会预判；预判一形成，假动作就是最好的拐弯（"猜 → 验证"的精髓）
  2. 团战里的分工清楚：东堂控位置，虎杖输出
  3. 教学战和实战合在一起，学会的东西当场兑现
- **不能借**：假动作只能用一两次，用多了观众不再预判，拐弯就没了

### JJ-4 领域展开与领域对撞

> 打斗卡（2026-11-01 按新方法重写）。这张卡讲的是一个招式从"教"到"兑现"的全过程，跨了好几场仗。资料：Jujutsu Kaisen Wiki（领域展开页）、此前整理的 JJ-1。五条悟对宿傩的细节没有逐话核对。

- **类型**：终极招式的仪式；同类能力的层次差
- **经过**：
  1. **教**：五条悟带着虎杖去打漏瑚，边打边给他讲：领域展开是咒术的顶点，领域里术式必中，连五条悟的"无下限"都挡不住；漏瑚先展开，五条悟用自己的领域"无量空处"压了过去（JJ-1）
  2. **规则一次讲清**：要结手印；必中；两个领域相撞，更精炼的压过另一个；消耗巨大；展开以后术式会烧坏一阵
  3. **兑现**：五条悟对宿傩，最强对最强，领域反复对撞。两人为了反复展开，不惜弄伤自己大脑里的术式刻印，再用反转术式修好，代价是脑子受到永久损伤，到了极限就再也展开不了
  4. 宿傩在五条悟的领域里展开自己的领域，破坏了结界，必中斩中五条悟（两个必中怎么互相抵消，来源说法不一 ⚠️待核实）
  5. 五条悟最终战死，读者反应很激烈 ⚠️待核实（具体话数和场景）
- **情绪和这场仗想说的**：
  - **带走的情绪**：等仪式的期待。"领域展开"四个字一出来，观众就知道最大的东西要来了；最强对最强的紧张
  - **这场仗证明了什么**：层次差是看得懂的
  - **谁变了**：不适用；这张卡的重点是规则怎么教、怎么兑现
- **怎么交给观众**：
  1. **第一次出现就是教学**：五条悟边打边讲，观众和虎杖一起学会规则（教学战和压制战叠在一起）
  2. **仪式**：手印加招式名，每个人的领域都长成他自己的样子
  3. **规则简单**：必中，更精炼的胜。最强对最强也能看懂谁占上风
  4. **代价越打越重**：从"消耗大"到"弄伤大脑"
- **对照高光倒推**：
  - 先在乎什么：五条悟是"最强"
  - 先知道什么：领域的规则，早在第一次出现时就教过了
  - 先被压到多低：五条悟的领域被破
  - 爆点：领域对撞
- **为什么成立**：
  1. 规则在第一次出现时就教会了观众，后面不用再讲
  2. 仪式反复出现，观众会等、会跟着喊
  - **前提**：教的那一场要早，而且要用压倒性的胜利来教
- **能借**：
  1. 终极招式有清楚的胜负规则（"更精炼的胜"），最强对最强也能看得懂
  2. 手印加招式名，是观众等着看的仪式
  3. 让最强的角色在一场压制战里顺便教规则
- **不能借**：
  1. 领域对撞的细节规则后期越来越复杂，连粉丝都在争，短剧里只保留一条最简单的胜负规则
  2. 把期待吊到最高的角色，结局处理要格外小心，兑现方式让人觉得被骗，口碑会反噬（推测）

## 全职猎人（HX）

### HX-1 酷拉皮卡的锁链（对窝金）

> 打斗卡（2026-11-01 按新方法重写）。资料：Hunter × Hunter Wiki（酷拉皮卡页、窝金页，含富坚义博的说法）。没有逐镜头核对。

- **类型**：限制即执念；复仇死斗
- **经过**：
  1. 五年前，幻影旅团屠杀了窟卢塔族，夺走他们的火红眼。酷拉皮卡是幸存者
  2. 他在心脏上缠了一条"律令之链"，立下誓约：束缚之链只能用在旅团身上，用在别人身上，他就会死
  3. 在友客鑫，旅团的窝金一个人屠杀了大批黑帮，还杀了几个"阴兽"。酷拉皮卡看见他背上的蜘蛛刺青，怒不可遏，不顾同伴劝阻，趁他麻痹时用锁链把他抓走
  4. 窝金被同伴救出来，追到酒店，让酷拉皮卡自己选死在哪里。两人去了沙漠
  5. 窝金问他是谁，说感觉到他的念里有惊人的决心。酷拉皮卡问他记不记得自己杀过的人，提起窟卢塔族和五年前。窝金承认那时他在旅团，但说不记得了
  6. 窝金全力攻击，酷拉皮卡全部扛住。他用束缚之链捆住窝金，亮出"绝对时间"，逼问其他团员的下落和能力
  7. 窝金一次又一次叫他杀了自己。酷拉皮卡把律令之链刺进他的心脏：必须如实回答，否则就死
  8. 窝金笑着叫他滚。锁链捏碎了他的心脏。他被埋在沙漠里一座没有名字的坟里；旅团为了给他报仇，屠杀了黑帮
- **情绪和这场仗想说的**：
  - **带走的情绪**：复仇的痛快里夹着一阵空。仇人连杀过谁都不记得了；对方至死不出卖同伴，又让人生出一丝敬意（推测）
  - **这场仗证明了什么**：誓约越狠，力量越大。执念被直接写进了能力
  - **谁变了**：酷拉皮卡迈过了复仇的第一步，从此没有回头路（推测）
- **怎么交给观众**：
  - **第一层：能力就是誓言**：只能对旅团用，用错就死。观众知道他把命押在了复仇上
  - **第二层：先演对手有多强**：窝金一个人屠杀黑帮和阴兽，是旅团里肉体最强的人
  - **第三层：最刺的一刀是一句话**："不记得了。"全族的血仇，在凶手那里什么都不是
  - **第四层：规则翻盘**：扛住全力攻击，锁链一捆就动不了，眼睛变红，绝对时间发动
  - **第五层：用规则处刑**：律令之链让对方自己选，说实话或者死。窝金选了死，结局由对方的选择决定
- **对照高光倒推**：
  - 先在乎什么：窟卢塔族被灭；酷拉皮卡的誓约
  - 先知道什么：锁链只能对旅团用；窝金有多强
  - 先被压到多低："不记得了"
  - 爆点：锁链捆住窝金；律令之链捏碎心脏
- **为什么成立**：
  1. 能力规则就是人物动机，一眼看懂
  2. 对手不是纯粹的坏，窝金有骨气，复仇才不只是爽
  3. 最残酷的结果由规则执行，主角没有亲手"下杀手"，却比亲手更重
  - **前提**：誓约要在打之前告诉观众
- **能借**：
  1. 誓约越狠，力量越大，代价越重，观众越在乎这一战
  2. 限制把人物的执念直接写进了能力（只能对仇人用），也逼他做选择
  3. 让仇人"不记得"：一句话把复仇的情绪推到顶
  4. 用规则处刑：让对方在规则里自己选
- **不能借**：
  1. 限制太狠会把角色锁死在一条线上，故事要给他别的出路
  2. 念能力的细节越到后面越复杂（绝对时间怎么折寿，来源说法冲突 ⚠️待核实），短剧只保留一条规则
- **制作备注**：富坚义博说，酷拉皮卡的灵感来自宫崎骏《风之谷》里的王虫（愤怒时眼睛变红）

### HX-2 尼特罗会长 vs 蚁王

> 打斗卡（2026-11-01 按新方法重写）。资料：Hunter × Hunter Wiki（蚁王页、尼特罗页、小麦页）。没有逐话核对。

- **类型**：死斗，分层升级，最后一层是情绪反转；长线对手的结局
- **经过**：
  1. 蚁王出生才几十天，是嵌合蚁里最强的个体，看不起人类社会，觉得靠血统当统治者毫无道理
  2. 他和盲女小麦下军仪，一盘一盘输给她。他第一次露出人的情绪：威胁她输了就扯掉她的手臂。小麦对他和棋的敬意超出了他的预料，他扯下了自己的手臂向她道歉
  3. 猎人协会会长尼特罗把他带到没人的地方对决。尼特罗的百式观音，用极快的速度挥动观音的手臂出掌（他年轻时每天打一万次"感谢之拳"练出来）⚠️待核实
  4. 百式观音猛攻 → 蚁王开始分析、预判尼特罗的动作 → 零之掌倾尽全部的气，仍打不倒蚁王
  5. 尼特罗自杀，引爆了体内的炸弹"蔷薇"。蚁王第一次感到恐惧
  6. 蚁王没有当场死，中了蔷薇的毒。他向人类承认：人类赢了。他甚至愿意下跪，只求最后的时间能和小麦一起度过
  7. 他想再下一盘棋，又怕把毒传给小麦，劝她离开。小麦留了下来。两人下着军仪，手牵着手中毒死去
- **情绪和这场仗想说的**：
  - **带走的情绪**：寒意和心碎。人类赢过完美生物，靠的不是武，是人性里最丑的那一部分；赢了的反派最后学会了温柔
  - **这场仗证明了什么**：怪物在最后一刻成了人，人为了赢先成了怪物（推测）
  - **谁变了**：蚁王，从看不起人类，到为一个盲女下跪
- **怎么交给观众**：
  - **第一层：先让反派变得可以被同情**：扯下自己的手臂向小麦道歉，这一幕比任何战斗都先到
  - **第二层：死斗分层**：猛攻 → 被看穿 → 倾尽全力 → 还是打不倒
  - **第三层：最后一层的反转是情绪上的**：老人选择同归于尽，蚁王第一次害怕
  - **第四层：胜负模糊**：技术上蚁王赢了，结局上人类赢了
  - **第五层：用一盘棋送别**：最强的生物和最弱的女孩，手牵手死去
- **对照高光倒推**：
  - 先在乎什么：蚁王和小麦的军仪
  - 先知道什么：尼特罗是人类最强的人；蔷薇在他体内
  - 先被压到多低：零之掌也打不倒蚁王
  - 爆点：蔷薇引爆；最后一盘棋
- **为什么成立**：
  1. 反派的转变先于结局，观众同情他是被一步步带过去的
  2. 胜负和情绪分开：赢的方式让人不舒服，输的人让人心疼
  - **前提**：反派要有足够长的戏去改变
- **能借**：
  1. 死斗分层，每一层都比上一层更狠，最后一层的反转是情绪上的
  2. 仗的胜负模糊：技术上蚁王赢了，结局上人类赢了
  3. 反派在结局被同情（和"对手是受害者"相通）；让反派的温柔落在一个最弱的人身上
  4. 让长线对手的最后时间用在一件和战斗无关的事上（下棋）
- **不能借**：蚁王篇极长，蚁王的转变铺了几十集，短剧要压缩到最核心的一两个画面

### HX-3 小杰一行 vs 爆弹魔根斯（贪婪之岛）

  8. 之后他昏迷不醒，靠维生设备活着。医生说，从没见过一个 12 岁的孩子一夜之间变成这样。后来奇犽带着妹妹亚路嘉把他救了回来；他见到父亲金，哭着说凯特的事，又去向复活后的凯特道歉

  - **带走的情绪**：爽和恐惧并存，观众被主角吓到；最后是心碎
  - **这场仗证明了什么**：复仇能让人变强，也能让人变成另一个人（推测）
  - **谁变了**：小杰，从天真的少年变成一个能威胁杀死盲女的人；奇犽，从被小杰拉出黑暗的人，变成去拉小杰的人（推测）
- **怎么交给观众**：
  - **第一层：先让对手做好事**：彼多在救人。观众的立场第一次站到了怪物那边
  - **第二层：让主角做坏事**：威胁一个盲女。观众开始怕他
  - **第三层：最后一根稻草是一句真话**："他已经死了"
  - **第四层：变强的样子让人不安**：一个孩子突然长成大人，打碎对手的头骨还不停
  - **第五层：用旁人的眼睛看主角**：奇犽的惊恐就是观众的惊恐
  - **第六层：最可怕的一句话**：断了手，却高兴自己"和凯特一样了"
- **对照高光倒推**：
  - 先在乎什么：小杰和凯特；小杰和奇犽
  - 先知道什么：凯特死在彼多手里；念的誓约越重，力量越大（HX-1）
  - 先被压到多低："凯特已经死了"
  - 爆点：成年化；流着泪的最后一击
- **为什么成立**：
  1. 誓约的规则早就教过观众（HX-1），这一次是把规则推到极限
  2. 敌人在这一刻比主角更像人，观众的同情被翻了过来
  3. 有一个旁观的伙伴，观众有地方安放自己的害怕
  - **前提**：主角之前一直是"好孩子"，崩坏才有落差
- **能借**：
  1. 情绪爆发可以让观众害怕，而不只是爽；代价大到几乎毁掉主角，这一下的分量就到顶了
  2. 爆发前先让对手做一件好事，让主角做一件坏事
  3. 用伙伴的眼睛看主角的崩坏
  4. 后续的救赎由伙伴完成（奇犽带亚路嘉来救他）
- **不能借**：只能用在季终级别的节点，而且后面要用很长的戏来救主角
- **待核实**：小杰之后"失去念"是永久还是暂时 ⚠️待核实

### SV-1 被盯上的街（第 8 集）

> 单元卡（2026-11-01 按新方法重写）。资料：Ultraman Wiki（集页剧情和花絮）、口碑汇总（见赛文来源；All About 问卷第 1 名）。没有亲眼看过本集。

- **故事**：
  1. 一个出租车司机突然劫持乘客、动手打人，被抓住后马上昏倒。几个孩子在旁边看着
  2. 安娜去接其中一个孩子，告诉他：他当飞行员的爸爸，也就是安娜的舅舅，开的客机坠毁了，130 人遇难。葬礼上，人们都在议论最近突然多起来的暴力事件
  3. 弹和古桥巡逻经过北川町，休息时弹在自动售货机给古桥买了一包烟。一个拿步枪的人突然冲过来，古桥制服他时受了伤。那人只记得发狂前买过一包烟
  4. 弹开车回基地，前面的卡车突然倒下一车石头，驾驶座上没有人。无线电里有人叫出他是赛文，警告他别插手北川町
  5. 古桥伤好，抽了弹买的那包烟，立刻暴怒；曾我不知情，也抽了，也发了狂。弹拆开香烟，找到红色的结晶：宇宙罂粟的种子，吸进去的人会把身边的人都看成敌人，想杀死对方
  6. 飞行员的妻子说，丈夫坠机前在同一台售货机买过烟
  7. 弹和安娜蹲守售货机，跟踪来补货的人，进了一间看起来没人住的破旧老房子。梅特隆星人在里面礼貌地等着他，两人隔着矮桌坐在榻榻米上
  8. 外星人解释：这只是一场实验，为了找出地球的弱点。毁灭地球最简单的办法，是播下不信任和仇恨，让人类自己毁掉自己
  9. 弹被困进飞船带往太空，安娜通知基地，鹰 1 号打中飞船把他放了出来。赛文很快打倒巨大化的外星人
  10. 旁白冷冷地说：外星人的计划很可怕，不过人类之间的信任，还远远没有发展到能被外星人利用的程度
- **情绪和想表达的**：
  - **带走的情绪**：冷到骨子里。最可怕的不是外星人，是我们本来就离互相残杀不远；后劲是那句讽刺
  - **想说的那句话**：人和人之间的信任很脆弱。结尾的旁白是反话：我们现在本来就不怎么信任彼此，外星人连利用的机会都没有
  - **谁变了**：没有人变。外星人走了，问题原封不动交给观众，这正是这一集的用意（推测）
- **怎么交给观众**：
  - **第一层：暴力落在日常里**
    1. 出租车、售货机、香烟。施暴的是普通人，事后什么都不记得。怕的是身边任何一个人随时会变
    2. 编剧金城哲夫说，当时日本大约一半的人抽烟，这个设定"真实得可怕"
  - **第二层：暴力落到自己人身上**
    1. 先是安娜的舅舅和 130 个乘客，再是队友古桥和曾我
    2. 害队友发狂的那包烟，是弹亲手买的（推测：主角也成了不知情的传播者）
  - **第三层：揭开的地方最不像揭开**
    1. 破旧的老房子、榻榻米、矮桌、礼貌地等着的外星人。超现实的对手放进最日常的空间，反差本身就是名场面
    2. 外星人用最平静的语气说出最可怕的话：你们会自己毁掉自己
    3. 导演实相寺昭雄故意违反电视台"减少日本元素、方便出口"的要求拍成这样
  - **第四层：问题不让打斗解决**
    1. 打斗很短
    2. 最后一句旁白不是安慰，是冷嘲，把问题塞回观众手里。这句不在原剧本里，是导演加的（也有说法是佐佐木守应导演请求写的）
- **对照高光倒推**：
  - 先在乎什么：安娜失去舅舅的孩子；被害的队友
  - 先知道什么：烟是传播的途径
  - 先被压到多低：队友一个个发狂，烟还是主角买的
  - 爆点：矮桌边的对话（不是打斗），和最后一句旁白
- **为什么成立**：
  1. 武器是观众手边的日常物件，处境不用想象
  2. 主题收成了一句话"人与人失去信任"，剧本改了三稿才收到这么小
  3. 名场面、揭秘、主题是同一场戏：那场对话同时完成了三件事
  4. 赛文的打斗和必杀都在，壳没有缺
  - **前提**：日常物件要是观众当时真的天天碰的东西
- **能借**：
  1. 对手的武器是一件日常物品，规则作用在人和人之间的信任上
  2. 超现实的对手放进最日常的空间，用最平静的语气说出最可怕的话
  3. 打斗很短，问题放在最后一句冷嘲里
  4. 让主角在不知情中参与了灾难（推测）
- **不能借**：
  1. 剧本改了三稿，最后才从"抽烟引发核事故"收到"人与人失去信任"。主题问题要收得足够小，一句话说得清
  2. 香烟放到今天的平台未必能播；要换成当下人人手边的东西

  - 爆点：桐山说出弹的话，R2 被取消
- **为什么成立**：
  1. 1960 年代冷战，核武器是观众心里真实的恐惧
  2. 对手是人类自己造出来的，问题不用另外解释
  3. 主题落在一个看得见的改变上：有人改了主意
  - **前提**：现实议题要和观众当下的恐惧对上
- **能借**：
  1. 对手是人类自己造出来的：怪兽的来历，就是这一集要问的问题
  2. 主题用主角的一句话说出来，结尾让最不同意他的人重复这句话
  3. 同一段音乐在关键时刻反复出现；用画面传达立场
  4. 让主角在开头站在少数一边
- **不能借**：2011 年福岛核事故后，这集的重播被取消过。现实议题要注意时间和平台尺度

### SV-3 孤独的地球人（第 29 集）

> 单元卡（2026-11-01 按新方法重写）。资料：Ultraman Wiki（集页剧情和花絮）、口碑汇总（见赛文来源）。没有亲眼看过本集。

- **故事**：
  1. 京南大学自己发射了一颗观测卫星。曾我很高兴，他的未婚妻冴子就在那里读书。弹带回调查部的报告：项目负责人丹羽教授很可能是外星人
  2. 冴子的老朋友、研究生一宫一直跟着教授做研究。曾我让冴子把一宫带到警备队保护起来
  3. 冴子开车载着一宫，告诉他教授是外星人，一宫突然抢过方向盘，车撞上了树。他早就知道教授是外星人，可教授是好人：他的瞬间移动理论没人理会，只有教授认真对待，还帮他造出了能用的装置。他说自己不相信人类，跑了
  4. 曾我去教授办公室，被电晕，醒来时已经在卫星上。教授扫描了他全部的记忆，准备让外星飞船来收走卫星
  5. 一宫回到教授那里，警告他警备队知道了，问要不要毁掉装置和卫星。教授告诉他：卫星里装的是防卫军全球基地的情报，要拿回母星去策划侵略
  6. 一宫感到被背叛，想阻止他，教授现出原形要杀他。弹赶到，变身
  7. 外星人用幻影分身拖住赛文，自己变回人形想逃。一宫冲进装置间，把自己和教授一起推进了只能传送一个人的装置；装置损毁，两人在一道光里消失
  8. 赛文飞上太空救回卫星，鹰 2 号击毁外星飞船
  9. 第二天，曾我说一宫要是活着，会是个出色的学者；弹说，他也许还活着，在宇宙的某个地方望着地球
- **情绪和想表达的**：
  - **带走的情绪**：孤独。才华不被承认的人，唯一的理解者是来利用他的，他最后独自保护了地球
  - **想说的那句话**：编剧市川森一说，一宫就是年轻时的自己：剧本屡屡被退，被人说"你没才能，放弃吧"，心里想的是"我明明有才能，为什么世界不承认"。他一口气写完了这一集
  - **谁变了**：一宫，从"我不相信人类"，到用自己的命保护了人类
- **怎么交给观众**：
  - **第一层：先让你站在一宫这边**：只有教授认真看他的理论。"我不相信人类"不是坏，是被冷落太久。观众能理解他，因为写的人就是他
  - **第二层：理解比威胁更危险**：对手不是来硬打的，是来"理解"一个没人理解的人。背叛来自唯一对他好的人
  - **第三层：才华用在了刀刃上**：带走对手的，正是他自己造的那台没人相信的装置，而且只能传送一个人。他的理论第一次被证明，就是他牺牲的那一刻（推测）
  - **第四层：给他留一个余地**：赛文打的只是幻影，真正的结局由一宫完成。最后一句"也许还活着，望着地球"，悲伤里留了一点温柔
- **对照高光倒推**：
  - 先在乎什么：一宫不被承认
  - 先知道什么：装置只能传送一个人
  - 先被压到多低：唯一理解他的人要杀他
  - 爆点：他把自己和对手一起推进装置
- **为什么成立**：
  1. 不被承认是很多人都有过的处境
  2. 写的人是真心的
  3. 情绪由单元配角一宫扛，弹负责在结尾替他说一句话，主角没有被抢光
  - **前提**：单元配角要在同一集里先被理解，再做选择
- **能借**：
  1. 编剧把自己真实的处境写进单元
  2. 对手不是来硬打的，是来"理解"一个没人理解的人，这比威胁更危险
  3. 让配角用自己的才华（他造的东西）完成牺牲
  4. 结尾给牺牲者留一个"也许还活着"的余地
- **不能借**：
  1. 市川自己也觉得结尾"有点简单"
  2. 主角的打斗只是在拖时间，这种写法一季里不能多

### SV-4 被盗的奥特眼镜（第 37 集）

  3. 基地收到一座在宇宙中漂流的城市"佩加萨"发来的信号：动力坏了，80 小时后会撞上地球，请地球把自己的轨道倒过来就行

  7. 影子单独联系安娜，让她和弹一起离开地球：如果改不了轨道，它的任务就是炸毁地球。它向安娜道歉，现出原形，逃出去要把炸弹埋进地心
  8. 弹找到它，告诉它城市已经没了。它愤怒：你们毁掉了一个那么先进的文明。它说自己一直拖着不放炸弹，是因为希望到最后一刻，自己的人能避开相撞
  9. 赛文缴了它的炸弹，它逃进阴影里。赛文把炸弹带到太空引爆

  - 先知道什么：这里的人类是奴隶
  - 先被压到多低：姐姐和唯一肯帮忙的人要被处决
  - 爆点：给长官的头上油（反常的画面）；结尾队长的那句"试飞成功"
- **为什么成立**：
  1. 导演实相寺昭雄受戈达尔《阿尔法城》启发：不靠特效、不靠科幻道具，把熟悉的现实街景拍得陌生，照样讲出一个科幻故事；两部作品都是低预算
  2. 地球上的一切看起来都一样，只是人和机器的位置颠倒了
  - **前提**：要有导演的风格来撑，否则低成本就只是简陋
- **能借**：
  1. 熟悉的现实街景拍得陌生，照样讲出一个科幻故事
  2. 一切都一样，只有一处颠倒：熟悉里的反常
  3. 结尾把问题带回自己人身上
  4. 用一个小动作（上油、泡咖啡）说清权力关系
- **不能借**：原本的第 43 集方案是"外星人 15 + 怪兽 35"，一集出五十多只怪兽，因为收视和预算被否了。大场面不是唯一的答案，但这也说明这种集要有导演的风格来撑
