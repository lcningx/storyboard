# 案例拆解

> 《短剧爆款剧本框架》的证据库。框架正文里的每条结论都引用这里的案例编号，不在正文里展开。
> 2026-11-01 起建立，一部作品一部作品往上加。

## 怎么用

### 证据标准

1. 每条结论至少 3 个案例，至少来自 2 部作品。
2. 每条结论都写适用边界或反例：什么情况下不成立、会用坏。
3. 分清"观察"和"推论"：作品里发生了什么是观察，我们因此该怎么做是推论。
4. 事实要核实。查到可靠来源的不标；来源不可靠、有冲突或是推论的，标 **⚠️待核实**。

### 怎么建档

**先弄懂它想让人感到什么，再拆它怎么做到的。** 手法是为情绪服务的；只拆手法、不说情绪，就会把一集好故事拆成一堆技巧（2026-11-01 用户指出的问题）。

建一张卡按这个顺序走：

1. **先找口碑**：至少两份来源都说它好，才算值得拆。记下大家说好在哪
2. **读全剧情和花絮**：剧情按场面顺序读完；花絮里找编剧、导演说过的话，尤其是"想写什么""为什么这样改"
3. **回答三个问题**，答不出来不往下拆：
   - 观众看完带走的是什么情绪？
   - 它想说的那句话是什么？
   - 谁变了，怎么变的？
4. **按情绪的层次拆手法**：先在乎、再被压、最后落下来，每一层下面写它用了哪几招。不按技巧分类排
5. **对照高光倒推**：观众要先在乎什么、先知道什么、先被压到多低，这一集分别怎么答
6. **写清它成立的前提**：在什么条件下这一招才管用，换个位置会不会失效
7. **最后才写能借、不能借**
8. 没亲眼看过的，镜头、配乐、台词说不准的地方标 ⚠️待核实；自己的推导标"推测"

### 卡片字段

卡分两种。**单元卡**拆一整集或一个单元，**打斗卡**拆一场仗。

**单元卡**

| 字段 | 写什么 |
|---|---|
| 故事 | 按场面顺序，把发生了什么说清楚 |
| 情绪和想表达的 | 三个问题的答案：带走什么情绪、想说的那句话、谁变了 |
| 怎么交给观众 | 按情绪层次排，每层写用了哪几招 |
| 对照高光倒推 | 先在乎什么、先知道什么、先被压到多低；爆点是什么 |
| 为什么成立 | 前提和适用边界 |
| 能借 | 我们能拿走的做法 |
| 不能借 | 照搬会出问题的地方，以及短剧要怎么改 |

**打斗卡**

| 字段 | 写什么 |
|---|---|
| 类型 | 这场仗的任务：亮相、切磋、教学、突破、压制、规则、团战、死斗、关系反转……可以组合 |
| 情绪 | 这场仗让观众感到什么，情绪从哪来：能力、回忆、关系、守住了什么。放在最前面想清楚 |
| 规则 | 能力怎么用、有什么限制；观众在哪一刻知道的 |
| 量级 | 观众靠什么感觉到强：参照物、旁人反应、对方没认真…… |
| 代价 | 用这招付出什么，画面上看不看得见 |
| 分几层 | 一场仗里升级了几次，每次靠什么 |
| 能借 | 我们能拿走的做法 |
| 不能借 | 照搬会出问题的地方，以及短剧要怎么改 |

2026-11-01 之前写的卡用的是旧字段，情绪部分大多写得薄，之后按新方法逐张重写。已按新方法写的：TG-10、TG-15。

## 海贼王（OP）

### OP-1 路飞 vs 阿尔比达（漫画第 2 话，动画第 1 集）

- **类型**：亮相战
- **规则**：橡胶。一场教两件事：铁棒打在身上没事（打不伤），拳头能伸长（能打远）
- **量级**：阿尔比达是一船之主，科比怕她怕得要死。对手的分量借科比的恐惧立起来；路飞一拳把她打倒
- **代价**：无
- **分几层**：一层
- **情绪**：科比的懦弱和路飞的坦荡形成对比，新角色的情绪借这个对比带出来
- **能借**：亮相战可以一次教完能力的两面（防和攻）；对手的分量不一定靠对手自己展示，可以借旁人的反应
- **不能借**：没有"压"的打法只适合很短的戏，拖长了就没有悬念

### OP-2 路飞 vs 克洛克达尔，三战（阿拉巴斯坦篇）

- **类型**：压制战 → 压制战 → 规则战破局，同一个对手打三场
- **规则**：克洛克达尔是自然系的沙人，拳头直接穿过他的身体
  - 第一战：打不着，被钩子刺穿，扔在沙漠里。克洛克达尔给了三分钟期限 ⚠️待核实（只见于粉丝站）
  - 第二战：带了水，沾水的沙能打到，但还是输了（具体怎么输 ⚠️待核实）
  - 第三战：用自己的血沾湿拳头，打赢
- **量级**：七武海的身份，加上整个国家被他玩弄在手里
- **代价**：第三战用的是自己的血，代价直接在画面上
- **分几层**：跨三场仗，每场多懂一点规则
- **情绪**：薇薇的国家；路飞连输两次后的执念
- **能借**：
  - 破解对手的规则可以拆到好几集里，每输一次多懂一点。正好对应两三集的单元：每集结尾停在"压"
  - 解法来自生活常识（沙子沾水会结块），观众回头一想就觉得合理，几乎不花脑子
- **不能借**：原作三场仗拉得很长，短剧要压缩

### OP-3 索隆 vs Mr.1（阿拉巴斯坦篇）

- **类型**：突破战，在仗里学会一样新东西
- **规则**：Mr.1 全身能变成钢铁，刀砍不进去
- **量级**：钢铁是观众熟悉的东西，"砍开钢铁"不用任何解释
- **代价**：被砍到濒死
- **分几层**：砍不动 → 濒死 → 领悟"万物的呼吸"，一刀砍开钢铁
- **情绪**：成为世界第一剑豪的目标
- **能借**：仗里的突破要同时满足两点：已经被逼到绝境；原理能一句话说清（"听见呼吸"）
- **不能借**：在仗里临时学会新能力，离"作弊"只有一步。原作成立，是因为"能砍开钢铁"早就作为剑士的境界立在那里了 ⚠️待核实（推论，需要核对前文有没有铺）

### OP-4 索隆 vs 鹰眼（海上餐厅篇）

- **类型**：压制战，个人层面
- **规则**：没有特别的规则，就是剑术的差距
- **量级**：鹰眼是世界第一剑豪；只拿一把很小的刀对付索隆的三把刀 ⚠️待核实（"小刀"出自二手来源）
- **代价**：胸前留下一道大伤
- **分几层**：一层，从头到尾被压着打
- **情绪**：输了，但转身用正面挨刀，"背上的伤是剑士的耻辱"，守住了尊严
- **能借**：压制战要给观众留一笔"欠账"，比如一个誓言；用"对方根本没认真"表现差距，比真的打得很惨更狠
- **不能借**：输了却没留下任何"还账"的期待，就是纯憋屈

### OP-5 路飞 vs 青雉（长环长岛篇）

- **类型**：压制战，世界层面
- **规则**：青雉能把东西冻住
- **量级**：路飞要求单挑，被冻成冰，彻底输了。青雉饶了他，理由是他打败克洛克达尔，海军欠他一份人情
- **代价**：无
- **分几层**：一层
- **情绪**：为了保护罗宾而单挑
- **能借**：和 OP-4 对比，压制战有两种用法：OP-4 立个人目标（我要打败他），OP-5 立整个世界的刻度（这个级别现在根本碰不了）。两种任务不一样，不能混用
- **不能借**：世界刻度类的压制不能频繁用，用多了主角显得永远在输

### OP-6 草帽团 vs CP9（司法岛篇）

- **类型**：团战，拆成一对一
- **规则**：罗宾戴着海楼石手铐，钥匙分散在五个 CP9 成员手里，草帽团必须分头去打
- **量级**：CP9 是政府的秘密杀手组织
- **代价**：每个人都打到重伤
- **分几层**：开打之前先把情绪拉满：罗宾喊出"我想活下去"，路飞让狙击王烧掉世界政府的旗帜，等于宣战
- **情绪**：救罗宾
- **能借**：
  - 用一个物件规则给"分头单挑"一个理由，一次性给每个伙伴一场戏
  - 情绪先在开打前拉满，再分头去打
- **不能借**：五场单挑在短剧里撑不住，最多拆两三场

### OP-7 二挡和三挡的首次使用（司法岛篇）

- **类型**：死斗中的用法升级
- **规则**：二挡第一次用是对布鲁诺（第 387 还是 388 话，来源有冲突 ⚠️待核实）；三挡第一次完整亮相，有说是打布鲁诺，有说是打路奇 ⚠️待核实
- **量级**：二挡加速后对手跟不上，三挡把拳头变成巨人的
- **代价**：路奇点破二挡在透支身体 ⚠️待核实
- **分几层**：一挡打不过 → 二挡 → 三挡
- **情绪**：救罗宾
- **能借**：新招先在次一级的对手身上演示规则，到打大 boss 时观众已经懂了 ⚠️待核实（推论，依赖上面的首次使用顺序）
- **不能借**：新形态一次出两个，短剧里观众消化不了，一集只开一个

### OP-8 路飞 vs 多弗朗明哥，四挡（德雷斯罗萨篇）

- **类型**：死斗
- **规则**：四挡第 784 话首次使用；第 786 话交代代价：用完以后十分钟内用不了霸气
- **量级**：一拳把七武海从王宫屋顶打飞
- **代价**：十分钟用不了霸气
- **分几层**：四挡猛攻 → 解除后十分钟的空窗 → 再战
- **情绪**：德雷斯罗萨一国人的命
- **能借**：限制可以制造出一整段新的戏。这十分钟里需要别人帮路飞拖住多弗朗明哥，支援戏就有了 ⚠️待核实（"别人帮他拖住"的具体情节）。限制不只用来"压"主角，还能给伙伴腾出戏份
- **不能借**：原作的空窗戏很长，短剧要压成一两个回合

### OP-9 索隆和山治的日常斗嘴

- **类型**：切磋战
- **规则**：无
- **量级**：两人实力接近
- **代价**：无
- **分几层**：无
- **情绪**：冤家式的亲近
- **能借**：永远分不出胜负，这本身就是看点；给评论区制造"谁更强"的话题，关系也在一次次斗嘴里被确认
- **不能借**：分出了胜负，话题就没了

### OP-10 路飞 vs 女帝汉库克与蛇姬姐妹（女儿岛篇，漫画第 518–520 话）

- **类型**：规则战 + 关系反转战
- **规则**：
  - 汉库克的甜甜果实，能把对她动了心的人变成石头；满场被石化的人就是证明
  - 她两次对路飞放石化光线，都失效了（第 518 话）；路飞以为那是福克西的迟缓光线，摆错了防御姿势，本身是个笑点
  - 为什么无效：剧里玛丽哥尔德猜他是吓坏了顾不上心动；"路飞心里没有邪念"这个更广为人知的说法是不是原作给的解释 ⚠️待核实
- **量级**：满场石像是参照物，观众一眼知道这招有多可怕，再看它对路飞失效
- **代价**：无
- **分几层**：打败处刑者豹子巴库拉 → 对上桑达索尼亚和玛丽哥尔德，打斗中无意识地第二次放出霸王色霸气 → 玛丽哥尔德的火烧掉了桑达索尼亚的衣服，后背的奴隶印记要暴露，路飞冲上去用身体挡住 → 打赢两姐妹（第 520 话）
- **情绪**：敌人藏了一辈子的伤疤，被对手护住了
- **能借**：
  1. 颜值可以就是规则本身：女帝的美貌直接是武器，满场石像是证明。框架第五节说"颜值 + 反常"，这里是把颜值做成了能力，AI 出颜值的成本接近零
  2. 免疫可以来自人物性格：路飞扛住石化不靠练出来的力量，靠"他就是这样的人"。规则一和人物挂钩，就成了刻画人物的工具
  3. 打斗中途换目标：拼命打着，突然变成帮敌人守秘密。观众猜的是"谁会赢"，被引到"他会怎么对待敌人"，是猜错了但回头一想合理的惊喜
  4. 仗打完关系翻转：汉库克爱上路飞，敌人变成日后的援军。留下的不是胜利，是关系（对应框架第三节"单元留下什么"里的关系变化）
- **不能借**：挡背的动作成立，是因为前面花了很多篇幅铺印记的秘密有多重。短剧要在同一集前半段就铺好，而且只能用一个画面讲清楚

### 海贼王小结（观察，未升格为规律）

1. 同一个对手可以用不同类型的仗来打：克洛克达尔前两次是压制，第三次才是规则战破局（OP-2）
2. 压制战有两种：立个人目标的（OP-4），立世界刻度的（OP-5）
3. 新招先在小场面教规则（OP-7）⚠️待核实
4. 限制可以生出新的戏，比如给伙伴腾出支援段落（OP-8）
5. 情绪的蓄力可以放在开打之前，不一定在打到最低点时才注入（OP-6）
6. 仗的结局不只是输赢，还可以是关系（OP-10）。打斗可以按结局分：打赢、打输、打平、打出关系
7. 颜值可以做成能力规则；免疫可以来自人物性格（OP-10）

## 一人之下（YR）

### YR-1 张楚岚的初赛（罗天大醮）

- **类型**：亮相战，亮的是打法风格，不是能力
- **规则**：能耍赖就绝不动手。轻松晋级，得名"不摇碧莲"（真人版改为"不要脸"）
- **量级**：不立量级，立人设
- **代价**：无
- **分几层**：一层
- **情绪**：好笑
- **能借**：亮相战可以亮"这个人怎么打"，不一定是"这个人有多强"，观众记住的是一种性格
- **不能借**：只靠耍赖赢，多了观众觉得主角没真本事，所以必须有一场证明他不只会耍赖（见 YR-2）

### YR-2 张楚岚 vs 张灵玉（罗天大醮决赛）

- **类型**：打到死斗级的切磋
- **规则**：张灵玉只能修阴五雷，因为和夏禾的过往让他失去了元阳，阴雷本来就是他的心结
- **量级**：张灵玉是老天师的关门弟子
- **代价**：张灵玉最后行炁受阻、力竭倒地
- **分几层**：张灵玉先让一招，夸张楚岚天赋在自己之上 → 解开心结，把阴五雷发挥到极致 → 逼出张楚岚的最强状态 → 张灵玉力竭认输。不少说法认为是老天师给他下了药 ⚠️待核实（天师府词条说张楚岚夺冠靠老天师"暗箱操作"）
- **情绪**：心结，能力的上限锁在心结里
- **能借**：
  1. 心结就是能力的锁，解开心结和能力升级是同一个瞬间。这是变强方式 C 的一种做法：情绪不是外加的回忆杀，而是写在能力规则里
  2. 这一场的任务是证明主角不只会耍赖，和 YR-1 前后呼应
- **不能借**：靠场外因素（下药）决出胜负，观众回头会觉得被骗。短剧要么胜负干净，要么把它做成后面明确交代的悬念

### YR-3 王也 vs 诸葛青（罗天大醮）

- **类型**：同类能力的量级比拼
- **规则**：两人都用奇门。诸葛青的武侯奇门顺势引导；王也的风后奇门能在自定中宫后改动天地格局 ⚠️待核实（粉丝分析）
- **量级**：诸葛青被称为几十年来第一个掌握全部武侯奇门的人，仍输给王也，打得怀疑人生；诸葛青拿出全力，王也看起来还有保留
- **代价**：快速连续发动风后奇局，受内伤吐血、最后晕倒 ⚠️待核实（简书分析）；暴露八奇技传人的身份，被武当除名
- **分几层**：诸葛青全力 → 王也破局
- **情绪**：诸葛青的骄傲被打碎
- **能借**：
  1. 同类能力相撞，打的是层次差：观众先懂"奇门是什么"，才懂"风后奇门高在哪"
  2. 代价可以是剧情后果，不只是身体：赢了比赛，丢了师门
- **不能借**："中宫""格局"这类术语短剧观众接不住，必须换成一眼看懂的画面

### YR-4 冯宝宝 vs 萧霄（罗天大醮）

- **类型**：规则战，反转成碾压
- **规则**：萧霄的绝技擤气，能把人的灵魂暂时轰出体外
- **量级**：诸葛青和王也赶紧下场救下萧霄。两个高手都坐不住，观众就知道这一下有多危险
- **代价**：无（萧霄差点丧命）
- **分几层**：冯宝宝手忙脚乱 → 几回合后找到办法 → 把萧霄还没发出的擤气摁回去
- **情绪**：冯宝宝下手没轻重，带来恐惧和好笑
- **能借**：
  1. 规则战的解法可以是"用你的招打你"，不需要新能力，需要对规则的另一种理解
  2. 借旁人的反应立量级（和 OP-1 同一个做法）
- **不能借**：主角一方差点打死人，要有人拦下，否则观众对主角的好感会掉

### YR-5 风莎燕 vs 贾正亮（罗天大醮）

- **类型**：切磋战，打出关系
- **规则**：贾正亮用十二把斩仙飞刀；风莎燕能穿梭空间，绝技"宇宙迷"能在一定范围里设置多个空间出入口
- **量级**：贾正亮前面靠飞刀击败对手，是大黑马
- **代价**：两人都见血
- **分几层**：开始都不留情，刀刀见血、拳拳到肉 → 风莎燕放出"宇宙迷" → 最后一击贾正亮手下留情，惜败
- **情绪**：赛后两人关系迅速升温
- **能借**：打出关系（和 OP-10 同一种结局）
- **不能借**：前半场的"不留情"必须是真的，否则最后的手下留情没有分量

### YR-6 风星潼 vs 王并（罗天大醮）

- **类型**：同一种能力的正邪对照
- **规则**：两人都用拘灵遣将。风星潼看似气势十足，其实温和；王并的充满邪气
- **量级**：风星潼差点被打死
- **代价**：风星潼失去了一直陪着他的子仲爷爷和帮他过关的柳大爷
- **分几层**：正邪对拼 → 风星潼落败
- **情绪**：失去伙伴的痛
- **能借**：
  1. 同一种能力换一个人用，就是一面镜子：观众看到"这个能力在坏人手里是什么样"
  2. 输的代价可以是失去伙伴
- **不能借**：之后张灵玉轻松打败王并，有评论认为打得太轻。反派刚立起来就被别人轻松打掉，前面立的量级就白费了（反例）

### YR-7 老天师 vs 全性十四人（锡林郭勒草原）

- **类型**：碾压，亮相战的极端版
- **规则**：老天师常用金光咒，这是天师府的基础功法，也是异人界数一数二的护体功法
- **量级**：以丁嶋安为首的十四名全性高手被轻松击败，最后击杀全性代掌门龚庆；十佬想出面阻拦，老天师一巴掌扇飞陆瑾，就没人敢上前了 ⚠️待核实（二手文章）
- **代价**：战后被十佬会判决禁足龙虎山
- **分几层**：一层
- **情绪**：震慑
- **能借**：
  1. 基础招打出天花板：最基础的功法在最强的人手里就是碾压
  2. 量级要靠"观众已经知道多强的人"衬托：陆瑾是观众早就认识的十佬，比打倒一群新面孔有说服力
  3. 碾压也有代价，代价落在剧情上：被禁足
- **不能借**：碾压只适合配角或师父，主角一直碾压就没有"压"

### YR-8 陈朵之死（碧游村篇）

- **类型**：不是打斗，是对手的单元故事
- **规则**：陈朵是蛊身圣童，杀害华南地区负责人廖忠后逃走（廖忠之死的因果，各来源说法不一 ⚠️待核实）
- **量级**：无
- **代价**：她用生命力压住蛊毒，撑了约二十小时
- **分几层**：公司给她两个选项，回公司或者死，她选了死 → 二十小时里和大家逛街、买衣服、吃冰淇淋，做以前没做过的事 → 毒发，含笑而终
- **情绪**："对手"本身是受害者。一辈子被药仙会、公司、碧游村安排，没人问过她想要什么
- **能借**：
  1. 对手是受害者（和框架第二节"迪迦里有的怪兽本身是受害者"同一回事，待用特摄案例交叉验证）
  2. 单元的情绪高潮可以不是打斗，而是一个选择
- **不能借**：碧游村篇有一百多话，短剧里一个对手的悲剧要压在一两集讲完

## 迪迦奥特曼（TG）

> 中文资料多来自问答站和个人文章，可靠性低于前两部，⚠️ 较多。

### TG-1 每集的公式（全剧层面）

- **类型**：叙事壳
- **规则**：出现异常 → GUTS 调查 → 怪兽现身 → 大古变身 → 吃亏、计时器闪烁 → 换形态 → 必杀 ⚠️待核实（按全剧归纳，没有找到出处）
- **量级**：不适用
- **代价**：不适用
- **分几层**：不适用
- **情绪**：观众等的不是"会不会变身"，而是"什么时候、怎么来"
- **能借**：流程固定，观众不用花脑子跟结构，注意力全留给每集的新东西
- **不能借**：固定的是叙事，不是打法。打法也固定，每集就只剩"换了一只怪兽"

### TG-2 三种形态：复合型、强力型、空中型

- **类型**：变强方式 A（换形态）的仪式
- **规则**：复合型力量和速度均衡，平时以它登场；强力型（红）力气最大，擅长近身肉搏；空中型（蓝紫）最敏捷，飞行能力最强。额头的水晶负责形态转换，换时发出不同颜色的光
- **量级**：不适用
- **代价**：无
- **分几层**：复合型 → 按战况换成另外两种
- **情绪**：仪式感
- **能借**：换形态是对战况的回答。对手会飞就换空中型，皮厚就换强力型，观众能提前猜"该换哪个了"
- **不能借**：三种形态之间只差数值（力量、速度），不差规则。数值型换形态，打起来只能比谁更大、更快。《生肖》第一版"戴面具变兽"错就错在这里

### TG-3 彩色计时器

- **类型**：限制
- **规则**：能量减少时胸口计时器由蓝变红并闪烁，熄灭即力量耗尽
- **量级**：不适用
- **代价**：时间
- **分几层**：不适用
- **情绪**：紧张
- **能借**：限制要看得见，观众看灯就知道情况危急；它同时是节拍信号："压"开始了
- **不能借**：迪迦里的计时器大多只是"快不行了"的信号，很少真的逼大古做选择 ⚠️待核实（推论）。和 OP-8 对比：四挡的十分钟空窗逼出"谁来拖住对手"，还生出一段戏。同样是限制，有的只是节拍信号，有的逼人做选择

### TG-4 怪鸟西拉（第 32 集）

- **类型**：对手是受害者
- **规则**：根津博士的女儿麻美在滋尔达气体爆炸中丧生，她养的鹦鹉西拉被她提前放走，后来因气体变异成怪兽
- **量级**：不适用
- **代价**：西拉的生命
- **分几层**：西拉吞下全部滋尔达气体 → 被 GUTS 送进宇宙 → 在迪迦的光的引导下变成金色凤凰，麻美的灵魂出现在它头顶
- **情绪**：心疼
- **能借**：
  1. 对手是受害者（和 YR-8 同一回事）
  2. 仗的结局可以是救赎、送走，不一定是打倒
- **不能借**：要拍出眼泪，靠前面对"人和怪兽原本的关系"的铺垫，短剧要在同一集前半段铺好
- **补充（2026-11-01 深挖）**：
  - 口碑：迪迦"最催泪"的一集，中日多份推荐都提到；日文博客说泪点在于"怪兽和博士各自的念想在结尾重合"
  - 编剧太田爱说想讲的是"失败了也还有很多能做的事，失败以后也要继续往前走"；早期方案以发明毒气的根津博士为中心，导演北浦改成以死去的女孩麻美为中心
  - 能借：同一个悲剧，从"造成悲剧的人"和"失去所爱的生灵"两边讲，结尾让两边的念想重合，比只讲一边更催泪

### TG-5 雪娜和小野田（第 33 集）

- **类型**：情绪由单元配角承载
- **规则**：第 33 集《吸血都市》（2026-11-01 据 Ultraman Wiki 分集页确认）。杂志记者小野田的前搭档雪娜成了吸血鬼；雪娜在告别小野田后，在灼热的阳光下慢慢融化，小野田绝望地呼喊；最后攻击怪兽时，小野田把这一击想象成在给雪娜拍照
- **量级**：不适用
- **代价**：雪娜的生命
- **分几层**：不适用
- **情绪**：悲伤
- **能借**：一集的情绪不一定压在主角身上，可以让单元配角扛（对应框架"变量层每集换，负责打动人"）
- **不能借**：单元配角的情绪比主角还重，次数多了，观众会觉得主角是工具人

### TG-6 大古的身份分批被知道

- **类型**：贯穿线，信息差分层
- **规则** ⚠️待核实（主要来自问答站）：居间惠队长最先确定（约第 44 集）；丽娜第 39 集开始怀疑，第 50 集当面说破；其余队员第 51 集才知道（迪迦被打回石像时，丽娜失声喊出"大古"）
- **量级**：不适用
- **代价**：不适用
- **分几层**：三层
- **情绪**：长时间"观众 > 角色"，观众一直期待"他们什么时候会知道"
- **能借**：一个秘密分好几次让不同的人知道，每一次都是一个情绪点
- **不能借**：短剧集数少，最多分两三层

### TG-7 奥特之星（第 49 集）

- **类型**：前辈返场
- **规则**：大古穿越到 1965 年的圆谷制作组；迪迦败下阵来、能量被夺走，初代奥特曼跨越时空前来支援 ⚠️待核实（多个二手来源一致）
- **量级**：不适用
- **代价**：不适用
- **分几层**：不适用
- **情绪**：情怀
- **能借**：前辈返场支援，就是"自己造出来的熟梗"，迪迦借的是整个系列的熟悉度
- **不能借**：新剧没有前辈可借，要先自己攒出"前辈"
- **补充（2026-11-01 深挖）**：
  - 口碑：虎扑评分前列，网友"五佳"排第 1，Yahoo 回答称"神回"
  - 编剧是初代奥特曼的编剧上原正三。他起初婉拒，说"以后的奥特曼应该由年轻人写"；被说服的理由是迪迦是系列 30 周年，可以借此回顾过去、向创作者致敬。故事设在 1960 年代，写圆谷英二、金城哲夫和他自己一起创造奥特曼。故事发生的龙森湖，就是初代第 1 集怪兽藏身的地方
  - 能借：致敬集要有一个真实的情感来源（创作者本人回望自己的过去），不只是让前辈露个脸

### TG-8 大结局（第 51、52 集）

- **类型**：全剧终极爆发，变强方式 C（羁绊）
- **规则**：迪迦面对打不过的邪神加坦杰厄仍冲上去，战败，变成石像；GUTS 用光遗传子进行照射作战；全世界的孩子变成光，迪迦复活
- **量级**：邪神吞噬地球
- **代价**：主角"死了"
- **分几层**：战败石化 → 人类出手 → 孩子们变成光 → 复活
- **情绪**：羁绊
- **能借**：最低点是主角"死了"；翻盘靠全剧积累的羁绊集中兑现；人类不是旁观者
- **不能借**：这种级别的爆发只能放在季终

### TG-9 恶魔的审判（第 25 集）

- **类型**：主题问题集：信仰之争；人类在最低点出力
- **规则**：第 3 集出现过的基里艾洛德人，这次扮成城市上空的"天使"，宣称能让死者复活，把人群说动，认定迪迦才是"恶魔"，并打开"地狱之门"。居间惠的婆婆也信了，因为她想让死去的儿子回来
- **量级**：它会跟着迪迦换形态：迪迦换强力型，它也变强；迪迦换空中型，它长出翅膀
- **代价**：迪迦力竭倒地，眼睛暗下去，被黑暗吞没
- **分几层**：人群倒向"天使" → 迪迦三种形态都被它克制，倒下 → 居间惠想起迪迦需要光，让 GUTS 战机和车灯照他，不够 → 通过所有通讯向市民求助，人们开车、举着手电赶来照亮迪迦 → 城市的灯忽然全亮，迪迦站起来，打败它，关上地狱之门
- **情绪**：人们宁愿相信能马上解除痛苦的东西；但也有人站出来，用各自的光照亮迪迦
- **能借**：
  1. 对手打的不是迪迦的身体，是人心里"信谁"。对手的规则作用在人群上
  2. 最低点由普通人出力翻盘。导演村石宏实说，这场戏不是在演"光能量补给"，而是人们的信任和力量才是让迪迦复活的"光"
  3. 迪迦复活的姿势，照着城里广告牌上米开朗基罗的《创造亚当》摆（美术寺井雄二带来画册，导演当场想到）；战后迪迦竖大拇指致谢。编剧小中千昭原本只写了点一下头，不赞成加这些
  4. 结尾有一个女人捡起天使的羽毛：不是每个人都信奥特曼（导演原话）。胜利以后留一个"没被改变的人"，让主题不至于变成说教
- **不能借**：靠大量群众演员和城市灯光，制作量大；短剧可以把"群众"压成几个有代表性的人

### TG-10 超越时空的微笑（第 36 集）

> 单元卡（2026-11-01 按新方法重写）。资料：Ultraman Wiki（集页、怪兽戈尔德拉斯页）、五篇日文剧评和角色介绍、讲谈社 TELEMAGA、中文网友评价（来源见迪迦来源）。没有亲眼看过本集，镜头、配乐细节说不准。

- **故事**：
  1. 开头是 GUTS 情报分析员矢住的梦：童年时，他遇见过一位老婆婆
  2. 时空怪兽戈尔德拉斯把各地的磁场聚到樱之丘，过去消失的人和物接连出现：一艘七十年前失踪的运输船停在市区，大正四年（1915 年）出生的女学生手冢百合也被拉到了现代。矢住第一眼见到她，就有一种说不清的似曾相识
  3. 两人去找她的家，那里已经变成一条大马路，她慌了
  4. 队长派矢住带她散心：吃汉堡、进游戏厅、拍大头贴；他在路边摊买了一个吊坠，把两人的大头贴放进去送给她
  5. 堀井提醒矢住：原因一消失，她停住的时间会一下子涌回来，她可能变成白发老太太，最坏会变成骷髅
  6. 什么都不知道的百合，向出发去战斗的矢住道谢，一直挥手直到车开远，矢住从后视镜里看着她
  7. 矢住自己查出怪兽的弱点：角发光以后，力量减弱约 0.3 秒。副队长宗方问"能做到吗？"他答"是！"宗方说"射击就交给你了！"
  8. 他想着后视镜里挥手的她，按下扳机打碎了角；迪迦消灭怪兽，时空复原
  9. 她和怪兽一起消失了。矢住说"是我杀了她"
  10. 他想起童年那位老婆婆，回家找出她当年送他的吊坠，打开，里面是那张大头贴：老婆婆就是百合。她回到了自己的时代，活过了一生，在晚年遇见了小时候的他
- **情绪和想表达的**：
  - **带走的情绪**：一段注定只有一天的初恋，亲手放开它的痛，最后被一个跨越八十年的微笑接住
  - **想说的那句话（推测）**：相遇哪怕只有一天，也不会因为分开而消失；你以为自己伤害了对方，对方其实带着你给的东西好好活了一辈子，还回来守过你。日文剧评的读后感："人死了，就再也见不到喜欢的人；活着，总有一天能再见"
  - **谁变了**：矢住，一个不是战士的普通队员，学会了为别人放手
- **怎么交给观众**：
  - **第一层：先让你在乎她**
    1. 先让你心疼她的处境，再让你喜欢她这个人：她到现代以后最先遇到的，是家变成了马路
    2. 约会用的全是观众最熟悉的小事（汉堡、游戏厅、大头贴），她每惊讶一次，甜和"她不属于这里"的距离感就同时出现一次
    3. 一天的约会被凝成一件能拿在手里的东西：吊坠。这时观众只觉得是个可爱的小礼物
    4. 心动的是一个普通人，不是英雄，观众代入的是"普通男孩第一次喜欢上一个人"
  - **第二层：让放手有重量**
    1. 代价在按扳机之前就说清楚了（堀井的警告），之后每一秒都是"知道结局会疼"的
    2. 告别放在她不知道的时候：她笑着挥手道谢，矢住从后视镜里看着她越来越小。观众和矢住知道同一个秘密，她却在笑（剧评者印象最深的场面）
    3. 选择交到他一个人手上，只用一个字："能做到吗？""是！"没人替他决定，台词越短越重
    4. 按扳机前，再让观众看她一眼（他想起后视镜里的她）
    5. 胜利的那一秒就是失去的那一秒：没有欢呼，只有"是我杀了她"
  - **第三层：让那个微笑落下来**
    1. 答案一开始就摆在观众面前：开头的梦、第一眼的似曾相识，观众看到了，但没当回事
    2. 结尾一句解释都没有，只打开一个吊坠。观众自己把梦、似曾相识、送出去的吊坠全部连起来；从"我杀了她"的最低处，一下翻到最暖的地方
    3. 信物绕了八十年回到他手里，观众感到的是"她一直带着它"，而不是"设计得真巧"
    4. 片名把终点定在一个微笑上，不是打赢怪兽
  - **贯穿全集**：只跟着矢住一个人的心走，主角大古退到后面。剧评说实际只有二十几分钟，观众照样能代入
- **对照高光倒推**：
  - 先在乎什么：她失去了家；那一天的约会
  - 先知道什么：打倒怪兽，她会老去、会死
  - 先被压到多低：不知情的挥手；"是我杀了她"
  - 爆点：打开吊坠，不是打赢怪兽
- **为什么成立**：
  1. 矢住是观众看了三十多集的熟面孔，他的心动和痛不需要再介绍
  2. 怪兽战的壳还在：怪兽、GUTS、迪迦、必杀一个不少，只是退到后面
  3. 情绪线一条到底，没有支线分心
- **能借**：
  1. 代价由亲手按扳机的人承担：胜利条件和失去所爱是同一个动作
  2. 不知情的告别：观众知道代价，当事人不知道，平常的道别就成了名场面
  3. 信物闭环：首尾呼应靠一件物件，不靠台词；结尾的那一下同时揭开谜底、解开主角的心结
  4. 熟悉的日常里放进一个反常的人：反常感和甜感都来自最普通的场景，几乎不花特效钱
  5. 借经典的机制，换自己的皮：编剧长谷川圭一参考了电影《时光倒流七十年》，那部电影里老妇人把一块怀表交给年轻男主角，怀表成了没有起点的闭环；本集换成了大正少女和大头贴吊坠（框架第二章"借什么、新在哪"的程度 1 到 2）
- **不能借**：
  1. 谜底揭得太早：开头的梦就露了底，有剧评认为扫兴。要用"开头的梦 = 结尾的真相"，梦里只给一点点，比如只看见吊坠、看不见脸
  2. 时间悖论不严谨：特效导演大冈新一说"给出清楚、让人满意的结局"比严格的逻辑更重要；情感单元可以这样，规则战不行
  3. 中段偏平（中文网友）；少女的表演偏硬（日文剧评）
- **待核实**：讲谈社《电视君》引用的台词"……这么阴沉！打起精神来嘛。呵呵……你看……我不也这么精神吗……"，推测是年老的百合对小时候的矢住说的 ⚠️待核实
- **制作备注**：编剧右田昌万为主，长谷川圭一提供了《时光倒流七十年》等想法；百合原本设想年纪更大，因为由中学生出演改成少女。少女百合由神谷沙耶加饰演，年老的百合由中千子饰演

### TG-11 继承影子的人（第 44 集）

- **类型**：镜像主角；力量落到恶人手里；伙伴之死
- **规则**：科学家正木敬吾也带着超古代人的基因。他先造机器怪兽逼大古变身（第 43 集），查出迪迦是谁，再偷走神光棒，和另一座巨人石像融合成邪恶迪迦。他想成为神，结果他和巨人都控制不了那股力量
- **量级**：在熊本横冲直撞，GUTS 毫无办法
- **代价**：加迪死了
- **分几层**：大古失去神光棒，变不了身 → 石像从前的伙伴加迪，附在一条受伤的狗身上醒来，哭着劝旧友住手 → 邪恶迪迦把它打死 → 大古夺回神光棒，变身，两个迪迦对决 → 迪迦抱住死去的加迪（动作演员即兴，导演保留）
- **情绪**：伙伴为了唤醒变坏的旧友而死
- **能借**：
  1. 同一种力量换一个人用就是镜像（和 YR-6、KJ-6 一回事）。编剧小中千昭解释集名用"影"不用"暗"：邪恶迪迦不是天生的恶，它仍然是真正的奥特曼，只是落到了错误的人手里
  2. 集名《继承影子的人》和第 1 集《继承光的人》对照，镜像从标题就开始了
  3. 主角先失去变身能力，让伙伴先上场、先牺牲，主角回来时情绪已经蓄满（和 SV 的胶囊怪兽是同一种结构）
- **不能借**：加迪是制作方要求的"胶囊怪兽"式角色，依附在狗身上来源于"狗是人的伙伴"。短剧里用伙伴之死，伙伴必须在前面先露过面

### TG-12 永恒的生命（第 45 集）

- **类型**：主题问题集：诱惑；人类自己选择
- **规则**：一种黄花（吉杰拉）的花粉让人陶醉、沉溺；花开遍全世界，TPC 全员都醉了，只剩大古和少女特拉清醒。特拉和父亲努克是超古代文明的生化人，靠这种花的提取物保住大脑活下来；超古代文明就是在这种快乐里灭亡的
- **量级**：天黑以后花粉失效，人们却自己上街去找花、为花打架
- **代价**：烧掉花粉，也就毁了努克父女赖以生存的东西
- **分几层**：花开遍全球 → GUTS 醒来后讨论：人类也许宁愿要快乐的毁灭，也不要痛苦的现实 → 迪迦在人群"别碰它"的喊声中攻击巨花 → 被花粉喷中、倒吊起来 → GUTS 开火，同时一些人自己动手毁掉身边的小花 → 迪迦烧掉花根 → 努克父女道谢："生命是短暂的，人类是美好的"
- **情绪**：人类差一点选择沉溺
- **能借**：
  1. 对手是一种诱惑，不是一个敌人；迪迦能打倒巨花，但打不掉人们想要它的心
  2. 结尾 GUTS 总结：做决定的是人类，不是迪迦。最后的胜利有一部分来自普通人自己动手（和 TG-9 互相呼应，网友也指出这两集是一对）
  3. 编剧右田昌万说，经典奥特曼都是"出问题、解决问题"的因果结构，这集不一样：打倒怪兽不等于人们马上清醒。他避开了"从洗脑中醒来"这种写法
- **不能借**：写"戒断"太写实，儿童向作品里没法写；编剧最初想写说服沉溺者戒掉，发现写不出来，才改成以迪迦为中心。短剧要找一个能用画面讲清的"放下"

### TG-13 复活的鬼神（第 16 集）

- **类型**：民间传说单元：轻松、换口味
- **规则**：三个小偷从山中神社偷走一把剑和一尊像，被古代游侠武士斩碎、分开埋葬的鬼神宿那鬼复活报仇。武士的魂附在一个良心不安的小偷身上；他说鬼神的恨比当年更深了，这次他一个人打不过
- **量级**：鬼神的手脚从整座山里冒出来
- **代价**：无
- **分几层**：小偷偷宝、内讧 → 大古遇见一个时而看起来像武士的人，武士说大古"不是人，但不是威胁" → 鬼神现身，迪迦被它背后的第二张脸偷袭 → 迪迦砍下鬼头，鬼头飞起来咬住他的肩膀 → 武士的剑自己飞起来，刺中鬼头，净化了它 → 小偷被警察带走前，把武士的话转告大古
- **情绪**：好笑，带一点传奇感
- **能借**：
  1. 拿观众熟悉的民间传说当单元：武士斩鬼、分尸封印、鬼神复仇，规则观众一听就懂
  2. 导演川崎郷太和摄影商量后，刻意避开严肃基调，用轻松的风格拍（日文博客把这集评为"笑的神回"）。长篇单元剧里，需要这样的集来换口味
  3. 请了搞笑组合客串小偷，喜剧感来自人物，不来自台词
  4. 日文博客说结尾"问到了奥特曼的本质"：武士认出大古不是人
- **不能借**：初稿是"怪兽把车困在隧道里"，被推翻后编剧川上英幸改用自己喜欢的妖怪传说重写。题材要选写的人真心喜欢的

### TG-14 我看到了奥比科（第 27 集）

- **类型**：民间传说单元：不想被遗忘的妖怪；送别
- **规则**：妖怪奥比科每晚扮成推着路边摊的厨子，用影子戏吓唬日子野村的人；被它抓走的人五分钟后出现在山里，头发全白。因为村子要盖健身乐园，它从前最喜欢的地方要没了，它才开始作祟
- **量级**：它在暗处瞬移，把 GUTS 队员一个个戏弄
- **代价**：奥比科的命
- **分几层**：新城夜里听见孩子的声音叫他"一起玩"，他记住堀井奶奶的话没有回头 → 大古往它的锅里扔了追踪器 → 村民夜里全部闭门，GUTS 放鞭炮把它引出来，它看见村子恢复了旧日的样子，高兴得跳起来 → 大古求它离开，它不肯，变成巨人 → 迪迦只防守、不还手 → 奥比科看着眼前的村子，自己迎上迪迦的手刀，两个都化为光粒 → GUTS 明白了，它吓人是因为不想被忘记
- **情绪**：开头像鬼故事，结尾是一股乡愁（网友评价）
- **能借**：
  1. 编剧太田爱说，故事起点是"一个总在回想已经消失的东西的角色"，想让孩子理解人和地方的失去。奥比科原本设想成一个老人，只活在怀念里
  2. 对手吓人的动机，是怕被遗忘：动机一揭开，鬼故事就变成了乡愁
  3. 主角选择只守不攻，对手自己选择结束（和 YR-8 的"单元高潮是一个选择"相通）
- **不能借**：原剧本和制片人的结局是"迪迦把虚弱的奥比科送到远离人类的地方"，因为"奥比科什么坏事都没做"；导演拍摄时擅自改成了它自己消散，制片人看片后很不满，当面质问导演。结局要事先和团队对齐

### TG-15 蓝色夜晚的记忆（第 29 集）

> 单元卡（2026-11-01 按新方法重写）。资料：Ultraman Wiki（集页、纳塔恩星人页）、三篇日文剧评、讲谈社 TELEMAGA、中文影评摘要（来源见迪迦来源）。没有亲眼看过本集，镜头、舞台细节说不准。

- **故事**：
  1. 当红歌手来栖玛雅人气大到粉丝有专门的称呼。真弓拉着大古去看她的演唱会，矢住吃醋，丽娜冷眼旁观。开场曲是《Be My Baby》的翻唱
  2. 新城试飞出事，差点死掉，醒来像变了个人，迷上了玛雅
  3. 真相：玛雅身体里住着一个外星女孩。十五年前她流落地球，附在一个刚在车祸中死去的女孩身上，从此用这个名字活着。附在新城身上的，是她失散十五年的哥哥，来接妹妹
  4. 她们的故乡被曾经的友邦纳塔恩星人灭了，母亲被杀，哥哥被抓后逃出。哥哥对大古说"故乡已经没了，要和同伴去找新的地方"，对妹妹却说"我们回出生的那颗星球"
  5. 兄妹重逢，哥哥解释为什么十五年都没能来接她
  6. 纳塔恩星人附在路人身上追到地球，开枪打死了附在新城身上的哥哥。大古怒喊"践踏自由，算什么正义！"，迪迦不到一分钟就消灭了它
  7. 新城醒来，人没事。为了不让玛雅知道哥哥已死，他假装还是哥哥，劝她"留在地球吧"
  8. 玛雅看穿了，没有说破，扑进了新城的怀里
  9. 出道一周年的舞台上，她唱了一首送给哥哥的《蓝色夜晚的记忆》
- **情绪和想表达的**：
  - **带走的情绪**：孤独。一个被万人喜爱的明星，其实是这个星球上最孤独的人；中间有过一次回家的希望，又被拿走；最后她选择留下来
  - **想说的那句话（推测）**：故乡没了以后，人要在异乡把自己活下去，留下来不是被困住，是自己的选择；爱一个人，有时就是替他撒一个谎；越热闹的人越可能孤独。编剧长谷川圭一说，他想写的是"留在地球上的辉夜姬"，一个充满孤独的故事
  - **谁变了**：玛雅，从等着被接回家，到自己决定留下
- **怎么交给观众**：
  - **第一层：在你知道真相之前，先让你看见她的热闹**
    1. 开场全是热闹：全民偶像、演唱会、队员们吃醋，一首欢快的老歌翻唱
    2. 后来才揭开连名字都不是她的。前面越热闹，揭开以后越孤独
    3. 新城的"追星"先被当成笑话，后来才知道是哥哥在找妹妹：同一个行为，先让你笑，再让你心疼
  - **第二层：让你比她先知道残酷的事**
    1. 哥哥对大古说故乡没了，对妹妹说"回家"。从此她每期待一次回家，观众就疼一次（和 TG-10 后视镜挥手同一种做法：她不知道，你知道）
    2. 十五年的道歉："终于被找到"的委屈和欢喜，是全集最暖的地方，也是为失去蓄力
  - **第三层：打斗一闪而过**
    1. 迪迦和敌人的战斗不到一分钟，是迪迦里最短的战斗之一。大古一句怒喊、一道光线，愤怒一闪就过去，镜头马上回到妹妹身上。打斗短，是为了不打断情绪线
  - **第四层：她怎么知道，又怎么接受**
    1. 第二个谎言：新城假装还是哥哥，劝她留下。一集里两个"哥哥"都在为她撒谎
    2. 她看穿了却不说破，扑进新城怀里。不用台词，观众从这个拥抱里就明白：她知道了，她接受了，她决定留下。中文影评指出，新城的话其实没起作用，她是在拥抱以后才决定留下的
    3. 最后的告别放在舞台上：万人面前，她为一个没人知道的人唱歌。一场在上万人面前举行、却没有人知道的葬礼（推测，由剧评"明星的孤独"推导）
    4. 情绪交给一首观众熟悉的歌：《蓝色夜晚的记忆》是 Procol Harum《苍白的浅影》的日文翻唱，歌词由编剧长谷川自己写。那段旋律本身就自带哀伤；剧评说歌和配乐配得极好，满屏的星空让宇宙显得又静又远
  - **人类这边的镜子（推测）**：新城自己也有妹妹真弓，日文剧评读出这一集也是真弓和新城吵架后的和好。新城去替一个外星哥哥扮演哥哥，可能正因为他自己就是哥哥
- **对照高光倒推**：
  - 先在乎什么：她的热闹，以及热闹背后十五年的孤独
  - 先知道什么：故乡已经没了，观众比她先知道
  - 先被压到多低：哥哥死在她面前
  - 爆点：那首歌，不是打斗
- **为什么成立**（为什么几乎没有打斗、主角戏份很少，照样被叫作神回）：
  1. **它给的情绪又多又稀有**：普通怪兽战给的是"爽"，看过几十场以后越来越薄；这一集给的是"孤独"和"送别"，整部剧里很少有。迪迦口碑前两档里，第 16、27、29、36 集都不是靠打斗出名的
  2. **壳一点没缺，只是压短了**：外星人、GUTS、变身、必杀都在。观众对"迪迦会赢"本来就有把握，一分钟打完不会觉得被骗；憋了一集的愤怒一下释放，爽被压缩了，没有消失
  3. **主角其实是换了一个**：这一集的主角是观众跟了二十八集的核心队员新城，视角只跟着兄妹一条线
  4. **处境人人都有过**（推测）：没有人是流落地球的外星少女，但几乎每个人都有过"在热闹里觉得没人懂我"、想家又回不去的时刻
  5. **写的人是真心的**：这是长谷川刚入行当布景助理时自己构思的故事
  6. **"封神"考验的是被记住**（推测）：几十场打斗会混在一起，一首在万人面前为无人知道的人唱的歌会单独留下来
  - **前提**：它是 52 集里的一集，稀少才珍贵；它花掉了前面二十八集对新城的积累；壳还在跑；情绪线足够强，强到能顶替打斗
- **能借**：
  1. 让观众比角色先知道一个残酷的事实，再看角色说出满怀希望的话
  2. 为对方撒谎的人，加上一个看穿却不说破的人：情绪全在没说出口的那部分
  3. 公开场合里的私人告别：越热闹的场面，告别越孤独
  4. 用一个人类配角，去照外星人的关系
  5. 核心角色立住以后，隔一段放一集"情绪集"：打斗压到最短，让观众已经在乎的配角当主角，用一种稀有的情绪换口味
- **不能借**：
  1. 借现成老歌有版权问题：短剧要用原创旋律，或找别的自带情绪的熟悉元素
  2. 故事原本是一小时的长度，被压成了 30 分钟；导演原田昌树（这是他在奥特曼系列的导演处女作）一开始也怀疑迪迦戏份这么少适不适合拍。主角退后的单元，要先想清楚用什么撑住节奏
  3. 反派只是工具（剧评说它"又弱又卑鄙"）：能这样做，是因为情绪全在兄妹身上；重心在打斗上的单元不能这样处理反派
  4. 试播集和前几集不能这样做：观众还不认识任何人，只能先用打斗和规则留住他
- **待核实**：哥哥对妹妹说"回家"的原话；舞台那场戏的具体样子 ⚠️待核实
- **制作备注**：长谷川说这个故事最初写的是一小时的长度；"玛雅"这个名字来自赛文第 37 集的玛雅（SV-4），两个玛雅的境遇正好相反（日文剧评）。片中歌曲由圆谷旗下歌手须藤瞳演唱，演玛雅的是田中规子

## 铠甲勇士（KJ）

> 资料主要来自维基百科和百度百科，维基条目本身标着"来源不足"。

### KJ-1 五行铠甲的分工

- **类型**：团队定位
- **规则**：炎龙侠（火）能力最均衡、最有潜力；风鹰侠（木）速度最快、能瞬间移动；黑犀侠（水）防御最强。地虎侠（土）、雪獒侠（金）的定位 ⚠️待核实
- **量级**：不适用
- **代价**：不适用
- **分几层**：不适用
- **情绪**：不适用
- **能借**：队伍里每人一句话说得清的定位，观众一看就能排名次
- **不能借**：定位是数值型的（速度、防御），和 TG-2 同一个毛病

### KJ-2 召唤口诀

- **类型**：仪式
- **规则**：基本格式是"××铠甲，合体！"
- **量级**：不适用
- **代价**：不适用
- **分几层**：不适用
- **情绪**：仪式感
- **能借**：一句孩子能模仿的口号本身就是传播素材，后来游戏联动宣传用的就是"铠甲合体"
- **不能借**：口号只负责仪式，替代不了打斗设计

### KJ-3 伙伴一集一集登场

- **类型**：伙伴集结
- **规则**：炎龙侠第 2 集登场，风鹰侠第 3 集，黑犀侠第 10 或 13 集 ⚠️待核实（来源不一致）
- **量级**：不适用
- **代价**：不适用
- **分几层**：不适用
- **情绪**：期待
- **能借**：伙伴逐个出场，对应框架"先露面，后展开"
- **不能借**：节奏细节未查全，核实后再下结论

### KJ-4 帝皇侠：最强形态先落在敌人手里

- **类型**：压制战 → 阶段高潮
- **规则**：帝皇侠第 46 集正式登场。召唤有两种方式：拥有五村血脉的人单独召唤，或五人合体召唤
- **量级**：向阳被黑帝控制后变成帝皇侠，召唤出远古四大恶兽
- **代价**：向阳之后身体虚弱，暂时无法再召唤
- **分几层**：向阳被控制成为帝皇侠 → 在敏慈的阻止下恢复意识 → 结局黑帝被暗影五护法残魂附身成为暗影黑魔兽，五位铠甲勇士合体成帝皇侠将它封印
- **情绪**：羁绊
- **能借**：
  1. 最强形态先出现在敌人一方或被控制的人身上，第一次露面就是压制战，量级先立住
  2. 再由主角们靠羁绊（五人合体）夺回来，成为阶段高潮
- **不能借**：原作走完这个过程用了四十多集，短剧要压到一个单元里

### KJ-5 暗影五护法附身，必须对方完全同意

- **类型**：反派规则
- **规则**：暗影五护法要附身他人才能在人间行动，而且必须得到对方完全同意。冰儿曾被恶水护法附身，结局摆脱控制，与北淼重归于好
- **量级**：不适用
- **代价**：被附身者失去自我
- **分几层**：不适用
- **情绪**：被诱惑、被救回
- **能借**：反派规则里写着"受害者必须同意"，每次附身都是一个人的心结和选择（可与 YR-2、TG-4 连起来看）
- **不能借**："同意"不拍出诱惑的过程，就是一句空设定

### KJ-6 铠甲能换人，也有人叛变

- **类型**：同一能力的镜像
- **规则**：铠甲是装备，人可以换。炎龙铠甲除李炘南外，张健、殿南也召唤过；后来还有二队。剧情里有张健叛变。叛变时是否用的炎龙铠甲 ⚠️待核实
- **量级**：不适用
- **代价**：不适用
- **分几层**：不适用
- **情绪**：背叛
- **能借**：同一套铠甲在不同人手里就是一面镜子（和 YR-6 一回事）
- **不能借**：换人太频繁，观众记不住谁是谁

### KJ-7 异能兽：每集都来的理由

- **类型**：叙事壳
- **规则**：五千年前暗影大帝派人带 55 颗魔灵石入侵地球，魔灵石和地球生命结合变异成异能兽。第 1 集异能兽袭击渔民，受害者都失去了某段记忆
- **量级**：不适用
- **代价**：不适用
- **分几层**：不适用
- **情绪**：不适用
- **能借**：
  1. 对手从哪来用一条统一规则说清，"为什么每集都来一个新对手"就有了答案
  2. 55 颗魔灵石天然是计数器，观众知道还剩多少（类似七龙珠的收集）
- **不能借**：规则太死，每只异能兽就是"一颗石头 + 一种生物"的流水线，每只还得有自己的故事（参见 TG-4、TG-5）

## 假面骑士（KR）

> 选了三部规则设计差异最大的：空我、龙骑、W。资料以英文维基和粉丝 wiki 为主。

### KR-1 空我的形态：武器要从环境里拿

- **类型**：变强方式 A（换形态），差在规则而不只是数值
- **规则**：
  - 青龙形态：速度最快、跳得最高，但力量比基础形态弱；把长棍类物件重构成青龙棍
  - 天马形态：感官提升到极限，能精准远射；要先拿到"能射出东西"的物件（常是一条警官的手枪）才能变出天马弓枪
  - 泰坦形态：力量和防御最强；把棒状物件（常是摩托车把手）变成泰坦剑
- **量级**：不适用
- **代价**：每种形态都有短板（青龙弱、天马脆、泰坦慢）
- **分几层**：基础形态 → 按战况换形态 → 后期 Rising 强化
- **情绪**：不适用
- **能借**：换形态有条件（先找到对应的物件），换形态本身就成了战术决策，也给了画面"在战场上找东西"的动作。这是 TG-2、KJ-1 的对照：形态差在规则和条件上，打法才会不一样
- **不能借**：每次都要找物件，节奏会拖。短剧里物件要提前在场景里摆好（铺垫）

### KR-2 空我的古朗基：反派自己有游戏规则

- **类型**：反派规则，叙事壳
- **规则**：古朗基族在玩一场杀人游戏（Gegeru），一次只派一个出手，按等级规定杀人数量和时限；成功就晋升，失败或违规就死。裁判在挑战者的腰带里植入封印能量，失败或被空我必杀击中就会自爆 ⚠️待核实（粉丝 wiki，各来源细节不一）
- **量级**：等级越高，杀人数越多
- **代价**：不适用
- **分几层**：不适用
- **情绪**：恐惧；警方和空我在追"他按什么规律选人"
- **能借**：
  1. 反派有自己的规则，"为什么一集一集来"就有了答案（和 KJ-7 一回事）
  2. 杀人数和时限就是倒计时，每集自带紧迫感
  3. 每个古朗基选人的规律不同，查出规律本身就是一场规则战
- **不能借**：杀人游戏的残酷程度要按平台尺度调整

### KR-3 龙骑：十三个骑士的大逃杀

- **类型**：限制逼选择；伙伴即对手
- **规则**：十三个骑士在镜世界里互相厮杀，最后的胜者能实现一个愿望。骑士借契约兽的力量变身，用 Final Vent 和契约兽合击。代价是要用打倒的怪物的生命喂契约兽；卡组被毁或退出不当骑士，契约兽就可能反噬主人 ⚠️待核实（出自维基镜像）
- **量级**：不适用
- **代价**：不打就可能被自己的契约兽吃掉
- **分几层**：不适用
- **情绪**：每个骑士为了自己的愿望而战，没有纯粹的反派
- **能借**：
  1. 限制逼人做选择：不打，契约兽就反噬；打，就要伤害别人。和 OP-8 一样，属于"逼选择"型限制
  2. 每个对手都有自己的愿望，打斗的情绪来自"他为什么非赢不可"
- **不能借**：十三个骑士人数太多，短剧撑不住

### KR-4 W：两个人变成一个骑士

- **类型**：组合，把关系写进能力
- **规则**：左翔太郎和菲利普用两个盖亚记忆体插进双驱动器，合成一个假面骑士 W；左右两半各一个记忆体，换着组合出不同形态。牙王记忆体组成的 FangJoker 更强更快，但对菲利普身体负担大、很少用；菲利普只有在翔太郎协助下才控制得住牙王 ⚠️待核实（粉丝 wiki）
- **量级**：不适用
- **代价**：FangJoker 伤菲利普的身体
- **分几层**：基础组合 → 换组合 → 特殊形态
- **情绪**：搭档的信任
- **能借**：
  1. 两人一体：关系就是能力，搭档吵架就打不好，这让关系戏和打斗戏成了同一件事
  2. 两集一个案子：第一集查（谜面），第二集破（解法），对应框架"两三集单元怎么断"
  3. 决胜台词"来，数数你的罪孽吧"，和 KJ-2 的口号一样是仪式
- **不能借**：组合太多观众记不住，短剧控制在两三种

## 超级战队（SS）

> 系列层面的套路为主，资料多为英文粉丝 wiki 和 TV Tropes。

### SS-1 每集的公式：先小打，再大打

- **类型**：叙事壳
- **规则**：怪人出现 → 地面战，用各自的武器和武术 → 怪人被打倒后巨大化 → 召唤机甲合体成巨型机器人 → 必杀。电子战队电子人确立了"打倒后变大"；也有例外，超电子生物人的怪人不会变大
- **量级**：第二场从人的尺度变成楼的尺度
- **代价**：不适用
- **分几层**：两场仗，两种尺度
- **情绪**：仪式感
- **能借**：一集里两场仗、两种尺度，框架"大小对比：先小打，再大打"直接写进了公式
- **不能借**：第二场往往没有新规则，只是换个尺度再打一遍 ⚠️待核实（推论）。第二场要有新东西，否则就是重复

### SS-2 第六人：先当对手，后入队

- **类型**：伙伴集结；打出关系
- **规则**：第六人是补充成员，通常在季中登场（粉丝说法是大约每年六月）。经典做法是先当敌人：恐龙战队的龙战士布莱先是敌人，兄弟和解后才加入；时间战队的时间火是红战士自负的竞争对手，最后成了队友；爆龙战队的爆龙杀手在最后一刻才倒戈
- **量级**：第六人登场时往往比主角们强
- **代价**：不适用
- **分几层**：敌对 → 交手 → 和解 → 入队
- **情绪**：从敌对到信任
- **能借**：新核心角色以对手身份先登场，先打一场压制战或切磋战，再翻转关系入队（和 OP-10、YR-5 的"打出关系"一回事）。季中登场正好是一个阶段高潮
- **不能借**：每个新伙伴都走"先当敌人"，就成了套路，要换着来

### SS-3 海贼战队：前辈的力量就是能力

- **类型**：熟梗当能力；前辈返场
- **规则**：过去 34 支战队在"传说大战"里交出了力量，力量化为大战力钥匙散落宇宙。海贼战队把钥匙插进变身器，就能变成前辈战队的成员，拿到他的外观、战斗方式和必杀技。前辈以平民身份来到地球，先考验海贼战队，再揭示自己战队成功的秘诀。结局时钥匙归还原主
- **量级**：借的是前辈的名声
- **代价**：不适用
- **分几层**：变成前辈 → 前辈考验 → 拿到前辈战队的大力量
- **情绪**：怀旧
- **能借**：
  1. 观众早就认识的东西直接做成能力，每集换一个前辈，就是一个自带情绪的变量（和 TG-7 一回事，镇魂街借历史人物也是同一招）
  2. "前辈考验后传授秘诀"本身就是一种教学战
- **不能借**：靠的是 34 年的积累，新剧没有。我们能借的熟梗是生肖、成语、民间传说

### SS-4 名乘和集体摆姿势

- **类型**：仪式
- **规则**：变身后各自报上名号、摆出姿势，最后集体亮相，背后爆炸 ⚠️待核实（广为人知，但没查到专门来源）
- **量级**：不适用
- **代价**：不适用
- **分几层**：不适用
- **情绪**：仪式感
- **能借**：集体亮相给观众一个确认"人齐了"的时刻，也给每个人一个单独的特写
- **不能借**：短剧时长紧，每人报名号太长，要压成一个镜头

## 妖精的尾巴（FT）

### FT-1 纳兹吞下以太纳诺 vs 杰拉尔（乐园之塔篇，动画第 40 集前后）

- **类型**：死斗，冒险爆发
- **规则**：纳兹是火之灭龙魔导士，能吃火恢复（吃不了自己的火 ⚠️待核实）。以太纳诺魔水晶里混着多种属性，不只是火
- **量级**：杰拉尔是幕后黑手，乐园之塔本身是一件兵器
- **代价**：非火属性的力量在体内反噬
- **分几层**：被压制 → 吃下魔水晶 → 进入"龙之力"，短时间内强到足以打败杰拉尔 → 纳兹昏倒，魔水晶失控要爆炸，艾露莎把自己融合进去救大家
- **情绪**：为了艾露莎
- **能借**：
  1. 爆发必须冒险：白给的变强不燃
  2. 爆发的后果可以转到伙伴身上，直接生出下一段情绪戏（艾露莎的牺牲）
- **不能借**：吃下魔水晶前要先让观众知道"吃别的属性会出事"，否则就是临时冒出的新能力

### FT-2 艾露莎的换装

- **类型**：变强方式 A（换装），差在克制规则
- **规则**：每套铠甲对应一种战况：海皇之铠抵消水系攻击；天轮之铠一次召出大量剑，专打一对多；炎帝之铠减轻火焰伤害；雷帝之铠克制雷系（对拉克萨斯、马卡洛夫有利）⚠️待核实（二手资料）
- **量级**：不适用
- **代价**：不适用
- **分几层**：按对手换装
- **情绪**：仪式感
- **能借**：每套铠甲差在"克制谁"，不只是数值，观众会预判"这次换哪套"（和 KR-1 一起，是 TG-2、KJ-1 的正面对照）
- **不能借**：铠甲太多，观众记不住。短剧里一个角色最多三四套，每套第一次出场都要用画面教清楚它克什么

### FT-3 纳兹和加吉尔 vs 拉克萨斯（妖精尾巴之战篇，动画第 41 集前后）

- **类型**：团战，关系在打斗中兑现
- **规则**：拉克萨斯是雷之灭龙魔导士，想夺下公会
- **量级**：拉克萨斯把纳兹打到濒死
- **代价**：加吉尔替纳兹硬吃了一招
- **分几层**：二打一 → 拉克萨斯放出雷龙天阵之矛要了结纳兹 → 加吉尔把雷引到自己身上，当避雷针硬扛 → 纳兹打败拉克萨斯
- **情绪**：加吉尔刚加入公会不久（之前是敌对公会的人），这一挡是他第一次用行动证明自己是妖精尾巴的人
- **能借**：前敌人用身体给新伙伴挡招，关系在打斗里兑现，不用台词交代（和 SS-2 的"先当对手后入队"接上）
- **不能借**：纳兹吃雷变成"雷炎龙模式"的具体场景和时间 ⚠️待核实，暂不使用

### FT-4 拉克萨斯被逐出公会，和幻想游行上的手势

- **类型**：不是打斗，是仗打完以后的余波
- **规则**：拉克萨斯被打败后回到公会，马卡洛夫含泪把孙子逐出公会。幻想游行时，拉克萨斯在远处看着，马卡洛夫和整个公会一起举起手势，无声地告诉他"我们会一直看着你"。这个手势是拉克萨斯小时候想出来的 ⚠️待核实（粉丝 wiki）
- **量级**：不适用
- **代价**：被逐出公会
- **分几层**：逐出 → 游行 → 手势 → 拉克萨斯落泪
- **情绪**：羁绊；反派被原谅
- **能借**：
  1. 羁绊需要一个具体的、能反复用的动作，光靠台词撑不住
  2. 动作的来历（他小时候发明的）就是铺垫，兑现时一句话都不用说
  3. 单元的情绪高潮可以放在打完以后的余波里
- **不能借**：没有前面的铺垫，手势就只是一个手势

## 镇魂街（ZH）

> 资料以知乎、百度百科、维基百科为主，粉丝整理居多，具体话数大多未核实。

### ZH-1 守护灵：历史人物就是能力

- **类型**：熟梗当能力
- **规则**：寄灵人召唤守护灵战斗，守护灵多是历史人物。曹焱兵是火属性寄灵人、三大武神躯之一，守护灵都是三国曹魏名将（许褚、典韦、夏侯惇、夏侯渊、徐晃、张郃、张辽等）。张郃能化成曹焱兵的铠甲。战力取决于召唤的守护灵数量；曹焱兵初登场时只召唤了许褚一个
- **量级**："地狱道"测定寄灵人和守护灵的总灵力，镇魂将分八等，从等活到无间
- **代价**：不适用
- **分几层**：召唤一个 → 逐个增加
- **情绪**：观众对这些历史人物自带印象和期待
- **能借**：
  1. 观众早就认识的人物直接做成能力，量级预期是现成的（和 TG-7、SS-3 一回事）
  2. 战力和"召唤了几个"挂钩，观众数得出来；初登场只放一个，就是先露面后展开
- **不能借**：熟梗要选观众真的熟的。三国武将对中文观众是零成本，生僻人物就没有这个效果

### ZH-2 于禁：赢的代价是失去守护灵

- **类型**：代价
- **规则**：少年曹焱兵以于禁为代价击败八神斋的恶灵军团，于禁魂飞魄散，曹焱兵因此得到十殿阎罗与七武将
- **量级**：一支恶灵军团
- **代价**：最初的守护灵于禁魂飞魄散
- **分几层**：不适用
- **情绪**：失去。历史上于禁晚节不保（降关羽），这里让他以牺牲收场，等于给熟梗一个反转 ⚠️待核实（推论，需核对原作有没有这层意思）
- **能借**：代价可以是失去伙伴（和 YR-6 一回事）；熟梗人物的"历史评价"可以在剧里被改写，观众会有"原来他还有这一面"的感受
- **不能借**：在回忆里交代的牺牲分量有限，最好让观众先认识这个伙伴再失去

### ZH-3 守护灵要认主

- **类型**：关系写进能力
- **规则**：夏侯惇、夏侯渊兄弟是一同认可了曹焱兵的实力才追随他；张辽最初奉曹操为主，直到曹焱兵和十殿阎罗龙核链接后才正式认曹焱兵为主
- **量级**：不适用
- **代价**：不适用
- **分几层**：不认 → 认可实力 → 认主
- **情绪**：被认可
- **能借**：能力（守护灵）有自己的意志，认可要靠赢来。关系变化直接等于战力变化（和 KR-4 一回事）
- **不能借**：每个守护灵都走一遍认主，节奏会拖

### ZH-4 曹焱兵被曹操夺舍

- **类型**：熟梗带来的反转
- **规则**：守护灵们生前的主公是曹操。剧情中曹焱兵被曹操夺舍，许褚一声"丞相"让观众意识到眼前的已经不是曹焱兵 ⚠️待核实（个人解读文章）
- **量级**：不适用
- **代价**：主角失去自我
- **分几层**：不适用
- **情绪**：震惊
- **能借**：熟梗本身带着历史关系（曹操是他们的主公），这层关系可以翻成威胁；一个称呼就能完成揭示，不用解释
- **不能借**：细节未核实，暂只作参考

### ZH-5 夏铃的守护灵李轩辕

- **类型**：守护灵和宿主之间的旧缘
- **规则**：李轩辕生前和夏铃的祖先木文元香相爱，为了救身患恶疾的元香，打算借师父的神器清风化煞来治病。武器是清风化煞
- **量级**：网剧里李轩辕打倒了黑尔
- **代价**：不适用
- **分几层**：不适用
- **情绪**：前世情缘
- **能借**：能力和宿主之间有一段过往，情绪就写进了能力里（和 YR-2 的心结同一个方向）
- **不能借**：前世情缘要交代就要回忆，短剧里只能给一个画面

## 火影忍者（NR）

### NR-1 小李 vs 我爱罗（中忍考试）

- **类型**：死斗，输了但燃
- **规则**：小李不会忍术，只会体术；我爱罗的沙子自动防御。小李腿上一直绑着负重
- **量级**：凯老师同意后，小李卸下负重，负重落地砸出两个大坑，速度暴涨。观众瞬间明白他之前一直带着这么重的东西在打
- **代价**：开八门遁甲（开到第五门）撕裂身体；我爱罗趁机压碎了他的手臂和腿，骨头碎片卡进脊柱，后来只有纲手能做这台手术
- **分几层**：被沙子挡住 → 卸负重 → 一门一门开八门 → 输
- **情绪**：努力能不能赢天才
- **能借**：
  1. 量级用熟悉的物件做参照（负重砸坑）
  2. 代价看得见、一层层加码
  3. 输也可以是全剧最燃的打斗之一，因为观众看到了他押上的一切
- **不能借**：输的代价太重（几乎断送忍者生涯），要有后续交代，不能让角色就此消失

### NR-2 鹿丸 vs 飞段（疾风传）

- **类型**：规则战 + 复仇
- **规则**：飞段的诅咒要在他的仪式圆圈里才生效；飞段不死
- **量级**：飞段杀了鹿丸的老师阿斯玛
- **代价**：不适用
- **分几层**：鹿丸看穿"必须在圆圈里" → 用影子模仿术把飞段拉出圆圈 → 把飞段和角都分开、引进奈良家的森林 → 炸开、把还在说话的飞段埋进只有奈良家知道的地方。阿斯玛留下的打火机，有说是最后一击，有说是放在土堆上致意 ⚠️待核实
- **情绪**：为老师报仇
- **能借**：
  1. 规则战：先看穿规则的前提条件（圆圈），再破坏前提
  2. 对付"不死"的对手，解法不是打死而是让他永远出不来，回头一想合理
  3. 遗物（打火机）把情绪和最后一击绑在一起
- **不能借**：鹿丸的推理过程如果全靠台词，节奏会塌，要用画面让观众自己看到"他总在圆圈里"

### NR-3 卡卡西的铃铛测试（第 5 集前后）

- **类型**：教学战
- **规则**：三个人抢卡卡西腰上的两个铃铛，抢不到就回忍者学校。三人各自单干，都失败了。测试真正考的是团队合作；动画里三人违反"不许帮"的规定喂了鸣人吃饭，反而通过了。卡卡西这一课是从他小时候的朋友带土那里学来的
- **量级**：卡卡西轻松戏耍三人
- **代价**：不适用
- **分几层**：各自单干 → 全部失败 → 违规互助 → 通过
- **情绪**：团队
- **能借**：
  1. 教学战的规则是假的，真正考的是另一件事。观众和角色一起被骗，再一起"懂了"
  2. 老师的这一课有来历（带土），给后面埋了线
- **不能借**：动画和漫画版本有差异，引用时以动画为准

### NR-4 鸣人 vs 佐助，医院天台

- **类型**：切磋战，打出关系裂缝
- **规则**：螺旋丸对千鸟
- **量级**：卡卡西出手打断，两人的招打在水塔上。佐助在意的是谁打出的洞大；水塔被千鸟打的一面只是小洞，被螺旋丸打的那一面整个背面都炸开了 ⚠️待核实（谁在什么时候看到的，来源说法不一）
- **代价**：不适用
- **分几层**：一层
- **情绪**：嫉妒；佐助的骄傲被打碎
- **能借**：
  1. 切磋不分胜负，重点是关系变化
  2. 用一个物件（水塔）做量级的裁判，不用任何人说谁更强
- **不能借**：没有前面长期的竞争铺垫，水塔这一下就只是一个洞

### NR-5 自来也 vs 佩恩 → 鸣人 vs 佩恩

- **类型**：前辈死于压制战，留下解法；后辈用规则战加关系收场
- **规则**：佩恩六道是六具身体，每具一种能力（天道操纵引力和斥力，饿鬼道、地狱道等各司其职）
- **量级**：自来也和其中三具打完以为赢了，佩恩又出现，砍断了他的左臂；木叶被佩恩摧毁
- **代价**：自来也战死
- **分几层**：自来也被压制 → 临死前破解了佩恩身份和能力的关键情报，送给鸣人 → 鸣人用仙人模式迎战六道 → 和长门对话，用说服收场
- **情绪**：师父的死；长门的仇恨
- **能借**：
  1. 前辈用命换来解法，后辈用这个解法赢：一场压制战直接变成下一场规则战的铺垫
  2. 对手由多个身体组成、各有一种能力，逐个破解就是天然的分层
- **不能借**：用一番话结束死斗，被观众戏称为"嘴遁"。说服要有前面的铺垫（两人相似的经历），不能光靠说

## 咒术回战（JJ）

### JJ-1 五条悟 vs 漏瑚（动画第 7 集，漫画第 14 话）

- **类型**：亮相战兼教学战
- **规则**：五条悟的"无下限"让攻击停在他面前碰不到他；漏瑚放出领域"盖棺铁围山"困住五条悟和虎杖，五条悟摘下眼罩，展开领域"无量空处"
- **量级**：漏瑚是特级咒灵，被当成教具。无量空处向漏瑚的感官灌入无限的信息，漏瑚说"什么都看得见，什么都感觉得到，信息永远接收不完，所以什么都做不了"
- **代价**：无
- **分几层**：无下限挡住攻击、让漏瑚"够过来试试" → 漏瑚开领域 → 五条摘眼罩开无量空处 → 漏瑚动弹不得
- **情绪**：震撼
- **能借**：
  1. 亮相战同时是教学战：五条悟把虎杖带在身边看，一边打一边讲，观众和虎杖一起学会"领域是什么"
  2. 对手越强，被当教具时越能立住主角方的量级
- **不能借**：一边打一边讲解，只有在碾压时成立；势均力敌的仗里停下来讲解会拖节奏

### JJ-2 七海建人：上班族的咒术

- **类型**：能力规则和人物身份一体
- **规则**：术式"十划咒法"把目标十等分，在 7:3 的位置强行制造弱点。他给自己立了"加班"的束缚：工作时间内压着咒力，超过工作时间后咒力反而增强（具体比例来自粉丝站 ⚠️待核实）。他还有一个"亮出底牌"的束缚，对真人时一起用过 ⚠️待核实
- **量级**：不适用
- **代价**：工作时间内压着自己
- **分几层**：上班时间 → 加班后增强
- **情绪**：讨厌加班的社畜，观众自带共鸣
- **能借**：规则来自观众最熟悉的日常（上班、加班），零理解成本；规则本身就是人设
- **不能借**：日常梗只能用在人物身上一两次，反复强调就成了段子

### JJ-3 东堂的不义游戏，和虎杖一起打花御

- **类型**：团战 + 教学战 + 规则战的拐弯
- **规则**：东堂拍手，就能把自己、虎杖或附近的东西对调位置；他也可以拍手却不换
- **量级**：花御是特级咒灵
- **代价**：不适用
- **分几层**：东堂在战斗中教虎杖打出黑闪（靠进入心流状态反复打出）→ 虎杖连续三次黑闪 → 花御预判第四次会换位、提前防备 → 东堂拍手但不换 → 第四击命中（依据章节摘要 ⚠️待核实）
- **情绪**：搭档的爽快
- **能借**：
  1. 规则越简单，观众和对手越会预判；预判一形成，假动作就是最好的拐弯（"猜 → 验证"的精髓）
  2. 团战里的分工清楚：东堂控位置，虎杖输出
  3. 教学战和实战合在一起，学会的东西当场兑现
- **不能借**：假动作只能用一两次，用多了观众不再预判，拐弯就没了

### JJ-4 领域展开与领域对撞

- **类型**：终极招式的仪式；同类能力的层次差
- **规则**：领域展开内，施术者的术式必中。两个领域相撞，更精炼的一方压过另一方。五条悟和宿傩的对决中（漫画第 225 话），宿傩在五条悟的无量空处里展开自己的领域，用"解"破坏结界，必中效果斩中五条悟的脖子。两个必中如何互相抵消、结界怎么破的，来源说法不一 ⚠️待核实
- **量级**：最强对最强
- **代价**：五条悟重伤
- **分几层**：领域对领域 → 一方结界被破 → 必中生效
- **情绪**：紧张
- **能借**：
  1. 终极招式有清楚的胜负规则（"更精炼的胜"），最强对最强也能看得懂
  2. 手印加招式名，是观众等着看的仪式
- **不能借**：领域对撞的细节规则后期越来越复杂，连粉丝都在争，短剧里只保留一条最简单的胜负规则

## 全职猎人（HX）

### HX-1 酷拉皮卡的锁链

- **类型**：限制即执念
- **规则**：酷拉皮卡在自己心脏上缠了一条"律法之链"立下誓约：束缚之链只能用在幻影旅团身上，用在别人身上他就会死。"绝对时间"在他眼睛变红时发动，让他百分之百运用所有系的念，代价是缩短寿命（具体怎么换算，来源说法冲突 ⚠️待核实）
- **量级**：对旅团是绝对压制
- **代价**：用错对象就死；绝对时间折寿
- **分几层**：不适用
- **情绪**：复仇
- **能借**：
  1. 誓约越狠，力量越大，代价越重，观众越在乎这一战
  2. 限制把人物的执念直接写进了能力（只能对仇人用），也逼他做选择
- **不能借**：限制太狠会把角色锁死在一条线上，故事要给他别的出路

### HX-2 尼特罗会长 vs 蚁王

- **类型**：死斗，分层升级，最后一层是情绪反转
- **规则**：百式观音以极快的速度挥动观音的手臂出掌
- **量级**：一个老人对完美生物
- **代价**：尼特罗的命
- **分几层**：百式观音猛攻 → 蚁王开始分析、预判尼特罗的动作 → 零之掌倾尽全部气，仍打不倒蚁王 → 引爆体内的炸弹"蔷薇"，和蚁王同归于尽。蚁王没有当场死，中了蔷薇的毒，最后几个小时和盲女小麦下军仪，两人手牵手中毒而死
- **情绪**：人类赢过完美生物，靠的不是武，是人性里最丑的那部分；蚁王最后的温柔让观众同情反派
- **能借**：
  1. 死斗分层，每一层都比上一层更狠，最后一层的反转是情绪上的
  2. 仗的胜负模糊：技术上蚁王赢了，结局上人类赢了
  3. 反派在结局被同情（和"对手是受害者"相通）
- **不能借**：蚁王篇极长，蚁王的转变铺了几十集，短剧要压缩到最核心的一两个画面

### HX-3 小杰一行 vs 爆弹魔根斯（贪婪之岛）

- **类型**：规则战，规则交代是能力生效的条件
- **规则**：根斯说出"Bomber"就能在目标身上放炸弹（倒数），而且必须把这个能力的规则讲给目标听才生效。被放炸弹的人摸到他并说"抓到炸弹魔了"就能解除
- **量级**：爆弹魔一伙杀了不少玩家
- **代价**：小杰的一只手被炸断，后来用"大天使的气息"治好
- **分几层**：被放炸弹 → 研究规则、制定对策 → 小杰拼命打赢，拿走所有卡片
- **情绪**：险胜
- **能借**：对手必须把规则讲给你听，"交代规则"本身就是剧情动作，不是讲课（和 JJ-2 七海"亮出底牌"同一个方向）
- **不能借**：规则细节多，短剧里只保留一条关键条件

### HX-4 小杰成年化 vs 尼飞彼多

- **类型**：变强方式 C（情绪爆发）的极端版
- **规则**：凯特死在尼飞彼多手里，小杰愤怒到极点，立下誓约押上全部潜力和生命力，暂时变成大人
- **量级**：成年小杰压倒尼飞彼多
- **代价**：打完以后濒死，失去念（"永久失去"还是"严重损伤"，来源说法不一 ⚠️待核实）
- **分几层**：凯特之死 → 小杰愤怒 → 誓约 → 成年化 → 打败尼飞彼多 → 濒死
- **情绪**：爽和恐惧并存，观众被主角吓到
- **能借**：情绪爆发可以让观众害怕，而不只是爽；代价大到几乎毁掉主角，这一下的分量就到顶了
- **不能借**：只能用在季终级别的节点，而且后面要用很长的戏来救主角

## 奥特赛文（SV）

> 资料：Ultraman Wiki 分集页的剧情与花絮（含编剧、导演访谈的转述）；口碑见《[参考作品/奥特赛文](参考作品/奥特赛文.md)》。2026-11-01 整理。

### SV-1 被盯上的街（第 8 集）

- **类型**：主题问题集：信任；名场面不是打斗
- **规则**：梅特隆星人在北川町的自动售货机里卖掺了"宇宙罂粟"种子的香烟，抽了的人会把身边的人都看成敌人、想杀死对方。安娜的舅舅驾驶的客机坠毁，130 人遇难；队员古桥、曾我抽了也暴怒
- **量级**：外星人只做了一个"实验"，就让一座城陷入互相残杀
- **代价**：无辜的人死去
- **分几层**：街上接连有人突然暴力 → 队员也中招 → 弹查出香烟里的种子 → 蹲守售货机，跟踪补货的人进了一间破旧的老公寓，梅特隆星人坐在矮桌前礼貌地等他 → 外星人解释：毁灭地球最简单的办法，是播下不信任和仇恨，让人类自己毁掉自己 → 弹被困飞船、获救，变身打败它 → 旁白：人类之间的信任，还远没发展到能被外星人利用的程度
- **情绪**：冷到骨子里的讽刺
- **能借**：
  1. 对手的武器是一件日常物品（香烟），规则作用在人和人之间的信任上。编剧金城哲夫说，当时日本大约一半的人抽烟，这个设定"真实得可怕"
  2. 全集最有名的一场是外星人和弹隔着矮桌、坐在榻榻米上对话。导演实相寺昭雄故意违反电视台"减少日本元素、方便出口"的要求拍成这样。超现实的对手放进最日常的空间，反差本身就是名场面
  3. 打斗很短，问题放在最后一句旁白里。这句冷嘲的旁白不在原剧本里，是导演加的（也有说法是佐佐木守应导演请求写的）
- **不能借**：剧本改了三稿，最后才从"抽烟引发核事故"收到"人与人失去信任"。主题问题要收得足够小，一句话说得清

### SV-2 超级武器 R1 号（第 26 集）

- **类型**：主题问题集：军备竞赛；对手是人类造出来的
- **规则**：防卫军造出能毁灭一颗行星的炸弹 R1，挑了一颗"没有生命"的基罗恩星做试验，准备效果好就造 R2。星球被炸毁，唯一的居民变异成星兽，飞来地球
- **量级**：它被炸碎以后第二天又完全复原，从嘴里喷出放射性灰烬
- **代价**：赛文的手受伤；星兽的放射性血液污染了一大片土地
- **分几层**：队员们为 R1 欢呼，只有弹不安，说军备竞赛是"一场边吐血边跑的悲伤马拉松" → 试验成功，星球被毁 → 星兽来袭，被炸碎又复活 → 赛文手受伤，最后扯下它的手臂、斩断它的脖子 → 科学家后悔，队长桐山也说出弹那句话，决定去说服委员会取消 R2
- **情绪**：悲哀，没有胜利的喜悦
- **能借**：
  1. 对手是人类自己造出来的：怪兽的来历，就是这一集要问的问题
  2. 主题用主角的一句话说出来，再在结尾让最不同意他的人重复这句话，问题就落了地
  3. 同一段音乐《死之悲》在一集里用了四次，都在"讨论武器"和"后悔"的时刻；打斗在花田里，配的却是主题曲。美术团队的目标是"拍出地球的美"，所以选了花田
  4. 场景里有一座仿原爆前浦上天主堂的模型，用画面而不是台词传达反核
- **不能借**：2011 年福岛核事故后，这集的重播被取消过。现实议题要注意时间和平台尺度

### SV-3 孤独的地球人（第 29 集）

- **类型**：主题问题集：孤独；被理解的人竟是敌人
- **规则**：大学教授丹羽其实是普罗特星人。研究生一宫的瞬间移动理论没人理会，只有教授认真对待，还帮他造出了装置；一宫明知教授是外星人，仍说他是好人，说自己不相信人类
- **量级**：外星人扫描了曾我的全部记忆，把防卫军全球基地的情报装进卫星
- **代价**：一宫的命
- **分几层**：一宫拒绝被保护 → 发现教授要拿卫星去策划侵略，感到被背叛 → 教授现出原形要杀他 → 赛文对战外星人的幻影分身 → 一宫把自己和外星人一起推进只能传送一个人的装置，装置损毁，两人消失 → 弹说：他也许还活着，在宇宙某处望着地球
- **情绪**：才华不被承认的人，最后独自保护了地球
- **能借**：
  1. 编剧市川森一说，一宫就是年轻时的自己：剧本屡屡被退，被说"你没才能，放弃吧"，心里想的是"我明明有才能，为什么世界不承认"。他一口气写完了这一集
  2. 对手不是来硬打的，是来"理解"一个没人理解的人，这比威胁更危险
  3. 结尾给牺牲者留一个"也许还活着"的余地，悲伤里留了一点温柔
- **不能借**：市川自己也觉得结尾"有点简单"

### SV-4 被盗的奥特眼镜（第 37 集）

- **类型**：情感单元：被母星抛弃的对手；送别
- **规则**：少女玛雅是麦哲伦星人，任务是偷走奥特眼镜。她从天文馆、酒吧里给母星发信号，请求来接她；母星回答：不接，星际导弹已经在路上了，七个小时后撞上地球
- **量级**：导弹的装甲连空间站都撞毁了
- **代价**：玛雅的命
- **分几层**：弹被逼下悬崖，眼镜被偷 → 在酒吧里用心灵感应和她对话，她否认母星要侵略 → 警备队截获母星的回复 → 酒吧里所有客人都戴着假眼镜，被她弹吉他催眠，围攻弹 → 弹把母星的回复给她看，她明白自己被抛弃了，把眼镜还给他 → 赛文飞进导弹，把它推离地球 → 玛雅在酒吧里放出毒气自尽；弹捡起她的胸针，想她为什么不试着在地球上活下去
- **情绪**：都市年轻人的孤独
- **能借**：
  1. 编剧市川森一年轻时常在新宿、六本木的酒吧跳舞到天亮，和陌生人说笑，他们都来自外地、满怀梦想，天亮分开时不留名字，各自回去，孤独涌上来，眼泪就掉下来。他把这种"青春的孤独和荒凉"直接写进了这一集：弹是从长崎来东京的他自己，玛雅是他在酒吧里遇到的外地女孩
  2. 对手本身是受害者，而且是被自己的人抛弃（和 TG-4、YR-8 一回事）
  3. 限制（眼镜被偷就变不了身）不只用来"压"，还让主角不得不先和对手对话
- **不能借**：初稿里玛雅从一开始就准备赴死，市川说本来是"弹的初恋故事"。定稿收得更克制。短剧里感情线要在一集内交代清楚

### SV-5 侬马鲁特的使者（第 42 集）

- **类型**：主题问题集：谁才是侵略者；正义一方存疑
- **规则**：男孩真一警告安娜：别再开发海底，否则"侬马鲁特"会保卫自己的家。弹想起，"侬马鲁特"正是他的故乡 M78 对地球人的古称。真一说，侬马鲁特才是地球原来的主人，是很久以前被人类赶进了海里
- **量级**：海底基地被炸；沉没的核战舰被侬马鲁特开出来攻击海边村庄
- **代价**：侬马鲁特的海底都市被全部毁灭
- **分几层**：警告被当成恶作剧 → 基地爆炸 → 打倒章鱼怪兽 → 战舰浮出、攻击村庄，弹不顾真一反对变身 → 水下发现侬马鲁特的都市，队长桐山一度犹豫，最后认定那是外星人的侵略基地，下令摧毁 → 队员们在海滩庆祝，只有弹和安娜心里不安：也许人类才是侵略者 → 两人循着真一的声音来到悬崖，一个母亲在墓前哭泣：她的儿子真一，爱海，两年前的今天淹死了
- **情绪**：胜利以后的不安
- **能借**：
  1. 主角自己的身份里藏着这个问题的钥匙："侬马鲁特"是他家乡对地球人的称呼。主角不是旁观者
  2. 庆祝和不安同时出现：全队欢呼，主角两人沉默，问题落在余波里，不替代打斗
  3. 结尾一个物件（墓碑）把前面所有的"男孩"翻转成另一种东西
  4. 这集起源于导演满田𥙿和金城哲夫喝酒时的一句话："地球人真的是地球原来的主人吗？"金城说"这能写成故事"
- **不能借**：剧本里原本写明"真一化为灵魂，成了侬马鲁特的使者"，定稿删掉了，留给观众去想。短剧的观众未必接得住这么大的留白，要权衡

### SV-6 史上最大的侵略（第 48–49 集）

- **类型**：季终：逼选择的限制；身份揭开；人类出力
- **规则**：弹的身体被连年的战斗透支，发高烧，打不中敌机。M78 的上司现身，求他回故乡养伤，警告他不能再耗能量；第 49 集上司再次出现：再变身就会死
- **量级**：戈斯星人摧毁世界多座大城市，限半小时投降，否则毁灭东京
- **代价**：他可能回不了家
- **分几层**：因为发烧失误，天城被抓 → 他不顾警告变身，打倒潘顿后倒下 → 为了不被体检发现身份，他溜出基地，被仓田当成逃兵 → 警备队准备用地底战车炸掉敌人基地，天城还在里面 → 安娜找到他，他说出自己是赛文；安娜说：你永远是弹 → 他告别，最后一次变身，救出天城 → 安娜把真相告诉全队，三架鹰号一起出击协助，赛文斩下潘顿的头 → 他用最后的力气飞回故乡；古桥说相信他会康复，也许有一天还会回来
- **情绪**：告别
- **能借**：
  1. 限制在季终兑现成选择：上司的警告每次出现，都是一次"要不要变"
  2. 揭开身份的那场戏，配的是舒曼的《A 小调钢琴协奏曲》，从坦白一直延续到最后一战。作曲冬木透认为原先提议的曲子不够强烈，撑不住"弹说出自己是外星人"那一刻。一来是为了加强情绪，二来是来不及作新曲
  3. 人类在最后一战出力（和 TG-8、TG-9 一回事）：知道真相的队员们一起出击
  4. 编剧金城哲夫把对故乡冲绳的思念写进了"不得不回去"，为了回去，有时要牺牲眼前珍惜的一切（市川森一的回忆）
- **不能借**：季终级的告别只能用一次

### SV-7 黑暗地带（第 6 集）

- **类型**：主题问题集：无法共存；对手是难民
- **规则**：一个影子躲进安娜的房间，说自己受了伤，只想歇一会儿，求她别报警。它来自一座在宇宙中漂流的城市，佩加萨人逃离了快要毁灭的母星，什么都靠机器生产。城市动力坏了，80 小时后会撞上地球；对方的回复是："把地球的轨道倒过来就行"，地球却做不到
- **量级**：城市的密度是地球的八万倍，一撞两边都完
- **代价**：整座城市被毁
- **分几层**：影子和弹、安娜聊天，说起它的城市，劝弹别让人类变得和它们一样依赖机器，又说人类和他们没法一起生活 → 地球联系不上城市，决定摧毁它；弹求先疏散，被驳回 → 警备队到城市跟前喊话，对方不予理会，城市被核武器炸毁 → 影子向安娜道歉，现出原形：它是被派来炸毁地球的，一直拖到最后，是希望自己的人能避开相撞 → 弹告诉它城市已经没了，它愤怒，赛文缴了它的炸弹，它逃进阴影里 → 安娜说，以后每次看到影子，都会想起它在哪里
- **情绪**：两种文明都没有错，却没法共存
- **能借**：
  1. 对手第一次出场不是在打，是在聊天：它先赢得了主角的好感，再揭开身份
  2. 灾难的起因是双方能力不对等："你们把轨道倒过来就行"，对方根本不知道地球做不到
  3. 结尾不给出路：最后一个佩加萨人只能在地球的阴影里流浪
- **不能借**：初稿让外星人在对话里尖锐批评 1960 年代的社会，二稿转向"过度依赖科技"，定稿才收成"无法共存"。主题问题要收到一句

### SV-8 奥特警备队向西（第 14–15 集）

- **类型**：两集单元：误会引发战争；量级很高的机器人对手
- **规则**：地球的观测火箭被佩丹星人当成侵略的前兆，他们发誓报复；关西接连有外国人被暗杀，死者都是防卫军国际科学小组的人。保护对象女科学家多萝西其实是佩丹星人假扮的
- **量级**：四个部件合体成机器人金古桥，赛文的招式全打不动
- **代价**：多萝西的记忆被清空
- **分几层**：（前编）护送、遇刺、潜艇被毁，发现内鬼 → 金古桥合体，压倒赛文，停在最低点 →（后编）弹以外星人对外星人的身份和佩丹星人谈判："错在地球人"，地球停止研究对付他们的武器，他们撤离；对方答应 → 送回来的真多萝西记忆被清空，弹开始怀疑 → 佩丹舰队来袭 → 科学家只造出一发能打穿装甲的炮弹，等一个时机 → 赛文举起金古桥，警备队一发命中 → 佩丹撤退，多萝西说以后发观测火箭会更小心
- **情绪**：被背叛的约定
- **能借**：
  1. 两集单元：前编停在主角被压倒，后编从谈判开始，正好是框架里"两三集的单元怎么断"
  2. 主角的外星人身份成了谈判筹码，又因此被背叛（日文博客说"佩丹星人和弹的约定被打破"是看点）
  3. 只有一发的武器：把翻盘压到一次机会上
  4. 金古桥"四个部件合体"来自导演满田和金城哲夫讨论出的"把散落的东西聚到一起"，部件本来想做更多，嫌合体太复杂，定成四个
- **不能借**：关西取景是赞助商（总部在大阪的武田药品）要求的。制作约束反而促成了一集名作，但这种条件可遇不可求

### SV-9 零下 140 度的对决（第 25 集）

- **类型**：对手专门克制主角；人类自己出力
- **规则**：波尔星人制造暴风雪，基地供暖的反应堆被怪兽冈达弄坏，系统瘫痪，战机和超级武器都用不了。弹生在没有雪的 M78 星云，怕冷，又在雪里弄丢了奥特眼镜。这一集第一次交代他额头的灯会闪，变身有时间限制
- **量级**：外星人自称地球历次冰河期都是他们干的
- **代价**：有人冻伤，医生一再请求撤离被部长拒绝
- **分几层**：弹在雪里步行回基地，昏倒，幻觉里外星人嘲笑他怕冷 → 眼镜丢了，只能放米克拉斯，米克拉斯被冻住 → 部长终于同意撤离，自己也冻倒；最后一个工程师坚持独自修好了反应堆 → 恢复动力的警备队把怪兽打退 → 赛文找回眼镜，先飞向太阳充能，回来斩杀冈达 → 外星人满意地撤退：打败它们的终究是人类，而赛文是能被削弱的
- **情绪**：坚持
- **能借**：
  1. 对手的规则直接针对主角的弱点（怕冷），而且这个弱点到这一集才揭开（和 OP-2 的"对手克制主角"一回事）
  2. 主角不在的时候，配角撑住局面：一个无名工程师修好了反应堆
  3. 反派撤退时的判断（"打败我们的是人类"）是对这一集的总结，说给观众听
- **不能借**：制片熊谷健说，连续两集雪景部分是为了海外市场，那里少见下雪。天气题材要看拍摄条件，当年冬天太冷，后面的拍摄因此很辛苦

### SV-10 赛文暗杀计划（第 39–40 集）

- **类型**：两集单元：对手研究透主角，压到最低；人类救奥特曼
- **规则**：加茨星人观察赛文对付怪兽的战斗，记下他的全部招式，计划在他化身赛文时杀掉他，打垮人类的士气。他们接连谎报警情，引弹出来
- **量级**：温达姆被它们轻易摧毁；赛文所有招式都无效
- **代价**：赛文被钉上十字架，宣布黎明公开处决
- **分几层**：（前编）弹察觉陷阱，一次次避免变身 → 曾我被抓，桥被炸断，弹不得不变身 → 赛文所有能力都失效，力竭，被钉上十字架；外星人当众展示，给人类 12 小时 →（后编）警备队收到来自赛文大脑的信号：合成一种能量能让他复活，需要一种非洲宝石，古桥手里只有半块 → 另一半在妹妹的朋友那里，她被外星人绑走，原来她戴的是假的，真的在家 → 第一次射击打中的是幻影 → 用她做诱饵找到真身 → 黎明，曾我一枪命中，赛文复活，摧毁空间站 → 队员们找到躺在草地上的弹，把他抛起来庆祝
- **情绪**：绝望到狂喜
- **能借**：
  1. 编剧藤川桂介故意反着写：不是主角用全力打赢，而是一开始就把赛文的能力封掉，整个故事讲他在限制下怎么活下来、怎么反击
  2. 导演饭岛敏宏是被请回来"救收视"的，他借用时代剧和动作片的结构：前半刻意把主角逼到绝境，后半大逆转
  3. 公开处决加 12 小时期限，给了观众一个看得见的倒计时
  4. 翻盘的钥匙是前编开头随手出现的半块宝石（铺垫在前面）；人类救奥特曼（和 TG-9、SV-6 一回事）
- **不能借**：剧本改了四稿，最早的版本甚至是给另一部剧《红人》写的。两集单元的结构要先定，再填人物

### SV-11 第四行星的噩梦（第 43 集）

- **类型**：主题问题集：自动化；低成本的科幻
- **规则**：弹和曾我试飞全自动远程火箭，进入冬眠后火箭失控，他们醒来时到了"第四行星"：两千年前机器人取代了它们的人类主人，人类只能服从，要求平等的人被处决。机器人计算出这里的人类五百年后会灭绝，准备去征服地球的人类
- **量级**：整个星球的机器统治
- **代价**：要求平等的人被当众处决
- **分几层**：加油站有日文招牌，两人以为回到了地球；打不通总部的电话 → 军官打了差点被车撞的男孩，还逮捕了他们 → 长官是机器人，助手打开它的头给齿轮上油 → 参观"综合中心"：处决、数据中心 → 助手是那个男孩的姐姐，带他们逃到人类的村子，只有一个人肯帮忙 → 赛文摧毁中心和舰队 → 回到地球，队长仍然认为试飞证明了自动化是成功的，两人强烈反对
- **情绪**：不寒而栗
- **能借**：
  1. 导演实相寺昭雄受戈达尔《阿尔法城》启发：不靠特效、不靠科幻道具，把熟悉的现实街景拍得陌生，照样讲出一个科幻故事；两部作品都是低预算
  2. 地球上的一切看起来都一样（日文招牌、加油站），只是人和机器的位置颠倒了，熟悉里的反常
  3. 结尾把问题带回自己人身上：队长还在为自动化高兴
- **不能借**：原本的第 43 集方案是"外星人 15 + 怪兽 35"、一集出五十多只怪兽，因为收视和预算被否了。大场面不是唯一的答案，但这也说明这种集要有导演的风格来撑
